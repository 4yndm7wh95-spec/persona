# P3R 原版系统音效分析（风格参考）

来源：`research/p3r_audio/p3r_general_system_sfx.mp3`（Persona 3 Reload - General System Sound Effects，8 分 39 秒）。
**仅用于风格分析，任何原声都不放进 mod**；mod 里的音效全部是程序合成（`mod/src/Audio/Sfx.cs`）。

## 切分
按静音（-55dB、间隔 ≥120ms）+ 强起音切分，得到 535 个独立音效。

## 测量结果（能量加权）
| | 数量 | 频谱重心中位 | 低频（<200Hz）占比中位 | 起音中位 |
|---|---|---|---|---|
| 短音（<0.4s） | 202 | ~1.9 kHz | ~2% | 30 ms |
| 长音（≥0.8s） | 191 | ~1.7 kHz | ~27% | 200 ms |

## 风格要素
1. **快速大幅颤音的合成音**（最有辨识度的"P3 数字感"）：颤音 14~28 次/秒，深度 ±15%~70%，同时音高大幅滑动。
   例：#35 840→320Hz、14 次/秒、±62%；#47 495→1380Hz、27 次/秒、±45%；#44 185→676Hz、19 次/秒、±16%。
2. **干净的琶音**：先一个高音点缀（~2.8kHz），约 260ms 后每 75~85ms 一个音，大致 C 大调 G5–C6–E6–G6–C7，带回声。
3. **慢慢涌起的宽频风声**：起音 200~370ms，持续 1.3~2s，低频约占四分之一，重心约 1~2kHz。
4. 锯齿状反复扫频、固定音高的节奏脉冲、纯正弦提示音。
5. **没有**非谐波铃声 / 高频闪光颗粒 —— 我们第一版"太亮"的根源是这类音色，而不是频率本身。

## 合成对照（v0.9.1 重做后）
`Sfx.cs` 新增 `Warble`（颤音 + 滑音的三角波）、`Arp`（琶音）、`Echo`（反馈回声）；七个音效全部改用以上词汇，
低频占比 / 重心对齐到原声的范围（冲击类低频占比 0.2~0.45，重心 0.4~1.2kHz；塔纳托斯斩击刻意更低沉）。
