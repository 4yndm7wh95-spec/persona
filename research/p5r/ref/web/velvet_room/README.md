# P5 / P5R 天鹅绒房间参考图（监狱主题）

圆形大厅、一圈牢房和铁栏、冷蓝色菱格软包墙、中央蓝底金色月桂纹地毯、伊戈尔的桌子；看守双子卡萝莉娜、芮丝汀娜；拉雯妲。只收 P5 / P5R 的监狱版天鹅绒房间，没有 P3、P4 的。

## 来源
- 全部来自 **Megami Tensei Wiki（megamitensei.fandom.com）** 的公开图片页，是官方插画、设定图、游戏内截图或官方宣传片截图。`sources.csv` 逐张列出 wiki 文件页和原图地址。
- P5R 的天鹅绒房间场景、伊戈尔、双子造型和原版 P5 相同，所以场景和伊戈尔用了 P5 的游戏内画面和设定图；明确标为 P5R 的只有 `11`、`12`、`13`。

## 获取方式与尺寸
- 网络策略不允许直接下载 wiki 图片，所以是在浏览器里以原始像素打开原图后分块截屏、再拼回原图尺寸。大图（超过 1920 宽或高于屏幕）用 wiki 的缩放地址按屏幕能放下的尺寸截取，每张的实际尺寸和原图尺寸写在 `sources.csv` 里。
- 截图统一保存为 PNG，原图是 JPG 的会比原文件大一点，但每张都不超过 3MB。

## 没找到 / 有缺口的画面
- **双子站在牢房铁栏外的正面游戏内画面**：只找到 `10`（侧面，背景是铁栏）。
- **第三学期拉雯妲的全身游戏内画面**：没找到；`14` 是官方全身设定原画（第三学期造型相同），`13` 是 P5R 半身插画。wiki 上的「蒙面拉雯妲」图出自《P5 战略版》，不是 P5R，所以没收。
