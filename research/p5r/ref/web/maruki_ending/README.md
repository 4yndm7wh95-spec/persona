# P5R 丸喜结局「SHOT / 将军」参考截图

第三学期最终战，对原人亚当（Adam Kadmon）的最后一击：怪盗团顶住巨人的拳头 → Joker 冲上巨人手臂 → 弹出「SHOT」按键提示 → 「将军」→ 开枪白闪 → 巨人崩塌。

## 来源
- 全部截自 B 站公开视频 **BV1GK4y1q7Lq「[P5R]『将军』！」**（上传者 Thres1h，水印 Canwinker，时长 2:47）：https://www.bilibili.com/video/BV1GK4y1q7Lq/
- 画面是简体中文版实机录像，按键提示显示为 **「SHOT」+ Xbox A 键图标**（英文版是「FIRE」，这里没找到英文版画面）。
- `sources.csv` 逐张列出：文件名、画面内容、来源网址、视频时间码。时间码标「约」的是转场段，误差 1～2 秒。

## 获取方式与质量说明（请注意）
- 这个工作环境的网络策略不允许直接下载 B 站 / YouTube / wiki 的媒体文件（yt-dlp、curl 都被拦截），YouTube 在浏览器里也无法播放。所以**没有下载视频，也没能按 0.5 秒间隔逐帧截取**，而是在浏览器里打开 B 站播放器，跳到各时间点后截屏，共 34 张，覆盖整段的关键镜头。
- 源视频清晰度约 **360p**，大部分截图是 640×360 原始像素（少数 854/1401 宽的是放大播放时截的，没有更多细节）。上传者剪辑时给画面加了**不规则的黑色波浪边框**，右下角有游戏的「跳过 / LOG」按钮，右上角有 B 站水印。
- 仓库里没有放任何视频文件。
