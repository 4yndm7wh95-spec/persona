# P5R 原版暂停菜单 Joker：GMD / GAP 渲染

素材来自仓库里的 `research/p5r/model/joker/source/MENU_C0001_001_A.GMD` 和同名 `.GAP`。GFD Studio 0.10.3 的 GFDLibrary 完整读出 317 个节点、120 个 main 槽和 2 个 blend 槽；79 个 main 槽时长为零且无控制器，未渲染。其余 43 段的编号和时长均与 `joker_menu_anim_list.csv` 一致；所有动作控制器都找到了目标节点。

从仓库根目录运行（以下 Godot 参数使用绝对路径，`<repo>` 替换成工作区路径）：

```powershell
& C:/Users/kkk/sts2_tools/dotnet/dotnet.exe run -p:RollForward=Major --project tools/p5/menu3d/Export.csproj -- research/p5r/model/joker/source tools/p5/menu3d/scratch
& C:/Users/kkk/sts2_tools/godot/Godot_v4.5.1-stable_win64_console.exe --path tools/p5/menu3d --script capture.gd -- <repo> <repo>/research/p5r/menu3d all
py tools/p5/menu3d/sheets.py
```

导出器应用压缩 PRS 轨道的位移及缩放比例，在原始时间轴上以 30fps 采样，保留末帧；旋转使用四元数球面插值。蒙皮用 GFDLibrary 的原始逆绑定矩阵、顶点权重和动画后的骨骼世界矩阵求每帧顶点。长动作取首帧、中间一帧、末帧，文件名保留原采样帧号。Speed 单列记录，不改动时间轴。

Godot 4.5.1 以无光照材质渲染，颜色为原材质漫反射色乘原黑白贴图，使用原背面剔除和贴图 alpha 裁切。输出 1920×1080 RGBA、4×MSAA。原包没有可用的相机节点或相机轨道。共用相机根据 `frame_0052` 叠图拟合：位置 (0, 155, 70)，朝向 −Z、上方向 +Y，垂直 FOV 44°，水平偏移 −14、垂直偏移 0，远裁剪 500（GMD 单位）。叠图中头部位置接近，肩线、头部角度和原截图仍有差别。

可见片段的抽样未发现明显骨骼爆开。287 张原始帧中，229 张有可见人物或模型部分及半透明边缘，58 张在共用相机下是全透明，仍保留原采样帧；长片段和 blend 中尤为常见。没有重建游戏运行时的换装、可见性切换、UI 遮罩、轮廓和后处理。为避免同一位置的多种服装和辅助几何互相遮挡，固定用校服外观，隐藏替代衣服、对应手套、面具、模糊网格及辅助零件。这会影响依赖这些物件的片段；也因此不把所有帧当作已验证的游戏画面。脸部按材质乘贴图后比实机暗。
