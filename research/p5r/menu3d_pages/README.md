# P5R 暂停菜单子页 Joker 入场帧

用 v2（`9ffe9423`）的 GMD/GAP 蒙皮和可见网格配置重渲 SKILL、ITEM、EQUIP。沿用怪盗服、051B 黑手套和原贴图颜色。Godot 4.5.1 以 3840×2160、4× MSAA 渲染，按 2×2 像素平均缩为 1920×1080，再转换为 PNG 所需的直通 alpha。帧序列以 30 fps 采样并保留片段末帧。

## 相机

位置为 GMD 模型坐标，旋转为 Godot 的 X/Y/Z 欧拉角（度），FOV 为垂直视角。四个机位的水平和垂直偏移均为 0，远裁剪为 500。用 50% 透明叠图检查头发边缘、眼部、立领、肩线和持物方向，再适当放宽视角以留出边缘空间。完整参数在 [cameras.json](cameras.json)。

- SKILL 的站姿与停留按两段构图取景，0109–0111 大部分人物被实机白色转场遮挡。第二机位保留抬膝和俯身的连续性，俯身阶段的衣摆和肩线还有偏差。
- ITEM 的固定机位主要拟合 0183–0186 的张指、扫脸和定势。0178–0181 中参考人物从右侧向左移动，固定机位的头部偏左、偏上。近镜头的五指在扫动中仍会越过画幅右缘。
- EQUIP 的固定机位以 0241–0242 的脸部、立领和枪口为锚。0234–0239 的画面中人物明显从右向左移动，早期位置偏差较大，举过头顶的手或枪会经过画幅上缘。
- 实机剪影反色、动态遮罩、UI 遮挡和二维定格会改变画面里的边界及黑白关系。对比图保留这些参考信息，导出的透明帧只含 v2 渲染工具输出的 3D 内容。

## 复现

从仓库根运行。首次使用时用 v2 的 `Export.csproj` 命令生成 `tools/p5/menu3d/scratch`，见 [原渲染说明](../menu3d/README.md)。

```powershell
$repo = (Get-Location).Path.Replace('\', '/')
& C:/Users/kkk/sts2_tools/godot/Godot_v4.5.1-stable_win64_console.exe --path "$repo/tools/p5/menu3d" --script capture.gd -- $repo "$repo/research/p5r/menu3d_pages" pages "$repo/research/p5r/menu3d_pages/cameras.json"
py tools/p5/menu3d/page_sheets.py
```

共 38 张透明帧和 3 张对比图。检查了序号完整性、1920×1080 的 RGBA 格式、透明区的零 alpha 与零 RGB，以及轮廓半透明覆盖。
