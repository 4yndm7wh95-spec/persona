# 纸偶重做计划（rig v6）

## 为什么
见 `research/VANILLA_RIG_ANALYSIS.md`。原版：81 个插槽、54 张专门为动画画的零件、手调贝塞尔关键帧、大幅挤压拉伸、长定格、瞬间换图。
我们（v5）：一整张立绘做网格扭曲 + 几张整条手臂换图、弹簧模拟逐帧烘焙（全线性）。动作只能做小，节奏均匀发软，换图有重影。

## 素材（docs/ART_SPEC.md 阶段 9）
9A 基准图（A 字站姿、零件不互相遮挡）→ 9B 同画布编辑出的分离零件（天然对齐）→ 9C 同画布编辑出的换手图。

## 骨骼（build_rig_v6.py）
- 零件：躯干（胸 / 胯两段网格）、头（+ 头发前 / 后 / 侧三块，表情贴片）、颈、近侧上臂 / 前臂 / 手、远侧上臂 / 前臂 / 手、两腿（大腿 / 小腿 / 鞋）、外套下摆左右、领带、耳机线。
- 关节靠零件重叠（分离图本身是完整的，被遮挡处已补画），不再靠一张图扭曲。
- 武器（剑 / 召唤器）属于"握持手"换图的一部分，跟手一起转。

## 动画（手调关键姿势，不再用弹簧做主体动作）
- 每个动作写成"关键姿势 + 时间 + 贝塞尔缓动"，直接导出 Spine 的 curve，不再 30fps 逐帧烘焙。
- 节奏照原版：攻击 4 帧出招 → 长定格 → 慢收招带过冲；受击先反向缩、再被击飞、关节依次跟上、阻尼回摆。
- 挤压拉伸（胸、头、手臂伸长）、大角度翻腕、换手图用阶梯（瞬间切换）。
- 弹簧只保留给头发、领带、外套下摆、耳机线（次级运动），算好后同样压成稀疏关键帧。

## 工作量
- Codex：9A 3 张 → 9B 约 8 张 → 9C 约 9 张（每张 2 个版本），约 3 轮生图。
- Claude：拼装 + 骨骼 1~2 轮；全部动作（待机 / 放松 / 低血 / 攻击 ×2 / 施法 ×4 / 受击 / 死亡 / 预备抬起放下 ×4）2~3 轮反馈。
