# P3R 风格宣传视频模板（真透明底）

全部是 **1920×1080、60fps、ProRes 4444 带 Alpha 的 .mov**，直接拖到剪辑软件的画中画 / 上层轨道就是透明叠加。
每个模板还有：同名 `.wav`（单独的音效）、`_preview.mp4`（套在示意画面上的效果预览，不透明，只用来看）。
重新生成：`python3 tools/promo/p3r_templates.py <输出目录> [模板名…]`（要 numpy、Pillow、ffmpeg）。

## 转场（两种，换着用）

| 文件 | 时长 | 怎么用 |
|---|---|---|
| `T1_allout_ripple.mov`<br>总攻击水波 | 1.8s | 游戏里总攻击那段（去掉背景大字和立绘）。右上角外落下水滴，同心圆一圈圈扫满全屏 → 再一滴深蓝盖满 → 透明水波从同一圆心挖开，露出下一个镜头。**画面在 0.62–1.40s 之间被完全盖住，在 1.00s 处切镜头。** |
| `T2_stripe_wipe.mov`<br>斜条扫屏 | 1.2s | P3R 菜单式的斜向色条从左往右层层扫过盖满，再从左往右层层退出。**完全盖住的区间 0.48–0.62s，在 0.55s 处切镜头。** |

转场的放法：把转场放在上层轨道，让它的「切镜头时刻」对准下层两段素材的接缝（前一段在接缝处结束、后一段从接缝开始）。

## 看这里（提示 / 强调）

| 文件 | 时长 | 怎么用 |
|---|---|---|
| `T3_lockon.mov` | 4.0s | P3R 锁定框：四个角括号旋转收拢锁定、内圈脉冲、外圈虚线慢转、上方小三角跳动，右上角斜标签「CHECK!」。框在画面正中 —— 画中画里拖到要强调的位置、按需要缩放。0.35s 锁定入场，中间循环脉冲（可以裁短），最后 0.3s 散开。 |
| `T3_lockon_notext.mov` | 4.0s | 同上，不带文字（自己加字）。 |
| `T5_critical.mov` | 1.4s | 强调弹字「CRITICAL!」（P3R 原版字图）：砸入 + 白闪 + 放射速度线，停留后淡出。放在高光时刻（暴击、秒杀）。 |

## 标题 / 装饰

| 文件 | 时长 | 怎么用 |
|---|---|---|
| `T4_cutin_band.mov` | 2.4s | 技能名 / 小标题切入条：深色斜切底条从右侧砸入、白光扫过、停留后向左滑出。**中间留空**，在它上面加自己的字（字的入场对齐 0.1s 左右，出场在 2.05s 前）。 |
| `T4_cutin_band_text.mov` | 2.4s | 同上，带示例字「ONE MORE!」。 |
| `T6_butterfly.mov` | 4.0s | 游戏结局的蓝蝶：左下飞入 → 画面中间绕一圈 → 右上飞走，扇翅夹滑翔，身后光晕和下落的鳞粉（无音效）。适合片头 / 片尾 / 章节间。 |

## 说明
- 音效用的是 mod 里的 P3R 原声（总攻击水滴声、切入声、锁定声等），视频里自带一条音轨，不要可以静音，单独的 `.wav` 方便自己对位。
- 剪映：素材拖进画中画即可，透明区域自动透明（ProRes 4444 带 Alpha）。Premiere / 达芬奇 / Final Cut：放在上层轨道。
- 字体：示例字用的是 Barlow Condensed Black Italic（SIL OFL 开源字体，在 `mod/pck_stage/p3makoto/fonts/`），自己加字时可以用同一个字体，风格统一。
