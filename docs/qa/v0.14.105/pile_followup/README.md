## 修改及原因

### ITEM 配色与鼻线

`HeroKeyOut` 三段蓝色分别改为 `(0.010,0.05,0.25)`、`(0.025,0.15,0.37)`、`(0.050,0.22,0.43)`；彩色高光压至 `(0.055,0.26,0.48)`，头发与外套同步调暗。

参考仓库原版 `T_PC0051_F000_00_Col.png`、`SK_PC0051_F000.glb`、`DT_CampParamCommon.json` 与用户原版特写。新增两条抗锯齿细线，使用鼻骨和两眼骨的投影定位，跟随人物姿态、视口尺寸和镜头平移；随立绘一起移动、淡出，仅 ITEM 显示。每条线取 17 个贝塞尔采样点，宽度曲线两端为 0，中间为 1。没有新增面部块状阴影，也没有改原画贴图。

### SKILL 枪模

真实原因是动作的稀疏缩放轨继承了上一页状态：`CampItemStart` 将 `Jnt_L_AttachHand01_00` 缩至 0.001，`CampSkillStart/Loop` 省略此单位缩放通道，缓存骨架因而仍保持隐藏。切换动作时恢复前一段缩放通道为单位缩放，再应用新动作；同一段播放不反复重置，不改变原版有意隐藏的道具。

`BoneScaleChannels` 是实际生产代码；回归检查读取原始动画二进制，先重现旧行为，再检查 32 轮 ITEM → SKILL → 其他页切换。

### 退场

| 页面 | 时长 | 处理 |
| --- | --- | --- |
| 弃牌堆 ITEM | 0.54 秒 | 立绘整组向左撤，位移 InOutCubic，淡出 InOutSine；入场参数保留 |
| 消耗牌堆 SKILL | 0.54 秒 | 装饰和白底原地淡出，前 0.216 秒完成；水域圆孔从 0.243 秒开始收拢，避免露出向右移动白板的左侧竖边 |
| 其他牌堆 | 原有 0.42 秒 | 保留原有退场参数 |

两页按连续时间计算缓动，不叠加相邻帧、不以逐帧平移制造运动。
