# 螃蟹大房间适配

## 原因与处理
- 原版房间对SceneContainer应用Encounter.GetCameraScaling/GetCameraOffset。贴身特效继续继承这组变换，人物相对位移也按同一世界变换换算。
- 原版GetBottomOfHitbox直接把Hitbox.Size加到GlobalPosition，在缩放父节点下会偏离实际脚底。模组效果改用Hitbox完整矩阵变换后的底边中点，包括敌人地面效果。
- 世界测得的身高用于局部几何时先逆变换，避免能力圆盘、光柱、Persona和增益高度再次缩小。
- 独立屏幕合成层抵消镜头变换，专用于眼神召唤、背景拼贴和横幅；保持原前后容器和绘制顺序，不改游戏节点。
- 补齐防御、铸墙、反射、招架、中子护盾、剑圣、锻造、冲锋及其他身体相对能力落点的方向参数；文字保持可读。
- 修正数处动画把全局位置写入Position的情况。没有资源改动，沿用4718bcfc的618文件资源包。

## 必要验证
Release编译成功，0警告/0错误；0.111与0.107接口兼容检查各1200处引用全部通过。未启动游戏，未使用Computer Use。按用户要求不做反复离线审查，实际显示待用户反馈。

## 用户优先观察
1. 左右爪交替出牌：人物转向后，防御/反射/招架是否在面前，剑光和冲锋是否朝目标。
2. 汇流：头顶时钟是否对准人物中轴，能力大蓝圈是否在人物身后，脚底法阵是否贴地。
3. 普通房间与螃蟹房对比：护盾、蓝圈、Persona、锻造与天鹅绒门相对人物的大小和距离是否接近。
4. 召唤眼神切入：右边和下边是否还有矩形边界，横幅是否铺满屏幕，人物是否仍在背景拼贴前面。
5. 持续特效：门、辉星、蓄力与封印图案在转向后是否出现跳位或落地偏移。
