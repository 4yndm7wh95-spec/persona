# 手柄奖励导航与建筑师 CG 修复（2026-10-20）

## 战后奖励左右错位

只读检查原版 NCardRewardSelectionScreen.RefreshOptions 与 NGridCardHolder.OnFocus：原版先按奖励节点顺序建立循环左右导航；获得焦点会 MoveToFrontSafely 改变节点绘制顺序。旧 StageFx.ShuffleIntro 延迟到标题播放结束后，Deal 再读取 GetChildren，把改变后的绘制顺序当作卡牌位置顺序，导致导航关系与视觉位置错位。手柄自动聚焦会触发这个条件。

现在每轮 RefreshOptions 后立即保存有效奖励牌的顺序，将同一份数组传给首次延迟发牌和重抽发牌。Deal 只剔除已经离开该行或正在释放的节点，不根据后来变化的绘制顺序重排。沿用原版导航链接、循环边界、选择/查看与跳过逻辑；不改奖励数据、不改牌的焦点行为、不消耗随机数。原有轮次 token 继续阻止过期回调影响重抽后的牌。

## 建筑师特殊 CG

旧的两处交互只轮询 ui_accept；本机 v0.111.0 的 MegaInput 实际定义 select=ui_select、confirm=ui_confirm。现在 CinematicConfirm 接受这两个游戏动作，并保留 ui_accept 兼容键盘。旧版本不存在的动作不注册。

- 技能菜单“伟大封印”和后续“闭上眼睛”分别激活确认处理，保留每阶段 400ms 的误触保护。
- 每阶段确认先清空回调，同一按钮映射多个动作或 GUI/热键重复到达也只确认一次；鼠标确认同时解除该阶段的键盘/手柄确认。
- 独立焦点停留在 CG，方向键与 Tab 不会跳到下层游戏。调用原版 AddBlockingScreen 隔离热键，并截住确认键的按下和松开，避免传给下层。
- 手柄/方向键导航时，直接显示唯一选项的高亮与箭头，无需鼠标悬停。
- 正常交还游戏、超时兜底、节点退出都移除绑定和挡键，恢复仍然有效的旧焦点；重复清理安全，已经排队的旧确认回调不会再执行。
- 演出被移除时结束等待中的 Task 并恢复时间倍率，避免退出本局后遗留等待。
