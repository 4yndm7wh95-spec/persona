## 2. 用户的偏好（做之前对照一遍）
- **照原版**：P4R 原版的东西要逐帧 / 逐像素看清楚再做，形状、宽窄、颜色、节奏都要对上；用户会截图圈出不像的地方。拿不准的先把原版描一遍（量出来）再做，描完还要自己判断顺不顺。
- **形状要丝滑**：弯道要顺，不能有直愣愣的直线段、硬拐角；用样条 + 密集采样，宽度用单调插值。
- **原版只当参照，形状要自己设计**（2026-11-28）：描图会描错，描出来的点直接用会弯弯扭扭。做法：曲线用「曲率平滑、单调 / 单峰」的方式生成（曲率积分），
  宽度用单调平滑函数，每条边界都用程序检查曲率有没有反复弯折；用户给的手绘线也只当参照、要平滑处理。
- **运动的东西要有方向感**：头部不要半圆（显得胖、没方向），尾端不要平切（像被截断）；用收尖的头尾（刀尖 / 笔刷收笔），速度越快拉得越长。
- **镜头要跟着主体走**：例如彩带往电视里收时，镜头和彩带共用一条进度曲线同步推进，同时到达。
- **节奏**：不要急躁、不要太快；动作之间要有适当的小停顿；运镜要丝滑（缓入缓出），不要硬切；高潮点要有铺垫（暗一下 → 中间有光 → 突然闪亮）。
- **快速版 vs 完整版**（已定）：快速版 = 砍段落，不加速，尽快出效果（伤害牌尽快出伤害）；完整版保留表演，只去掉空等。
- 不要：规整的形状（P4R 的电视框不是规整矩形）、斜条直接扫过去的转场、硬切、人物剪影扑上去、突然冒出来、字直接贴在上面不融合、画面主体太小、细节太少。
- 要：P4R 的 UI 平面设计细节（圆角标签、黑黄配色、星星、小花、小电视图标、网点、彩色细线、错色字）、动态（背景和立绘都要动）、透视感（由近到远）。
- 画得费劲的东西可以交给 Codex 生图当素材（用户说生多少张都行，Claude 来指挥）；但要能沿轨迹动起来、要逐色带变色这种，代码画更合适。
- 字要「融进」画面：巨字压出彩带的部分在画面上半透明，压在每条色带上换撞色（P4R CHANCE 的做法）。

### 6.3 彩带动画（正在做）
- 用户要求：
  1. 入场从右边进来长成最终形态，要丝滑。**头部不要半圆**（圆头前后都胖，没有方向感）；**也不要平的斜切**（尾端太平像被截断）。
  2. 彩带出现以后要**从右边往电视里收**，像被电视吸进去；**镜头要跟着彩带一起往电视里推**，不能彩带收完了镜头还离电视很远；速率丝滑，该停可以停一下，整体不拖沓。
- 现在的做法（原型 `tools/ribbon/v7/proto_seq.html`，预览 `docs/p4/preview/ribbon_v7_proto*.mp4`，已发给用户，**等反馈**）：
  - 头尾都**收尖**：各分界线在头尾附近按比例收向内沿——头是刀尖（凸），尾是笔刷收笔（细长），收尖长度跟速度走，停下时为 0；
  - 入场按「视觉弧长」走（卷曲处外侧色带不会被甩过去），速度 smootherstep，起步在画面外（不是在画面里从零加速）；落位时倒钩箭头弹开（eBack）；
  - 停一拍时 T2 短划沿彩带缓慢流动；
  - 退场：箭头先滑进电视，尾巴收尖往电视收（同样按视觉弧长、smootherstep），细线短划和星星跟着往电视里流；
    **镜头和尾巴共用同一条进度曲线**，直线推向电视（电视在画面里的位置平滑移到中心，变焦按指数走），尾巴进电视的同时屏幕推满画面（超出 7%，边框出画）。
