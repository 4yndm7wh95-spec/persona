## 2. 用户的偏好（做之前对照一遍）
- **照原版**：P4R 原版的东西要逐帧 / 逐像素看清楚再做，形状、宽窄、颜色、节奏都要对上；用户会截图圈出不像的地方。拿不准的先把原版描一遍（量出来）再做，描完还要自己判断顺不顺。
- **形状要丝滑**：弯道要顺，不能有直愣愣的直线段、硬拐角；用样条 + 密集采样，宽度用单调插值。
- **原版只当参照，形状要自己设计**（2026-11-28）：描图会描错，描出来的点直接用会弯弯扭扭。做法：曲线用「曲率平滑、单调 / 单峰」的方式生成（曲率积分），
  宽度用单调平滑函数，每条边界都用程序检查曲率有没有反复弯折；用户给的手绘线也只当参照、要平滑处理。
- **运动的东西要有方向感**：头部不要半圆（显得胖、没方向），尾端不要平切（像被截断）；用收尖的头尾（刀尖 / 笔刷收笔），速度越快拉得越长。
- **镜头要跟着主体走**：例如彩带往电视里收时，镜头和彩带共用一条进度曲线同步推进，同时到达。
- **节奏**：不要急躁、不要太快；动作之间要有适当的小停顿；运镜要丝滑（缓入缓出），不要硬切；高潮点要有铺垫（暗一下 → 中间有光 → 突然闪亮）。
- **快速版 vs 完整版**（已定）：快速版 = 砍段落，不加速，尽快出效果（伤害牌尽快出伤害）；完整版保留表演，只去掉空等。
- 不要：规整的形状（P4R 的电视框不是规整矩形）、斜条直接扫过去的转场、硬切、人物剪影扑上去、突然冒出来、字直接贴在上面不融合、画面主体太小、细节太少。
- 要：P4R 的 UI 平面设计细节（圆角标签、黑黄配色、星星、小花、小电视图标、网点、彩色细线、错色字）、动态（背景和立绘都要动）、透视感（由近到远）。
- 画得费劲的东西可以交给 Codex 生图当素材（用户说生多少张都行，Claude 来指挥）；但要能沿轨迹动起来、要逐色带变色这种，代码画更合适。
- 字要「融进」画面：巨字压出彩带的部分在画面上半透明，压在每条色带上换撞色（P4R CHANCE 的做法）。

### 6.3 彩带动画和后面的推镜（第二轮已做，等反馈）
- 用户第一轮意见（看了 `allout_v7_ribbon.mp4`）：
  1. 头尾**不要「扎成一束」**（所有色带收向一个尖很别扭），尾巴也不要弯弯的收尖；色带过程中是一条条宽的，应该**松散**。（更早还说过：不要半圆头、不要平的斜切。）
  2. **箭头不能在原地渐显**（偷懒、没融进彩带），箭头要是彩带的头、跟着彩带一起来。
  3. 节奏：从右边**起步稍慢 → 加速**，快到电视时**放慢、慢慢往电视里钻**（假停顿，不能停死、不能太久），然后**马上从尾巴开始收进电视**，镜头跟着拉近；
     拉近后看到演播室三台电视，停一下，再**有节奏地突然推近中间那台**。
  4. 中间电视：推进去时**是黑的**，推到「全屏」那一下**还是黑的**，但要**能看见电视的黄框、红框**；然后**屏幕中间先亮起一点 → 整个画面突然闪一下**，像电视突然打开，画面亮出来。
  5. 速度不要太慢、不拖沓：玩家能看清彩带怎么过去就行，要丝滑（上一版偏慢、很机械）。
- 现在的做法（`p4r_workbench.html` 的 `RIB7` / `ribbonLayer` / `studioCam` / `middleTV` / 时间轴；预览 `docs/p4/preview/allout_v7b*.mp4` 已发）：
  - 色带头尾：每条色带**各自一个直边斜尖**（内沿那边领先，尖长 = 2.2 × 这条的宽，上限 200px），下一条往后错开半个尖 → 一排松散的刀片，不收拢；头尾斜向相同（像平行四边形）。
    尖的位置按每条色带自己的中线弧长算（`RIB7.stations`），卷曲处也不会变形。
  - 箭头 = 彩带的头：在彩带自己的坐标系里画（沿内沿往回的距离 + 往外的偏移），跟着头走、贴着弯道；近大远小（`arrowScale`：底边 2.8 倍 → 末端 1 倍）。色带的前端在箭头的缺口处。

- 做法（`aoaScene`）：

    `FCUT` = 黄 [0 → 0.10 秒，出现时 0.70]、红 [0.02 → 0.14，0.65]、黄绿 [0.05 → 0.22，0.55，透明度 0.05 → 1]。黄框落定时整片外面填黄、画面震一下（`TIMP`）。

    圆角矩形（直边 + 圆弧角）再整体做一次平滑的桶形外鼓，**没有折角和小凸起**（原来的 `crtShape` 在角和边的接口有折角）。电视自己那圈框也换成 `smoothCRT`，
    颜色和顺序改成原版的（屏幕边上黄绿、外面红、最外一圈黄带）。
  - 落地后 `framed()`：黑屏 + 反光，停到 `FL0 = P1B + 0.62` → 中间亮点拉成亮线（`FL0..FL1`）→ 闪白 → 结算卡全屏画在框里（框一直留着）→ `OFF0` 关机（整幅画面裁在视口里压扁）。总长 5.73 秒。
