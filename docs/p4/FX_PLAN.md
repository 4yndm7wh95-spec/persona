# P4Yu 特效方案（草案，2026-11-27）

## 用户这次的要求（2026-11-27）
- 先做特效，开工前先定哪些牌更重要。金卡大部分要做得比较隆重。
- **焚烧**做成伊邪那岐大神的**几万真言**。
- P4 的特色：电视机（通过电视进入影世界）、主题色黄色、**手心向上把塔罗牌捏碎**。
- 战士的烧牌（消耗）和"抓牌、捏碎"结合起来，做成和**手牌里的牌**联动的动效。重点是几张大烧牌：恶魔之焰、添柴，以及无惧疼痛这类消耗相关的牌。
- 延续之前华丽、酷炫的风格。P4 的特效像 UI 一样，有很多黄色几何形状，要表现这种美感。

## 用户决定（2026-11-27，工作台第一轮）
- 技能名少用，只给部分金卡；用英文。做法：从人物身后、左下往右上划过的大规模背景特效，技能名是主角，周围配大量 P4 的黄色横条等 UI 感特效；不能是字幕弹进来又收回去。如果用汉字，也要当特效处理，而且要做得大。
- 1 MORE / CRITICAL / WEAK 是 P 系列通用元素，同样当特效做，少出现，只给部分牌。
- **不做 3D 半身特写**（我们是 2D，没有局内 3D 模型）。改成：背景屏幕中间由里向外伸出一只手，手心出现旋转的塔罗牌，握拳捏碎。手要是「特效」，不能有明显轮廓和贴图感：参考**最新版**毒性爆发的巨手（`p5mod/src/Vfx/CrushHand.cs`：着色器光线步进的立体手，边缘融掉、没有描边），但不要它的烟雾质感。
- 黄卡出场照原版：黄菱形出现在中间偏左，往左放大到 50–60% 屏幕，菱形里是眼睛特写（闭眼 → 慢慢睁开 → 停一下），菱形在三维里像翻页一样翻过去，落到手上变成那张纯黄卡。我们翻到画面中间那只手上，大小自己调。
- 捏碎：碎片纯色、从卡的位置往四周炸；捏完直接切回战场。不用完全照抄原版。
- 单张消耗走轻量版（草图已认可）。几万真言白金为主、黄色收尾。
- 人物描边只在身后一侧，粗细适中，静止。刀光是发光的，有明暗细节，形状讲究。伤害数字带声波括号、会弹。CRITICAL 轻微抖动。
- 圆角电视框不是「轮到谁框谁」：是战斗开始动画的一帧（几层框缩放到位，最后变成整个画面的黄色边框）。颜色按黄色。
- 美感：不是火、水、烟这类通俗特效，是用 UI 和平面设计做的特效；规整、有序、不乱，细节细腻，画面均匀（参考 P3 mod 的纯色圆环扩散）。还有**撞色**。文字是特效，周围要有衬托它的细节。
- UI 式特效草图认可，但细节要再丰富（参考原版放了哪些细节），也不要过度，P4R 本来就偏动画、卡通的电视主题。
- 总攻击以后做，只做最后结算那一下。参考 P4R 的运镜：镜头由慢到快推到主角脚下、仰拍全身、停一下，身后两块大屏幕亮起来；不一定用 3D，学它的创意。
- 用户上传的两段核心参考：`research/p4r/user_clips/`（先手攻击转场、召唤捏碎 + 拍手换人）。

  - 恶魔之焰快速版：彗星光团只在手牌区快速扫一下（约 0.25 秒），不飞电视、不伸手、不收叠。扫到哪张，哪张原地翻黄并立刻捏碎，碎片直接变刀光飞向敌人，一张牌一刀。约 0.35 秒出第一刀，整段约 0.8 秒。

  - 通用：快速版保留每张牌的招牌元素，去掉铺垫；阶段互相重叠；只在捏碎时有约 40 毫秒的小顿帧。

## 节奏调整（2026-11-27，用户第七轮）
- 用户：快速版要尽量保持原版「牌一打出去就马上落实效果」的感觉，伤害牌尽快出伤害，让玩家马上感到牌已经打出、已经生效；但不能为此阉割太多或加倍速。完整版也不要拖太久。去掉或缩短没必要的停顿；有必要的停顿（让特效更有感觉的）保留。可以比原版慢一点，但不能影响出牌。
- **以后定节奏的原则**：快速版 = 剪段落、不加速、一打出尽快见效果；完整版 = 表演不删，只去掉空等和两头拖得太长的缓动。

## P4R 特效语法（从用户上传的两段视频逐帧拆的）
1. **同一个形状贯穿多个镜头**：黄菱形先当窗口（里面是眼睛特写）→ 翻页 → 缩小落到手上变成卡。转场靠形状变形，不靠淡入淡出。
2. **一层层平面色带**：柠檬黄、黄绿、橙、深灰条；橙带边上一排黄色网点，黄带下缘几条细平行线；色带一直在流动（弧形绕到人物身后，或整屏斜条纹）。边缘干净，内部有细的速度线明暗。
3. **撞色**：字或色块越过颜色分界线时，跨过去的部分换成对面的配色（BATON 大字、黄带上的橙字）。
4. **电视语言**：电视套电视的灰色隧道、发光的黄色小屏幕射出多色光带；进战斗时几层倾斜的圆角电视框（黄、红、绿）缩放到位，最后留成整个画面的黄色边框，内侧一条细绿线、一条细红线。
5. **去色 + 黑剪影**：画面去色成灰，人物变纯黑剪影，只留黄色光带、黄绿圆盘。用最少的颜色做最强的对比。
6. **光束和圆环**：多色细光束从一点射出；彩虹圆环（粉、黄、绿）加内侧细白环扩散；捏碎时有白色细环、中心白光、很长的细光线交叉。
7. **星星的词汇**：白色小四角星、金色大四角星、彩色五角星、小花、圆点，分布均匀，按顺序亮起。
8. **人物处理**：身后一侧黄色描边；快速动作用动画式拖影；人格面具是蓝焰和蓝色晶片。

## P4R 的视觉特征（从 research/p4r 的截图看到的）
1. **把战斗做成电视节目**：
   - 战斗场地是舞台，有聚光灯和红地毯；系统名都是电视术语：Prime Time（黄金档）、Series Finale（大结局，就是总攻击）、Star of the show（当集明星）。
   - 指令盘是老电视的旋钮（PERSONA / ATTACK / GUARD / ITEM）。
   - 回合切换和锁定目标用圆角的显像管屏幕框；结算画面是一整墙黄色屏幕；战斗从电视里开场，结束时有雪花和小电视图标。
   - 官方访谈：初代 P4 像深夜电视频道，Golden 像黄金档，Revival 把电视主题推得更远。
2. **柠檬黄平涂 + 黑，平面几何**：
   - 角色特写外面包一圈很粗的黄色描边；圆形和圆环遮罩、菱形、倾斜的面板、多边形碎片、十字星芒；技能名放在黑底黄边的胶囊条里。
   - 这就是"像 UI 一样的特效"。
3. **捏碎塔罗牌**（`research/p4r/card_crush/`，整段约 1 秒）：
   - 黄色面板滑入，悠的特写，掌心朝镜头张开；
   - 掌心上方出现一张**纯黄色的平面大卡**，带星芒和细光线；
   - 手指合拢，握拳的一瞬间：**十字闪光 + 黄色多边形碎片向外炸开**；
   - 黄色圆环遮罩收拢；
   - 伊邪那岐在蓝焰里出现。
4. **人格面具是蓝色**：蓝焰、蓝色晶片和光点；伊邪那岐的招牌是蓝色雷光十字斩。雷属性魔法是白黄色的粗闪电配蓝光。
5. **点缀**：
   - 漫画星星（1 MORE、暴击、晕眩）、总攻击的卡通尘土团；
   - 黄、橙、绿三色彩带转场；
   - 文字的红蓝错位故障效果、半调网点斜条；
   - 眼镜反光（P4G 召唤特写里就有一张"眼镜闪光"贴图）。
6. **几万真言**：伊邪那岐大神（白色大衣、金色圆环、长枪，参考 `research/p4g/persona/camp__persona__pst_0bd.png`）的专属技能，对全体敌人造成多段万能属性伤害。原作剧情里，悠**摘下眼镜**后用这一击打倒伊邪那美。

## P4 特效规则（草案，等用户确认）
- **结构沿用 P5 的规则**（`docs/p5/FX_RULES.md`、`FX_STYLE_GUIDE.md`）：
  - 每张牌先有一个自己的"主意"；
  - 一到两个最满的瞬间：顿帧 80–90ms、震屏、闪光、碎片压在同一拍上，前后干净；
  - 碎片和光都有方向，从谁射向谁；
  - 一次做一个特效，先出带声音的预览。
- **材质换成 P4 的**：
  - 柠檬黄平涂几何（圆、环、菱形、圆角屏幕框、多边形碎片、十字星芒）+ 黑；人格面具用蓝焰和蓝色晶片；雷是白黄色。
  - **和 P5 时期不同的地方**：P5 时用户不要平涂几何和界面感，这次 P4 恰恰要这个。但几何要做得干净、会动、有光（边缘发光、碎片转动时闪光），不要静态贴片，不要粗糙。
- **电视元素**（屏幕框、雪花、换台、扫描线、聚光灯）用在转场、锁定、格挡和几张主题牌上，不当每张牌的主体。

## 核心系统：消耗 = 捏碎
悠的每一次"消耗"都不再是原版的烧掉，而是**这张牌变成黄色塔罗牌，被捏碎**。
- **轻量版**（单张消耗、自带消耗的牌，每回合可能出现很多次）：牌在原地翻成纯黄色 → 星芒一闪 → 碎成黄色多边形碎片落下。约 0.4 秒，声音很轻。
- **完整版**（大烧牌，一次消耗很多张）：
  - 悠特写伸手；
  - **手牌里真的那几张牌**飞到他掌心上方排成扇形，变黄；
  - 一握全碎（主拍）；
  - 碎片再变成这张牌的效果：伤害、新牌、格挡。
- **消耗触发类能力**（无惧疼痛、黑暗之拥）：之后每次捏碎，都会有一部分碎片飞去对应的地方：飞回悠身上变成格挡，或飞进抽牌堆再抽出一张牌。

### B（有自己的小主意）
- 燃烧契约：捏碎 1 张，碎片飞进抽牌堆，抽 2 张。
- 彼岸咆哮：回合结束时从消耗堆里**拼回来**（倒着放的捏碎），再打全体。
- 灰烬打击：消耗堆的碎片吸到刀上，碎片越多刀光越大。
- 闪电霹雳：**Mazio**，全体落下白黄色的雷（P4 的招牌雷）。
- 旋风斩：伊邪那岐转动薙刀，转 X 圈。
- 重锤：伊邪那岐过顶重劈 + 雷光十字。
- 燃烧：攻击力上升（红黄光柱往上走）。
- 耗血的牌：御血术、突破、放血、血墙、怨恨。P4 的物理技能消耗 HP，悠身上闪一下红色碎片。
- 其他能力牌：狱火、撕裂、残酷、凶恶、杂耍、惊逃、岩石铠甲。统一用召唤姿势，各自加一个小的常驻标志。

### C（轻量）
其余白卡、基础牌和普通的蓝卡：
- 攻击：悠的刀，配不同的刀光和命中；
- 防御：横刀格挡 + 一闪的黄色屏幕框；
- 自带消耗的牌：走轻量捏碎。

## 制作顺序（建议）
1. **捏碎系统**：先做单张轻量版，再用恶魔之焰做完整版，验证"手牌联动"。
2. **几万真言**（焚烧）。
3. 添柴、午夜，以及其余 S / A 牌，一次一张。
4. B，最后 C。
