## 形状怎么来的（单位：1280×720 画面的像素，s = 内沿 B0 的弧长）
1. **内沿 B0**（橙带内侧，绕卷曲一圈到箭头尖）：`fit_inner.py`。曲率是「单峰」函数——底边从很缓平滑变弯（二次渐增）→ 卷曲处最紧（约 1.2°/px，半径约 47px）→ 过了顶部放缓到箭头；位置由曲率积分得到，所以不会来回扭。拟合用户红线：rms 1.0px，最大 2.6px（底边星星那个手绘小尖角已排除）。
2. **顶部外沿**：`fit_outer.py`，回旋线（曲率线性变化），rms 0.43px。
3. **总宽 D(s)**：`measure_width.py` 沿 B0 法线和外沿求交（画面内那段），`fit_width.py` 用「对数斜率单峰」积分拟合，保证 D 单调变小、平滑；画面外的部分按原版色带估（底边约 680–820px，卷曲左边约 250px）。
4. **色带分界**：B0 + 份额 × D（沿 B0 外法线）。份额（累计，内→外：橙 | 黄绿 | 内黄 | 灰（含深色描边）| 外黄 | 外橙 | 最外黄）：
   近处 `0.11 0.23 0.50 0.74 0.83 0.91 1.0` → 远处 `0.27 0.42 0.60 0.67 0.78 0.90 1.0`（s 1150→1290 平滑过渡）→ 箭杆 `0 0 0.62 0.62 0.8 0.8 1.0`（s 1270→1360）。所有过渡用 C2 的 smootherstep。
5. **倒钩箭头**（半个三角形）：缺口在外沿 s=1365 处，倒钩尖 (343,338)，箭尖 = B0 末端 (423,378)，下沿是 B0。
6. 细黄线：T1 悬在底边上方（离橙带的空隙往卷曲方向收小），T2 在橙带里（橙带宽的 27% 处，两段），都是圆头，在橙色四角星处断开。
7. 颜色（从原版取）：黄 `#f8f40e`、橙 `#feb30c`、黄绿 `#aef01a`、灰带其实是深炭灰 `#333037`、描边 `#151417`。

`design.py` 汇总成 `design_v2.npz`，`preview.py design_v2.npz v2` 出平铺图、叠原图、箭头和卷曲放大图，并打印每条分界线的曲率检查（反向弯折次数）。

## 运行时（JS）
`ribbon7.js`：`RIB7.build()` 按上面的参数在 JS 里积分出同样的 B0 / D / 分界（任意分辨率，绘制时乘 H/720）。
- `drawTaper(ctx, R, {sT, sH, LT, LH, end})`：两头**收尖**（各分界线在头尾附近按比例收向内沿：头是刀尖、尾是笔刷收笔），用于入场、退场；`LH/LT` 是收尖长度，跟速度走，停下时为 0。
- `line()`：细线（圆头）；`R.AH` 倒钩箭头多边形；`sAtV / vAtS`：按「视觉弧长」（离内沿 0.3·D 那条线的弧长）换算，入场按它走，卷曲处外侧色带不会被甩过去。
- （`drawCut` 是斜切头尾的版本，用户说尾端太平像截断，已不用；`draw` 是圆头版本，用户说没方向感，已不用。）

## 原型
`proto_seq.html` + `frames.js`：入场 → 箭头弹开 → 停一拍 → 退场（尾巴收进电视，镜头同步直线推进电视）。电视和演播室是临时占位，正式版用工作台里原来画好的（用户：不要重画）。
`node frames.js $PWD/proto_seq.html <输出目录> 0 2.5 60` 出逐帧，再 `ffmpeg -framerate 60 -i <目录>/f%04d.png ...` 合成视频（预览在 `docs/p4/preview/`）。
