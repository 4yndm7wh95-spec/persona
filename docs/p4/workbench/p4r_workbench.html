01我记下的决定

有记错或者漏掉的，写在最下面的框里。

  • 技能名少用，只给部分金卡。用英文。不是字幕弹进来又收回去，而是从人物身后、左下往右上划过的大规模背景特效：技能名是主角，周围配大量 P4 的黄色横条这类 UI 感特效。
  • 1 MORE / CRITICAL / WEAK 是 P 系列通用元素，同样当特效做，少出现，只给部分牌。
  • 不做 3D 半身特写。改成背景的电视屏幕中间由里向外伸出一只手，手心出现旋转的塔罗牌，握拳捏碎。手是「特效」，不能有明显轮廓和贴图感。参考最新版毒性爆发的大手：着色器实时渲染的立体手，近大远小，边缘自然融掉、没有描边；不用它的烟雾质感。
  • 黄卡的出场照原版思路：黄菱形出现、往左放大到半屏，里面是眼睛特写（闭眼到睁眼），停一下，菱形像翻页一样翻过去，落到手上变成那张卡。
  • 捏碎：碎片纯色，从卡的位置往四周炸；捏完直接切回战场，不用整屏黄。
  • 单张消耗走轻量版（草图你说像）。几万真言白金为主、黄色收尾。
  • 描边只在人物身后一侧，粗细适中，静止不变。刀光是发光的，有明暗，形状讲究。伤害数字带声波括号、会弹。CRITICAL 轻微抖动。圆角电视框不是「轮到谁框谁」，是战斗开始动画里的一帧：几层框缩放到位，最后留成整个画面的黄色边框；颜色按黄色来。
  • 美感：不是火、水、烟这类通俗特效，是用 UI 和平面设计做的特效：规整、有序、不乱、细节细腻、画面均匀。参考 P3 mod 那种纯色圆环扩散的做法。还有撞色。
  • 总攻击以后再做，只做最后结算那一下。参考 P4R 的运镜：镜头由慢到快推到主角脚下、仰拍全身、停一下，身后两块大屏幕亮起来。不一定用 3D，学它的创意。
