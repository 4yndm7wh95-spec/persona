# 云电脑 Claude 任务：收集 P4R（Persona 4 Revival）的公开影像参考

（这份是发给有云电脑的 Claude 的完整任务单。用户直接整段复制过去就行。）

---

你的任务是给一个《杀戮尖塔 2》换皮 mod 收集参考资料：把原版角色"铁甲战士"换成《女神异闻录 4》的主角鸣上悠，Persona 是伊邪那岐。写 mod 的那个 Claude 看不了视频，只能看你截的图和剪的短片段，再根据这些设计人物姿势、特效和界面。所以**截得越多、越清楚越好**。

## 背景
- P4R = **Persona 4 Revival**（日文「ペルソナ4 リバイバル」），ATLUS 出的 P4G 重制版，计划 2027-02-18 发售（PS5 / Xbox Series / PC）。游戏还没发售，只能用公开的视频和图片。
- 已经知道的官方视频（可能不全，请自己再找）：
  - 2026-06 Xbox Games Showcase 的首个实机预告（公布了发售日）；
  - 2026-07 角色介绍预告；
  - 2026-08 新系统预告（介绍 5 个新功能）；
  - gamescom 2026 剧情预告；
  - 据说 2026-10 还有一支以战斗为主的 Shadow 预告，没核实。
- 去哪找：
  - ATLUS 官方 YouTube（日本的 ATLUS 公式频道、ATLUS West）和官网；
  - Xbox Wire / PlayStation Blog 的新闻稿和官方截图；
  - 媒体的试玩和长篇实机录像（IGN、GameSpot、Famitsu、4Gamer、電撃オンライン 等）；
  - 展会试玩录像（例如 TGS 2026）；
  - B 站上的官方搬运和中文字幕版（找最高画质的版本）。
- 只用官方和公开渠道。不要找泄露版本、拆包、盗版、破解。

## 要找什么（按优先级）
1. **鸣上悠在战斗里的样子**：
   - 待机站姿；
   - 普通攻击：刀怎么挥，每一招从起手到收招；
   - 防御、受击、倒地、胜利姿势；
   - **召唤 Persona 的完整过程**：塔罗牌出现 → 怎么把它击碎 → 伊邪那岐出现；
   - 武器造型；
   - 服装：冬季 / 夏季校服、电视世界里戴的眼镜；
   - 正面、侧面、3/4 侧面都要。
2. **伊邪那岐**（有伊邪那岐大神的话也要）：全身造型、出场方式、攻击动作（雷系 Zio 系列、斩击）。
3. **特效**：
   - 雷系魔法（单体 / 全体 / 大招）；
   - 斩击和物理技能；
   - 暴击、打中弱点、1 More、Down；
   - 总攻击：开始 → 尘土团 → 结束定格画面；
   - 新系统的演出；
   - 增益 / 减益（攻击力上升之类）、回复、Persona 切换；
   - 受伤和濒死时的画面效果；
   - Shuffle Time（如果有）。
4. **界面（UI）**：
   - 战斗：HP / SP 条和队员头像、指令菜单、技能列表、目标选择、伤害数字和弹出文字、行动顺序、战斗结算和升级画面；
   - 其他：标题画面、主菜单 / 暂停菜单、存档读档、天气和日历过场、对话框、天鹅绒房间（商店）、加载画面、转场（进电视的效果）；
   - 字体和配色（P4 标志性的黄色）。
5. **场景**（以后做背景用）：电视世界 / 午夜电视台、Junes 天台美食广场、稻羽街景、主角房间、天鹅绒房间（轿车内）。
6. **宣传图**：官网和新闻稿里的高清主视觉、角色立绘、官方截图。

## 怎么交付
- **截图**：
  - 用原视频的最高清晰度，至少 1080p；
  - 存 PNG 或质量 90 以上的 JPG，不缩小；
  - 尽量挑没有字幕、没有台标遮挡的帧。
- **短片段**（动作和特效最需要这个）：
  - 每段不超过 15 秒，1080p，mp4（H.264），每段不超过 30MB；
  - 保留原声，用来对照音效的时机。
  - 重点内容每项至少 3 段：悠的普通攻击、召唤、伊邪那岐出手、雷系魔法、总攻击、战斗 UI 操作、转场。
- **数量**：每个类别有的话至少 20 张截图，越多越好。
- **不要提交完整的长视频**。总量控制在 1GB 以内。
- **目录**：全部放进 `research/p4r/`，按类别分子目录：

  | 子目录 | 内容 |
  |---|---|
  | `yu_battle/` | 悠的战斗动作 |
  | `yu_summon/` | 召唤过程 |
  | `izanagi/` | 伊邪那岐 |
  | `fx_elec/` | 雷系魔法 |
  | `fx_phys/` | 斩击和物理技能 |
  | `fx_crit_1more/` | 暴击、1 More、Down |
  | `allout/` | 总攻击 |
  | `fx_buff_heal/` | 增益、减益、回复 |
  | `ui_battle/` | 战斗界面 |
  | `ui_menu/` | 菜单和其他界面 |
  | `ui_transition/` | 转场和加载画面 |
  | `velvet/` | 天鹅绒房间 |
  | `scenes/` | 场景 |
  | `keyart/` | 宣传图 |
  | `other/` | 其他 |

- **命名**：`<类别>/<来源编号>_<分分秒秒>_<简短英文描述>.jpg`（片段用 `.mp4`），例如 `yu_summon/S03_0112_card_shatter.mp4`。
- **`research/p4r/sources.md`**：每个来源一条，写编号（S01、S02 …）、标题、链接、频道、发布日期、时长、内容概括，以及重点时间点列表。
- **`research/p4r/index.csv`**：每个文件一行，列出文件名、类别、来源编号、时间点、一句话描述（只写画面上看得到的东西）。
