你在用户的 Windows 电脑上工作。任务：给 P5Joker 的总攻击重画**玻璃击碎的裂纹**贴图（生图）。上一轮 art/p5/fx/gen_codex/allout_cracks/ 那几张是写实风（细、毛、带倒刺、像闪电），和 P5 的平涂图形风格不搭，这一轮**换成 P5 自己的裂纹画法**。不改任何代码，不启动游戏。

**先读 docs/codex/README.md**，按里面的长期规则来：生图一律真透明底（RGBA，裂纹以外 alpha = 0），每张只生成一次，生成完清理透明残点、保存、直接提交推送，不自我审查、不重画、不写报告。

【风格参考（必须看）】
docs/codex/ref/allout_star_cracks_ref.png：P5R 原版总攻击收尾卡上那颗被打碎的五角星。要的就是这种裂纹：
- **黑色、硬边、平涂**，没有发光、没有模糊、没有写实的毛边和细小倒刺；
- 裂纹是**有棱角的直线段折线**（像刀刻出来的），靠近撞击点是粗的楔形，往外越来越细、最后收成尖；
- 撞击点周围一圈**尖锐的黑色楔形碎片**向外炸开（参考图里红色弹孔周围那圈黑刺），中间可以留一个不规则的洞；
- 少量**细小的黑色三角碎屑**散在主裂纹旁边；
- 每条主裂纹的一侧带一线很细的**白色高光边**（1～3px，表现玻璃断面反光），只在一侧、断断续续，不是整条白描边。

【画面要求】
- 透明底，只有裂纹（黑色 + 那一线白高光）。不要背景、不要玻璃本体、不要颜色（不要红色）、不要阴影。
- 撞击点在画布**正中心**。主裂纹 **7～9 条**，方向不均匀（不要正好放射对称），长短不一：其中 3～4 条一直冲到画布边缘，其余停在半路；主裂纹上有 1～2 处分叉（分叉也是直线段）。**不要一圈圈的环形裂纹，不要蛛网**，最多在撞击点附近有两三段短的横向裂纹把相邻主裂纹连起来。
- 线条粗细：撞击点附近 14～20px 的楔形，中段 5～8px，末端收成尖。
- 画布 2048×2048。

【要画的三张】放 art/p5/fx/gen_codex/allout_cracks_v2/：
1. crack_p5_a.png：上面描述的完整裂纹（主用）。
2. crack_p5_b.png：同样要求，换一种裂法（主裂纹更少、更长、整体偏斜）。
3. crack_p5_core.png：只有撞击点那一团：中间一个不规则的黑洞（直径约画布宽 18%），周围一圈尖锐的黑色楔形碎片往外炸开（到约 45% 半径为止），带几点白色高光碎边。画布 1024×1024。

Claude 会把完整裂纹按离撞击点的距离切成三段，做成"裂一段、顿一下、再裂一段"的节奏，所以**主裂纹要从撞击点连续地往外延伸**（不要断开的孤立线段）。
