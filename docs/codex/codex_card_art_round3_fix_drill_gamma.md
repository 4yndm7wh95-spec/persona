# 第三轮修正：天际钻头、伽马爆破

用户反馈：天际钻头特别奇怪；伽马爆破还好，但两只手端着手枪很奇怪。

## 我看到的问题
- **天际钻头**：Regent 的身体被换成了两条没有身体的西装袖子，一只手握着钻头、一只手平放在地上，看起来像地上躺着两截手臂；塔塔罗斯塔做成钻头后像一个扭曲的城市模型，认不出是塔，也认不出是钻头。
- **伽马爆破**：两只手像警察一样平端着枪，这不是 P3 的召唤姿势。P3 的召唤器是顶在自己太阳穴上开的。

## 改法
- 天际钻头：**钻头恢复原版那支金色钻头**，只换握钻头的角色，并且给角色一个完整的身体。A = Aigis（推荐），B = 杰克冰人。
- 伽马爆破：改成召唤器顶在太阳穴的经典姿势，只用一只手。A 是从结城理左后方拍，看得到后脑的蓝发和耳机，**看不到脸**；B 是完全不出现头，只有一只手把召唤器举向画面上沿。

**需要你定：** 之前的规则是"结城理的脸不出现"。A 只露后脑、看不到脸，算不算可以？可以就选 A，不行就选 B。两版都让 Codex 出，你看图再选。

每张卡两个候选，输出到 `art/cards/v4/local_edits/round3/fix_drill_gamma/<卡名>_<A或B>.png`，附 `comparison.png`（原版 | 第三轮 | A | B），状态 `awaiting_user_review`，不自动重试。
