# 卡图第五轮：29 张第三版

来源：用户在卡图审批台上标了「重做」的 29 张。用户备注：之前南瓜头用得太多，有些没什么创意。

**这一轮的规矩**
- 不再用南瓜灯杰克、杰克冰人、小精灵（提示词里写死了）。
- 改用之前没出场或只出场一次的 P3R 角色：荒垣、西奥多、望月绫时、千鸟、鷹也、仁、江户川老师、武器屋老铁匠、剑道部，人格面具卡斯托耳、刻耳柏洛斯、赫尔墨斯；已出场的角色每人最多出现两次。
- 结城理仍然只出现手。
- 暗影只在少数几张里当配角，并要求面具别再是同一款白色窄眼。
