【2. 生图：每个姿势一张完整的全身图】
统一要求（每张都一样）：
- **以母版 joker_master_a.png 为输入做图像编辑，再把对应的 *_ref.png 作为姿势参考图**，不要从零生成。脸、发型、表情风格、服装细节（长大衣、高立领、灰马甲和纽扣、白色口袋巾、红手套、黑裤子、棕靴）、配色、画风、身高比例必须和母版一致，**只改姿势**。参考图只看姿势和手脚位置，不要学它的 3D 质感、颜色和脸。
- 画布 1024×1536 竖版，**真透明底 PNG**（轮廓外 alpha = 0；工具出不了透明底才用纯 #00FF00 绿幕，报告说明）。无阴影、地面、光晕、文字、边框、动态线、特效。
- 人物 3/4 侧向画面右方（倒地除外）。大小和站位与母版一致：直立时头顶到鞋底约占画布高度的 90%，鞋底离下缘约 60px；腾空、倒地的姿势按实际高度，但全身都要在画面内、四周至少留 40px。
- 关节、透视、衣服褶皱符合真实人体，手指数量和形状正常；**不要像拼起来的木偶**。
- 不戴面具。

武器：
- slash：**右手**正握一把短小刀（Joker 的匕首：黑色刀柄、银色单刃、刀身约 20cm），刀刃朝前；左手自然在身后或身侧。
- gun：**右手**握一把黑色手枪，手臂平伸，枪口朝画面右方；左手放松。
- 其他姿势手里**不拿武器**。

summon：手到脸侧时，手指张开、手掌靠近眼睛一侧（P5 召唤 Persona 摘面具的动作，但现在没有面具，就是手抓向脸侧）；表情锐利。
victory：右手拉左手的红手套手腕处（P5 胜利动作），表情从容。

每个姿势出 2 张：art/p5/poses/<姿势名>_a.png、<姿势名>_b.png（_b 以 _a 为输入再微调动作角度，人物不变）。原样提交，不裁剪不抠图。
再拼一张 art/p5/poses/compare.png：每行一个姿势，依次放 参考图、_a、_b（各缩到 256×384），行首写姿势名。

【自检（报告里每个姿势逐条写）】
- 姿势是否和参考图对得上；人物是否和母版一致（脸、发型、服装、配色）；
- 手指、持刀 / 持枪的手是否正常（刀和枪握在**右手**）；
- 轮廓外 alpha 是否为 0、有没有底色残留；全身是否入画；
- 被安全策略拒绝的：写清楚哪张、拒绝原因，不要绕过（枪的那张如果被拒，改成「手臂平伸、手掌张开指向前方」再试一次，并在报告里说明）。
