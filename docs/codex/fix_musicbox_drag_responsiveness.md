# 音乐盒拖动起步延迟修正（1.1.2）

用户反馈 1.1.1 长按拖动不跟手。源码中位置没有插值，但手势必须满 450ms 才移动，即使已经明确拖出图标也仍要等，造成先停住再跳到鼠标的感觉。

修正：

1. `IconDrag.Step`：按下后移动累计达到 6 个视口逻辑像素，就切入拖动，不必等待 450ms。没有移动时仍可长按进入拖动模式。
2. 持续使用原抓取偏移，位置直接取当前鼠标坐标，不做位置缓动，不再添加固定等待。
3. 图标和输入捕获层的 `GuiInput` 鼠标移动事件直接更新位置，逐帧轮询只作兜底。GUI/轮询共用状态，释放只判断一次。
4. 点按需要在没有进入拖动的情况下松手；任何拖动都不打开面板。继续保留输入捕获清理、屏幕边界、位置保存和分辨率适配。
5. 清单和运行时版本同步升为 1.1.2。

验证：Release 0 警告、0 错误；MenuInteractionTests 28435 项通过，新增“20ms 内移动即进入拖动”“下一次移动无插值跟随”“快速拖动不误触点击”的回归检查。0.107.1 / 0.111.0 ApiCheck 均通过（MusicBox 249 处引用）。未启动游戏，实际手感仍需用户验收。
