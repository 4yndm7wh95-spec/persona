# 卡图第三轮：更有创意的 P3R 重写（26 张）

## 为什么重写

用户看完第二轮的反馈：**合理，但是"标准答案"，太保守、太平淡，只是换了形象，不够有意思；要更有创意，同时保留辨识度**。另外点名四张有问题：虚空形态（头改成蝴蝶太怪、和原版没区别）、彗星（和原版没区别）、星位序列（和原版没区别）、冲锋（只换了颜色，还是储君的头）。

我自己看第二轮的问题是：同一个南瓜灯杰克的脸重复了十几次，小精灵、杰克冰人也各重复好几次，很多卡只是"把 Regent 抠掉换成同一个姿势的魔物"。

## 这一轮的思路

每张卡不再只是"换角色"，而是**把被替换的东西重新演绎成一个具体的 P3R 时刻 / 角色 / 物件**，同时保持剪影、动作、位置和镜头不变，一眼还认得出是原来那张。例如：迫降 = 黑暗时间的棺材砸下来；下砸 = 总攻击的扭打云；伽马爆破 = 召唤器顶向镜头；天际钻头 = 塔塔罗斯塔当钻头；共鸣 = 俄耳甫斯拨竖琴；虚空形态 = 黑暗时间的时钟。

**范围**：第二轮里还在"待审"的 29 张里，除去 `meteor_shower`、`collision_course`、`the_sealed_throne`（没被你点名，先保留），其余 26 张。你已经通过的前 20 张（第 1～4 批）不动，你想让它们也更有创意，说一声我再写。

**新的取舍（请确认）**：这一轮开始出现 P3R 的人类角色 cameo（山吹、美锷、真田、顺平、风花、Ken、Aigis、Pharos、伊丽莎白、伊戈尔）和 Koromaru，不再只用三种魔物。结城理的脸仍然不出现。如果你不想要这些人物，我改回魔物和物件。

## 给 Codex 的执行方式

- 每批 5～6 张，生成后停下等用户审，不要自动重试。
- Image1 = 原版图（路径见每张）；有"参考图"的再附上；没有参考图的人物，如果你本机 P3R 导出里有该角色的参考图可以附上，没有就按文字描述画。
- 输出 1000×760 不透明 PNG，放 `art/cards/v4/local_edits/round3/batch_NN/<卡名>.png`，另存 `comparison.png`（原版 | 第二轮 | 新图）和 `prompts_and_sources.json`，状态 `awaiting_user_review`。
- 机器可读版本：`art/cards/v4/local_edits/round3_prompts.json`。
