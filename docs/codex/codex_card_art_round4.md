# 卡图第四轮：剩下的 11 张（原图里没有 Regent 的）

前几轮这些卡要么"保持原图"，要么只换了一点。现在它们是整套里唯一还完全是原版的卡，放在 P3R 卡组里会很显眼，所以这一轮用第三轮的创意方式做掉。

**新的取舍（请确认）**：这批第一次把原版的**敌人换成 P3R 的暗影**（黑色黏液 + 面具），因为这些卡里没有 Regent，能换的只有敌人和特效。不想换敌人的话告诉我，我改成只换特效。

范围：第二轮保留原图的 9 张（黑洞、轰击、星灭、引导之星、月面射击、粒子墙、七星、太阳打击、光谱偏移），加上第二轮没被点名的流星雨、碰撞轨迹。王之凝视和封印王座已经是关键牌自由设计，不在这里。

执行：每批生成完停下等用户审，不自动重试。Image1 = 原版图；输出 `art/cards/v4/local_edits/round4/batch_NN/<卡名>.png`，附对比图（原版 | 新图），状态 `awaiting_user_review`。流星雨是竖图 606×852。
