# Codex 任务：防御用的碎玻璃素材（P5Joker）

## 背景
防御（格挡）要做成"碎玻璃格挡"：Joker 抬臂，几十片碎玻璃从四周飞来，在他身前拼成一面错落的玻璃墙，停一下再炸开。
之前碎片是代码切出来的平面多边形，太粗糙（用户 2026-11-04）。需要一批**精细的手绘 / 渲染风格碎玻璃**，由代码负责运动、折射和闪光。

## 要画的
1. `glass_shards_sheet.png`：一张 4×4 的图集，16 片**互不相同**的碎玻璃。
   - 尖锐、不规则的碎片：三角、长条、带缺口的多边形都有，大小比例各异。
   - 每片都要有玻璃的细节：
     - 一道有**厚度**的亮边（侧面能看出玻璃厚度）；
     - 内部有斜向的**反光条纹**和细微的折射纹理；
     - 边缘有细小的崩口。
   - 颜色：以透明 / 冷白为主，边缘和反光里带一点 P5 红（#E5191C）。整体通透，不要实心的红色。
   - **真透明背景**，玻璃本身是半透明的（alpha 0.25～0.6），亮边和高光可以接近不透明。
   - 每格 512×512，碎片居中、不出格，四周留出余量。
2. `glass_glints.png`：一张 4×1 的图集，4 种**玻璃闪光**（十字星芒、细长的光条），白色带一点红，真透明背景，每格 256×256。
3. `glass_dust.png`：一张 256×256 的细碎玻璃屑（十几颗很小的亮点碎屑），真透明背景，用作粒子。

## 风格
- 参考 P5R 战斗里的玻璃 / 碎镜效果（眼神特写碎开、Shuffle Time 的碎玻璃），精致、锐利、反光强。
- 不要卡通平涂，不要粗黑描边。
