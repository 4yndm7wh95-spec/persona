# Codex 任务：亚森「伸手攥拳」的两张手臂分层（毒性爆发）

## 背景
毒性爆发（巨手版）里，亚森现身后要把手臂伸向敌人，跟着横幅后面的巨手一起攥拳、捏碎。
现在 `art/p5/fx/v4/arsene/layers_v7/arm_reach.png` 那只手臂是弯着抬在胸前的（手在下巴附近），只转角度做不出伸手和攥拳，所以需要补两张同一只手臂的新姿势。

## 要画的
在和 layers_v7 **完全相同的画布**上（2048×2304，坐标系同 `layers.json`），画亚森**右臂**（就是现在 `arm_reach.png` 那一只，红色袖子、黑手套）的两个姿势：

1. `arm_reach_extend.png`：整条手臂朝**画面右侧（敌人方向）**伸直、略微朝下，手掌张开成爪、掌心朝右，五指分开，有力。
2. `arm_reach_fist.png`：和 1 同样的伸直手臂、同样的位置和角度，只有手**攥成拳**，拳面朝右，看得出用力。

## 硬性要求
- 肩膀接口必须和现在的 `arm_reach.png` 对齐：肩关节在 pivot **(1380, 665)** 附近，和 `body.png` 接上不露缝，袖口、肩线的颜色和画法一致。
- 两张的手臂（肩到手腕）完全重合，只有手不同，方便代码直接切换。
- 风格照 `arsene_draft_v7_facefix.png`（P5R 立绘风、黑色粗描边、平涂加硬阴影）。
- **真透明背景**（不是白底、不是棋盘格），只画这一只手臂，不带身体和翅膀。
- 照 `docs/codex/README.md` 的长期规则：不启动游戏、不 force/rebase、游戏文件只读。
