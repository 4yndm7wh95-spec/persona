# 毒性爆发捏碎后卡顿修复（P5 Joker 0.9.13）

日期：2026-11-07。工作分支：`codex/p5-combat-fixes-20261104`。基于 `d56e270acc80f655174d9eeae86d5389c8d0b1b1`；不移动 Claude 的开发分支。

## 原因与改动

上轮日志调查和隔离测试见 `../p5_outbreak_perf_20261106/`。为了让手指压在眼神横幅上、掌臂留在后面，0.9.12 对同一只体积手做了两遍全屏光线步进，最后才按表面分类隐藏前/后部分。手散成烟时，不透明度降低、步进更难提前结束，加上手往镜头前推，在捏碎后的约 0.45 秒内形成持续 GPU 开销；这与用户每次都在后半段卡顿的反馈吻合。

本版把体积计算改成每帧一次：

- 新增 `CrushHandFrame`，每次施法独立拥有一个透明 HDR 子视口。体积手写入预乘颜色、不透明度和二值表面分类。
- 两个便宜的合成层仍分别放在同一次横幅前后；手指/拇指遮挡关系保留。分类先解码再插值，避免采样把掌臂误判到前面。
- 只把这只体积手的内部渲染高度限制为 720px（1080p 屏幕使用 1280×720 缓存），最后合成到完整屏幕。眼神、碎片、人物、界面继续按原来的尺寸渲染；这是空间采样优化，没有降低动画更新帧率。
- 透明/未出场时关闭缓存更新，结束随本次施法根节点释放；多次施法不共用缓存。仍使用 0.9.12 的普通屏幕根节点和图层顺序。
- 手、眼神捏碎和毒伤的共同时间轴、毒层计算、触媒规则、光波和角色动画均未改动。

只改 `CrushHand.cs`、新增 `CrushHandFrame.cs`，另更新版本、测试工具和本报告；无需修改或重新打包 PCK。

## GPU 实测

Godot 4.5.1，Forward+ / Direct3D 12，RTX 4060 Laptop GPU；视口 1920×1080，与本机游戏日志所示后端一致。每个状态预热 24 帧、采样 72 帧、关闭垂直同步与帧率上限。新方案计入 **缓存子视口 + 主视口两层合成** 的总 GPU 时间；没有只报合成层时间。

| 消散进度 | 旧双遍中位数 | 新缓存中位数 |
|---|---:|---:|
| 0% | 13.827 ms | 3.406 ms |
| 10% | 20.264 ms | 4.841 ms |
| 25% | 21.304 ms | 5.080 ms |
| 50% | 21.959 ms | 5.218 ms |
| 75% | 22.131 ms | 5.250 ms |
| 95% | 22.508 ms | 5.250 ms |

后半段这项效果的开销减少约 76%。原始采样汇总见 `hand_cache_perf.json`，逐项输出见 `cache.log`。这些是隔离特效的 GPU 耗时，不是整场游戏 FPS；游戏还存在其他绘制、碎片、伤害钩子和刻意的击中停顿，不能据此承诺任何配置都不掉帧。

## 画面与回归验证

- `compare.png`：原双遍 / 同分辨率缓存 / 实际 720p 缓存三列，张开、半握、攥紧三行。同分辨率对照的 RGB 平均通道差约 0.05～0.10/255，99% 通道差不超过 1；没有发现整体颜色或亮度偏移。
- 720p 缓存的 RGB 平均通道差约 0.25～0.49/255，99% 通道差约 4～9。局部边缘和烟的细粒度会更柔和，不声称逐像素一致。完整数据见 `visual_metrics.json`。
- `tail_compare.png`：消散 10% / 50% / 95% 的前后对照；没有删除消散效果、没有提前隐藏巨手。
- 透明视口检查：新旧图四角 alpha 均为 0；消散 50% 时新旧 alpha 平均差约 0.68/255（分辨率变化带来的局部边缘差异），见 `transparency.json`。
- 新缓存接入图层回归场景：开场背景采样仍是 `516379ff`，没有黑屏；人物、敌人、亚森、手牌、HUD 的标记颜色没有被舞台修改（0/5）；房间缩放与相机缩放/位移时屏幕覆盖仍正确。见 `layer_cache.log` 与 `new_intro.png`、`new_grip.png`、`new_zoom.png`。
- Release 与独立预览 C# 编译均通过；已有 ReadyFx 未赋值及 Preview 可空元组警告保留，没有新增编译错误。`build.log` 为最终增量编译输出，`preview_compile.log` 为预览编译输出。
- 实际游戏程序集的五个 Harmony 补丁仍能离线挂载/卸载；慢上毒等待、放行捏碎、重叠施法时钟及毒伤上下文隔离测试通过，见 `compatibility.log`。
- GPU 日志只有 Godot D3D12 的既有 PSO 缓存未实现警告，没有 shader 编译或运行错误。没有启动游戏。

## 复现

先运行 `tools/p5/verify_combat_patches/prepare_visual.py --eyes <现有资源包中的 eyes.png> --output <临时目录>`，再用普通 Godot 4.5.1：

```text
Godot --path <临时目录> --script res://hand_cache_check.gd --rendering-method forward_plus --rendering-driver d3d12 --resolution 960x540 --audio-driver Dummy
Godot --path <临时目录> --script res://layer_cache_check.gd --rendering-method forward_plus --rendering-driver d3d12 --resolution 960x540 --audio-driver Dummy
```

窗口分辨率是 960×540；性能脚本创建的被测视口为 1920×1080，缓存为 1280×720。测试中固定的噪声与时间参数用于新旧比较，未宣称与某一帧实机截图相同。
