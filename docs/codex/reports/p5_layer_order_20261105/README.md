# P5 Joker 0.9.12：毒性爆发眼神特写层级修复

0.9.11 把需要覆盖整个视口的特效根节点设成了顶层，意外改变了它们相对战斗人物和界面的绘制顺序。当同一帧里已有其他效果提前做过屏幕取样时，舞台还有可能把早先的黑底重新铺到整屏。

恢复 0.9.10 的背景容器绘制顺序：房间底图 → 红色舞台 → 手掌和手腕 → 眼神横幅 → 近侧的手指和拇指。Joker、敌人、后现身的亚森和战斗界面保持原有前后关系。舞台在自己开始绘制时读取已经画好的房间背景。大房间仍按视口铺满，做法是补偿父节点和相机的缩放位移，不把特效提到顶层。快速连续出牌时，每只手按自己的横幅节点定位。这次没有改毒伤、声音或动作节奏。

## 离线对照

Godot 4.5.1，OpenGL，960×540。使用项目的舞台着色器、原版眼神网格和巨手着色器；彩色色块代表角色和界面。场景中先放一次取到黑底的屏幕拷贝，模拟另一特效先取样。左右为同一镜头、同一帧的旧版做法与修复做法，见 [对照图](layer_order_comparison.png)。这是独立测试场景，非游戏实拍。

| 检查 | 0.9.11 | 0.9.12 |
| --- | --- | --- |
| 开场，横幅外原色 #516379 | 变为 #000000 | 保留 #516379 |
| 开场，角色与界面四个采样点 | 2/4 被改变 | 0/4 被改变 |
| 握紧，增加亚森后的五个采样点 | 3/5 被改变 | 0/5 被改变 |
| 房间缩小至 70%，叠加 65% 镜头缩放与平移 | 3/5 被改变 | 0/5 被改变，舞台仍覆盖视口 |

单独渲染了巨手张开、抓握、握紧和冲击环。使用本机游戏程序集运行兼容测试，毒伤补丁、独立播放时钟和异步结算上下文检查通过。Release 构建 0 个错误、1 条已有的 ReadyFx._aura 未赋值警告。没有启动游戏；实际普通房、精英房和 Boss 房仍以实机画面为准。
