# P3Makoto 0.15.33 · 修复 0.113 战斗与商店兼容

用户确认独立卡图已生效，但伤害数字恢复原版、打击等牌缺少命中音效，商店仍显示原版。检查本机 0.113 实测日志及其实际游戏程序集后修正；P3Makoto 与 P3CardArt 继续保持独立。

## 原因与修正

1. **数字和部分音效共用一个失效的命中入口。** 0.113 的 CreatureCmd.Damage 最终重载改为 DamageTargetData 集合并增加 modifyDamageHookType。AttackCommand 直接使用该新重载，旧补丁严格匹配旧签名，日志明确 `patch DamagePatch failed: Patching exception in method null`。因此命中目标未被标记，P3 伤害数字和命中音效回调没有运行，而攻击前的补丁仍关闭原版命中音效。
   - 优先补丁 0.113 的最终 targetData 重载；旧版仍补丁 targets 重载。每版只选择一个，避免多层转发重复触发。
   - 读取目标数据时取出 Creature 引用，不改动原伤害数据、数值或参数。
   - 只有伤害补丁已成功安装才屏蔽原版命中特效/音效，避免今后接口变化再次造成静音。
2. **商店补丁跑得太早。** 0.113 的 NMerchantRoom 已成为抽象基类；NStandardMerchantRoom._Ready 先调用基类，再赋值 MerchantButton。旧补丁挂在基类 _Ready 后，按钮仍为空，安装中途抛 NullReferenceException，留下部分构建状态。
   - 0.113 改挂 NStandardMerchantRoom._Ready 完成之后；旧版仍挂 NMerchantRoom._Ready。商人按钮未初始化时在创建覆盖层前明确报错。
3. 日志同时发现选人补丁依赖已经移除的 characterModel 参数，以及牌控件归还时给只读 IsFocused 赋值的报错；分别改为读取按钮的 Character，以及只在存在 setter 时写入。
4. 构建引用搜索优先 GameDir 的 HintPath，避免复用项目下其他版本的 DLL 副本。

独立诊断不运行伤害流程、播放音频或创建实机商店。用户此前要求自行审查，本次未启动游戏；修复后的数字、音效和商店视觉仍待用户重启验收。
