【游戏里怎么用（决定拆法）】
每层是一个独立的贴图，绕一个关节点旋转 / 缩放 / 平移：翅膀绕肩根扇动、手臂绕肩抬起、撒旦耶尔开枪时枪和手臂一起后坐、身体缓慢上下浮动。
所以：被别的层挡住的地方要**补画出来**（翅膀根部、手臂后面的胸口、枪后面的身体），否则一动就露出空洞。

【1. 先修裁切】
两张草图都有部件顶到画布边：亚森右翼翼尖顶到右边，撒旦耶尔左侧翅膀顶到左边。
用图像编辑**扩展画布并补全被裁掉的翼尖**（不改已有部分）：亚森扩到 2048×2304（主体位置不变，四周留空），撒旦耶尔扩到 3200×1700（左边补出完整翅膀，底部腰线以下仍然不画）。
扩完的全图存 arsene_full.png、satanael_full.png（拆层都以它为准）。

【2. 拆层】每层都是**和全图同样大小的画布、同样的坐标**（叠起来正好拼回全图），层外 alpha = 0，边缘干净不带别的层的颜色。
亚森 art/p5/fx/v4/arsene/layers/：
- wing_back.png：身后那只翅膀（画面左边、被身体挡住的那只），根部补全；
- body.png：头 + 礼帽 + 躯干 + 燕尾 + 腿（不含两只手臂、不含两只翅膀），被手臂挡住的胸口 / 腰部补全；
- arm_back.png：收在身侧的那只手臂；
- arm_reach.png：向前伸、爪子张开的那只手臂；
- wing_front.png：画面右边那只翅膀，根部补全；
- eyes_glow.png：只有发光的红眼睛（其余透明），用来单独做闪光。
撒旦耶尔 art/p5/fx/v4/satanael/layers/：
- wings_left.png、wings_right.png：左右两侧翅膀各一层，根部补全；
- body.png：头 + 角 + 躯干 + 腰带（不含手臂和枪），被枪和手臂挡住的胸口补全；
- gun_arms.png：两只手臂 + 巨枪（一起后坐，所以合成一层）；
- eyes_glow.png：只有发光的眼睛。

【3. 关节点】
各目录写 layers.json：每层的文件名、叠放顺序（从后往前）、关节点像素坐标（在全图坐标里），以及：
- 亚森：两翼的肩根、两只手臂的肩关节、身体的浮动中心（大约胸口）、伸出那只手的爪尖；
- 撒旦耶尔：两侧翅膀的肩根、手臂的肩关节（后坐绕这里转）、**枪口中心点**和枪管朝向（角度）、身体的浮动中心。
