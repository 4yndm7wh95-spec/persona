# P5Joker 卡图：思路、创意总表、第一步任务（导出原版 + 收集人物参考图）

## 思路（沿用 P3 卡图第三 / 五轮定下来的做法）

- **保持原版辨识度**：Image1 = 静默猎手的原版卡图，做「局部编辑」。原版的剪影、动作、位置、镜头、背景、配色、特效不变，缩略图一眼还认得出是哪张。
- **把被替换的东西重新演绎成一个具体的 P5R 时刻 / 角色 / 物件**，不是单纯「把猎人抠掉换成 Joker」。例：冲刺 = 摩尔加纳巴士冲过来；触不可及 = 岩井的模型枪店「Untouchable」；华丽收场 = 撒旦耶尔的大罪之弹。
- **人物**：以怪盗团为主（Joker、Skull、Mona、Panther、Fox、Queen、Oracle、Noir、Crow、Violet）和他们的人格面具；暗影随便用；
  其他角色只少量出场（天鹅绒房间的伊戈尔 / 卡萝莉娜 / 芮丝汀娜 / 拉雯妲、惣治郎、武见、岩井）。
- **不能 OOC**：每个出场的人物都必须照原版参考图画（脸型、发型、发色、面具、怪盗服、武器），所以**第一步先由 Codex 把参考图找齐**，生成时每张都附上对应人物的参考图。
- 少数关键牌（稀有 / 能力核心牌）以后可以按「自由设计」不管原版，先不做，等你点名。
- 画风：照原版卡图的硬朗赛璐璐（清楚的深色描边、近黑的暗部、明确的中间调和受光面），不要模糊、柔光、写实渲染；不要文字、数字、卡框、UI、水印。
