# P5Joker 特效风格说明（给新接手的会话）

> 这份不是规范，是「这个用户喜欢什么样的特效」的经验总结，帮你找准方向。
> 具体怎么做、用什么意象、怎么构图，请按你自己的审美和创意来，用户也一直鼓励「按你的审美来」。
> 拿不准时，先做一张给用户看，比照着这份文档推演更可靠。

---

## 一句话

**「P5R 的气质」用在一个写实一点的战斗画面里：精致、利落、有质感、有 P5 红。不是把 P5R 的 UI 和漫画演出搬进来。**

P5R 风格可以理解成两层：
- **气质层**：怪盗、反抗、帅、干脆、红黑白、网点、锐利的造型、节奏感。**我们要的是这一层。**
- **演出层**：大标题横幅、技能名大字、骷髅图标、全屏速度线、漫画分格、赛璐璐卡通烟团。**这一层只能点到为止，大多数时候不用。**

---

## 之前一次偏掉的例子（别照这个方向走）

用户给另一个会话的要求只有「贴合 P5R 风格」，那个会话做出来的东西（毒性爆发、几张技能牌）大致是这样：
- 全屏「毒性爆发 OUTBREAK」标题横幅 + 绿色骷髅图标；
- 卡通描边、平涂的绿色毒云团；
- 全屏放射速度线；
- 红色粗框的多边形护盾、圆环准星、悬在敌人身上的图标；
- 有些更简单的效果已经不算动漫风，而是**卡通**了，比如它做的面具火：形状简单、平涂、像儿童动画的火苗；
- **经常弹出文字**：技能名字幕、「+9」之类的数字、说明性的小字，用文字告诉玩家发生了什么。

用户的评价：**不是不好，可以有一点，但和我们现在的风格差得很远**。问题不在单个元素，而是整体变成了「动漫 / UI 演出」，像是贴上去的一层画面，而不是发生在战斗场景里、有体积有光的特效。

## 用户满意的东西有什么共同点

可以先看这些预览（`docs/p5/preview/`），比看文字更直观：
- `bullet_time_v7.mp4`：子弹时间（最近一次被明确认可，用户提了很多细节要求才过）
- `redo_acrobatics_v4.mp4`、`redo_batch2_v4.mp4`、`redo_batch3_v1.mp4`：「怪盗风」技能牌，用户说「可以 / 还可以」，方向认可
- `serpent_form_v25_*.mp4`：群蛇形态
- 更早的攻击、召唤、眼神特写相关 gif

我总结的几个共同点，不是公式：

1. **一个清楚的主意象，和牌效挂钩。**
   子弹时间就是「时停」：透明的钟、冻在半空的碎片、世界褪色只有 Joker 在动。抽牌就是牌飞进手牌。观众一眼能看懂「这张牌在做什么」。
2. **造型清楚、边缘干净。**
   被认可的东西都有明确的形：预告信卡、钟、齿轮、刀光、玻璃碎片、纸屑。软的雾、糊成一团的烟，一般都不讨好。
3. **精致、有材质、有细节，但不堆砌。**
   像预告信卡：牌背斜纹 + 网点 + 开窗，翻面、高光扫过、被切开、从切口烧掉。细节放在主角上，而不是在画面上多加东西。
4. **P5 红是主色。**
   配上黑、白，加一点网点。整片暗色调、浑浊的黑烟用户很不喜欢；纯光效（激光柱、光刃）也被否过。
5. **节奏有拍子。**
   每个动作一到两个最满的瞬间（顿帧、轻震、闪），前后干净。出牌反馈要即时，用户嫌过延迟。
6. **会动、是活的。**
   挂着的东西也要轻轻浮动、慢转、闪；完全静止的贴片会显得死。
7. **跟人物有关联。**
   特效从 Joker 身上、手上、影子里出来，或者落到敌人身上，有方向、有因果；不是凭空出现在屏幕中间。

## 用户明确不喜欢过的（提醒，不是禁令）

这些是真实踩过的坑。理由比条目重要：大多是因为「看起来像贴上去的」或「粗糙 / 塑料感」。

- **用文字代替特效**：弹出的字幕、技能名大字、说明性文字、飘字。用户特别点出过这一点。效果要靠画面本身讲清楚；游戏自己已经显示数字和能力图标，特效不需要再写字。
- **全屏划过的线条**（斜切色带、速度线、横贯屏幕的细带）：被说「粗糙」，是一整批牌被废的直接原因。
- **细线圆圈 / 冲击环、UI 图标、多边形贴片、星星贴片**：贴图感、突兀。柔和的光晕可以。
- **平涂色块、剪影填色**：「塑料感强」。
- **卡通化**：简单的卡通火苗、卡通烟团、Q 版造型。比「动漫风」更偏离方向。火、烟、光这类东西要有层次、流动、明暗和细节，不要几笔画出来的样子。
- **大面积暗色浓烟 / 墨 / 雾**：看不清、闷、没活力。用户说过 P5 是青春、有力量、主题是反抗，要有活力。
- **把「华丽」理解成多加东西**（金光、火花、全屏线）：表面化。华丽应该是主瞬间更大、更精、更有分量。
- **乱用预告信**：它是好素材，但不是每张牌都要有。
- 纯光柱、光刃（像激光棒）。

**动漫元素可以少量用**：网点、锐利的切角、一闪而过的眼神特写（`CutIn.Eyes`，用户认可过），只要融在画面里、短、不喧宾夺主。

## 一些容易失败的路（来自最近的失败）

最近一个会话做「融入暗影 / 余像 / 萎靡」（暗影主题的牌），改了三版都没过。原因是暗影题材容易让人做成软、暗、雾的东西，和上面第 2、4 条正好相反。

如果你遇到「暗、毒、诅咒」这类题材，可以想想怎么让它**依然有清楚的造型、有 P5 红、有亮部**，而不是用烟去「表现氛围」。这只是一个提醒，具体怎么解你来想。

## 和用户合作的方式

- **先做一张，给带声音的预览视频**（`docs/p5/preview/`，854 宽，用 SendUserFile 发）。方向对了再一批约 5 张。
- **发之前自己先看一遍渲染出来的帧**。用户明确要求过，很多问题自己就能看出来。
- **拿不准方向就问**，最好让用户给参考（P5R 里哪个技能、哪个 UI 动效、或别的 mod）。用户否了一版，就换思路，不要在旧代码上修修补补。
- 用户会给很具体的反馈（「残影太大」「反馈有延迟」「钟不能太大」），照着改就行。
- **音效**：要有，但不明显。每个效果两三个关键拍、一个主拍最清楚，不要堆在一起。用游戏自带的样本 / FMOD 事件，不要代码合成（用户嫌「代码感很重」）。
- 回复用中文。

## 技术上的起点（了解即可）

- 特效全部是 Godot 4.5 实时渲染（C# + 着色器），基本不用贴图。
- 可以复用的积木：`p5mod/src/Vfx/Phantom.cs`（预告信卡、拖尾、火花、纸屑）、`TimeStop.cs`（子弹时间：读屏调色、玻璃钟、冻结碎片）、`SkillRedo*.cs`（每张牌的实现）。
- 预览工具：`tools/p5/fxpreview/`（`render.sh` + `mix.py`，场景在 `Preview.cs` 的 `RunCards`）。
- 更多历史、每张牌的状态和环境配置看 `docs/HANDOFF.md` 最上面几条；`docs/p5/FX_RULES.md` 是更早的规则，部分已过时，可以参考它的「结构 / 方向 / 节奏」部分。

**最后再说一次：上面都是方向，不是限制。** 用户想要的是好看、帅、细节足够、有 P5 味道的特效。只要符合这个感觉，新的意象和做法都欢迎。
