# P5Joker 选人界面设计（静默猎手 → Joker）

参照 P3 mod 的思路：整块替换角色的选人背景场景、右侧放会动的分层立绘、选中时有一次强反馈、左侧介绍板换成主题风格。**这里是借思路，不照搬 P3 的画面。**
画风按 P5R：红 / 黑 / 白三色，锯齿形色块、网点、勒索信剪贴字、动作感强的斜切构图。

挂载点：`CharacterModel.CharacterSelectBg` → `screens/char_select/char_select_bg_silent`（对应 P3 的 RegentBg）。介绍板挂在同一个选人界面的原版面板上，做法同 `mod/src/Scenes/CharSelectInfo.cs`。

立绘姿势参考：`art/p5/ref/charselect_pose_ref.jpg`（用户给的官方 P5 Joker 头像：红手套食指点在眼角、竖起的大衣领子、侧身回头、红底）。

## 4. 立绘：分层与动画

### 4.1 分层（全部同一画布 1024×1536、同一位置、同一大小）

| 文件 | 内容 | 用途 |
|---|---|---|
| `portrait_base.png` | 用户参考图扩展成半身竖图：头顶到腰，透明底 | 静态兜底、残影、光晕 |
| `portrait_hand.png` | 只保留抬起的那只红手套（含前臂袖子） | 手单独浮动 |
| `portrait_nohand.png` | 去掉抬起的手，把被挡住的脸颊、衣领、大衣补画完整 | 手下面的底层 |
| `portrait_blink.png` | 和 base 完全一样，只闭眼 | 眨眼贴片 |
| `portrait_mask_hand.png` | 只保留一只红手套**捏着白色面具的边缘**，面具正好戴在脸上的位置 | 选中演出：扯面具 |

### 4.2 Spine 骨骼（同 `tools/ui/build_portrait.py` 的流程）
root → chest（呼吸）→ head（微摆）→ hair_l / hair_r（发梢）、collar（大衣领子被风吹得轻轻抖）、hand（跟着头，自己再浮动）。
常驻：呼吸、发梢飘、领子抖、眨眼、身后红色轮廓光呼吸、偶尔眼角一道白色反光（"叮"）。

### 4.3 入场 + 选中演出（约 2.2s）
1. **0.00s** 画面先闪一帧黑白反色（P5 切屏），立绘从右侧带两道红 / 黑错位残影滑入（0.35s，OutExpo）；锯齿色块从中心"嘭"地弹出。
2. **0.35s** 此时立绘是 nohand 底层 + `portrait_mask_hand`（戴着面具，手捏着面具边）。
3. **0.70s** 上方切入 P5 式横幅：一条斜的黑底白框，里面是 Joker 眼睛的特写（裁自立绘）。
4. **0.95s 扯面具**：mask_hand 层向画面左上甩出（旋转 + 位移 + 动态模糊残影），同一帧脸上炸开**蓝色火焰**（GPU 粒子 + 着色器火焰），横幅碎成玻璃片。
5. **1.00s** 身后亚森剪影从火焰里升起、双翼展开（已有 `art/p5/fx/arsene/arsene_still.png`），锁链声 + "Persona!" 音效；脚下楼顶震出一圈红色冲击线。
6. **1.30s** 火焰收束，手层换成 `portrait_hand`（食指点在眼角的招牌姿势），亚森淡成身后的大剪影慢慢消失。
7. **1.40s** 左侧介绍板入场（同 P3：等演出结束再进）。

设置里沿用 P3 的"选人动画"开关：关掉时直接进第 6 步的待机状态。

## 5. 左侧介绍板（P5R 状态界面风格）

- 底板：黑色锯齿多边形，向右上倾斜 -7°，外圈白色描边 + 红色错位阴影。
- 抬头：勒索信剪贴字 **JOKER**（生图 C1，烘焙成贴图）+ 下方小字"怪盗团 / CODE NAME"。旁边一块小塔罗牌形状"0 / THE FOOL"。
- 数字：HP / 金币用粗斜体（沿用 Barlow Condensed 900 Italic），白字 + 黑色硬阴影，HP 下划线红色、金币黄色。
- 描述：白字，左侧一条红竖线。
- 天赋：红边图标斜卡 + 名称 + 白底黑字 PASSIVE 标签。
- 动画：抬头的剪贴字逐个"啪"地拍上去（每个字母 40ms，各带一点旋转）→ 数字数上来 → 描述 → 天赋；常驻：每隔几秒一个字母抖一下，红色阴影轻微错动。

## 6. 生图 prompt（转发给 ChatGPT）

**通用说明（每条都附上）**
- 画风：《女神异闻录5 皇家版》官方立绘 / 头像画风——干净细线、大块纯黑阴影、锐利的明暗分界、赛璐璐平涂、少量灰阶。
- 需要透明底的图：直接要 PNG 透明背景；如果做不出透明，就用纯 `#00FF00` 绿色背景，人物身上不要出现这种绿色。
- 画面里不要文字、logo、边框、水印（剪贴字那两张除外）。
- **A2～A5 都在 A1 生成后，以 A1 为输入图做编辑，同一个对话里做**，要求同画布、同位置、同大小，人物不要挪动、不要缩放。

### A1 立绘底图（输入：用户参考图）

> 以这张图为输入做图像编辑，生成竖版 1024×1536、透明背景的 PNG。
> 保持同一个人物、同一张脸、同样的发型、表情（嘴角微微上扬的冷笑）、同样的姿势：身体侧向画面左侧，头转回来看向镜头，戴红手套的右手抬起、食指轻点在右眼眼角下方。
> 把画面**向下扩展到腰部**、向上留出头顶完整的头发：画出完整的黑色长大衣（高高竖起的领子、灰色高领内衬、大衣前襟和下摆往画面右侧被风吹起一点），腰部被画面底边截断。
> **去掉红色背景，换成完全透明**；人物轮廓外不要任何光晕、阴影、红色描边。
> 人物占画面高度约 95%，头部在画面上 1/3，身体右边缘可以贴到画布右边。
> 画风严格保持原图的 P5 官方画风：细墨线、大块纯黑阴影、锐利明暗边缘，不要变成厚涂或 3D。

### A2 只留手（输入：A1）

> 以这张图为输入做编辑，画布、位置、大小完全不变。**只保留**抬起的那只红手套和它的前臂（包括黑色大衣袖口），其余所有部分（头、身体、大衣、头发）全部删除变成透明。手的形状、角度、位置一个像素都不要动。

### A3 去掉手、补全脸（输入：A1）

> 以这张图为输入做编辑，画布、位置、大小完全不变。**去掉**抬起的右手和前臂，把原来被手和手指挡住的部分补画完整：右侧脸颊、下颌、竖起的大衣领子、大衣胸前。右臂自然垂下到画面外（看不见）。脸、头发、表情、眼睛和其他所有部分保持原样不动，背景保持透明。

### A4 闭眼（输入：A1）

> 以这张图为输入做编辑，画布、位置、大小、姿势完全不变，**只把两只眼睛闭上**（自然地闭眼，睫毛线向下弯），其他任何地方都不要改，背景保持透明。

### A5 手捏面具（输入：A3）

> 以这张图为输入做编辑，画布、位置、大小完全不变。给他戴上 Joker 的怪盗面具：**白色多米诺眼罩面具**，黑色描边，两侧向上翘出尖角，正好贴合遮住双眼一带，眼洞里能看到他的眼睛。
> 再画一只戴红手套的右手从画面左下方伸上来，**拇指和食指捏住面具左侧的边缘**，像正准备把面具扯下来。
> 然后**只保留这只手（含前臂袖子）和面具本身**，其余所有部分（脸、头发、身体）全部删除变成透明。面具的位置必须和戴在脸上时完全一致。

### B1 远景城市天际线

> 横版 1536×1024，透明背景 PNG。东京夜景城市天际线，从楼顶远眺：密集的高楼剪影高低错落，几块大型广告牌（屏幕空白、没有文字），远处一座红白色的电波塔形状。
> 建筑全部画成**纯黑剪影**，只有零星的红色和白色小方窗灯；天空部分完全透明（天空在游戏里另外画）。
> 天际线占画面下方约 60%，最下面一排建筑贴着画面底边。P5 的平面图形化风格，硬边、无渐变、无雾。

### B2 楼顶前景

> 横版 1536×1024，透明背景 PNG。从低角度看的楼顶边缘：画面下方是楼顶的地面边沿和一排铁栏杆，左侧一个圆柱形水塔（带梯子），旁边一根细长天线，几台空调外机，右侧一个空的霓虹招牌铁架。
> 全部是**纯黑剪影**，只在朝上的边缘有一道细细的红色轮廓光。天空、远处全部透明。P5 风格的硬边平面图形。

### B3 摩尔加纳背影（另附 `art/p5/ref/morgana_ref.png` 作参考）

> 1024×1024，透明背景 PNG。摩尔加纳（Q 版二头身黑白猫，大头、黄色项圈）**坐着的背影**，稍微侧过脸看向右边，尾巴向左边弯起。
> 画成剪影风格：身体几乎全黑，只保留白色的口鼻部轮廓边和黄色项圈，边缘一道细红色轮廓光。
> 同时单独再出一张同画布的图：**只有尾巴**（其余透明），尾巴根部的位置不变——游戏里尾巴要单独摆动。

### B4 预告信

> 竖版 1024×1536，透明背景 PNG。P5 风格的"预告信"卡片正面，平视角度、无透视：红黑配色，中间一个黑色礼帽剪影图案，周围是红色锯齿图形和网点，卡片边缘白色细框。**不要任何文字**（字在游戏里另外贴）。卡片铺满画布、四角是圆角。

### C1 剪贴字标题 "JOKER"

> 横版 1536×1024，透明背景 PNG。P5 风格的勒索信剪贴字：单词 **JOKER**，五个字母各自是从不同报纸杂志上剪下来的纸片——每块纸片底色不同（白、黑、红），字体各不相同（粗衬线、无衬线、手写体混杂），每块各自轻微旋转、大小有错落，纸片边缘是剪刀剪出的不规则直边。整体横向排列，占画面宽度约 85%，居中。只要这五块纸片，别的都透明。

### C2 剪贴字横幅 "TAKE YOUR HEART"

> 横版 1536×1024，透明背景 PNG。同 C1 的勒索信剪贴字风格，内容是 **TAKE YOUR HEART**（三个单词一行排开，单词之间留空隙），每个字母一块纸片，颜色只用黑、白、红。整行占画面宽度约 95%、垂直居中。只要纸片，别的都透明。

### D1 角色按钮头像（游戏里显示 132×195，也会裁圆）

> 竖版 1024×1536，**带完整背景**（不是透明）。以用户参考图为输入：Joker 胸像，侧脸回头、嘴角冷笑，红手套食指点在眼角。
> 背景：P5R 风格的红色底 + 黑色放射状太阳纹 + 白色锯齿爆炸形色块 + 黑色网点；人物头部大、构图简洁，脸在画面上半部居中（方便裁圆形图标）。不要文字、边框。

## 7. 生成后的落地步骤（拿到图之后我这边做）
1. 原图放 `art/p5/charselect/`（不裁剪、不改动），先出对齐检查（A2～A5 和 A1 叠图对比，偏移就用 v11_layers 的办法对齐）。
2. 写 `tools/p5/build_charselect_portrait.py`：分层 → Spine 网格（仿 `tools/ui/build_portrait.py`），出预览 GIF。
3. `p5mod/src/Scenes/CharSelectBg.cs` / `CharSelectInfo.cs`：天空着色器、各层视差与动画、选中演出、介绍板；沿用 P3 的"先搭好再藏原版、出错回滚"。
4. 预热：立绘、火焰着色器、剪贴字贴图在 mod 启动时后台预加载（P3 首次选中掉帧的教训）。
