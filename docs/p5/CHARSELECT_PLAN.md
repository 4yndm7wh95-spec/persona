# P5Joker 选人界面设计（静默猎手 → Joker）

## v3 修改（2026-11-17，按用户对 v2 预览的反馈）

预览：[charselect_v3.mp4](preview/charselect_v3.mp4)、[眼神特写那一帧](preview/charselect_v3_cutin.png)、[常驻静帧](preview/charselect_v3.png)。

- **眼神特写**：原来在屏幕正中，主眼（原版网格 UV (0.593,0.535) → 画布 (773,372)，1080p 下 x≈1124）正好压在斜条 / 面板下面。
  现在整条往左挪 364px（按横幅缩放换算，`CutInPlayback.Offset`，默认 0 不影响局内），主眼落在 x≈760，碎裂也从主眼开始（`ShatterFrom`）。
  和入场**同时**切进来（第 0 秒），不再等立绘滑完。原版左侧信息面板先藏起来，碎开后 0.6s 淡入（同 P3 mod，免得盖住特写）。
  横幅右段原版自带的黑白斜碎片现在露在主眼和斜条之间（原来藏在面板后），横幅 0.5s 就碎，保留。
- **立绘动态**：原来只有整体 0.45% 的缩放 + 手 ±3px，看不出来。现在用变形着色器（`cs_warp` 权重图：头 / 外圈发梢 / 左领尖）：
  头以脖子为支点 ±0.8° 轻摆（发顶约 ±9px）、发梢随风飘、领尖抖、呼吸 4.2s 一次（上半身起伏 8px、胸口微鼓）；
  描边、身体、手、眨眼贴片、眼睛金光都用同一套位移，接缝不撕开。手忽远忽近：以手掌下方为支点 ±3.5% 缩放（3.2s 一个来回），指尖在头的范围里还跟着脸动。
- **眨眼**：原来是一下子换成闭眼图 0.11s。现在眼皮从上往下合（0.07s，越合越快）→ 停 0.04s → 往上睁开（0.13s，越睁越慢）；
  眼皮线顺着两眼连线倾斜，**两只眼同一刻合上、睁开**（闭眼图本来就两只都闭了，只是远处那只在阴影里，水平眼皮线会让它先合晚睁）；眼睛金光在睁开过半后才亮回来。
- **音效分层**：原来 1 秒里四声冲击差不多响（入场切入、舞台又一声切入、眼神特写、碎裂）+ 游戏里还叠原版静默猎手的选中音效。现在三层各管一件事：
  0.07s 切入「嗖」（铺垫，0.8）→ 0.23s 原版眼神特写那一下（主音，1.1）→ 0.57s 碎裂（高潮，1.1）+ 低频垫底（0.45），和眼睛闪光同一刻 → 之后安静。
  原版 `silent_select` 只在要显示 Joker 画面的那一次拦掉（`CharSelectSfxMute`）。混音峰值 0.96，不爆音。

## 当前方案（v2，2026-11-17，按用户对 v1 预览的反馈重做）

预览：[charselect_v2.mp4](preview/charselect_v2.mp4)、[静帧](preview/charselect_v2.png)。代码 `p5mod/src/Vfx/CharSelectScene.cs`，贴图 `tools/p5/charselect_assets.py`（res://p5joker/fx/cs_*.png）。

用户对 v1 的意见：整页脏乱；立绘没按图 2 的范围、应该更大（参考 P3 mod 的占比）；亚森冒出来违和；锯齿球垫着很怪、没层次（黑底加粗）；天空那块（放射线、探照灯）太乱；
P3 的立绘左边被斜条挡住一部分，照这个思路把立绘和左边分开、更有空间感；蓝焰面具去掉、只做好眼睛的光；蓝色不搭 → 换颜色。

- **构图照 P3**：立绘贴右、占满屏幕高度的大特写，左边一道斜切口把它收进面板，切口上压斜条。
- **立绘范围 = 图 2**（`art/p5/ref/charselect_framing.png` 和底图模板匹配，相关 0.978）：图 2 = 画布 x −6…896、y 25…1174。
  画布 x 896 落在屏幕右边（切在大衣右肩里）、y 25 落在屏幕顶边，缩放 0.92（往下比图 2 多露一点）。v1 错在把右边界放在画布最右（x 1024），人小了、右肩全露。
- **斜切口**：屏幕 (1150,0) → (1330,1080)，切口左边的立绘不画（按全局坐标裁，滑入 / 手浮动时切口不动）。
  斜条（从切口往左）：纯黑斜板 −10…74（压住切口，上面滚动竖排小字 PHANTOM THIEVES // CODE NAME : JOKER // ARCANA 0）、红条 74…90、白线 102…107、半透明黑宽带 150…236。
  斜条的斜边用着色器画（抗锯齿）。
- **面板**：切口右边整块暗红黑（#22040a，和斜板的纯黑分得开），红色锯齿球压在上面 —— 锯齿之间、人物四周全是黑底，这就是"黑底加粗"。
  （试过：锯齿球外扩黑边 / 错开黑影 / 双层星形 —— 在暗红夜空上黑边都看不出来，不采用。）
- **人物描边**：离线烘焙（白 10px + 外圈黑到 17px，距离场抗锯齿），手单独一份跟着手动；去掉 v1 的红色模糊光晕（看着脏）。
- **背景**：只留干净的深红渐变（城市地平线后面最亮）+ 很淡很慢的云；去掉放射线、探照灯、星光、电车。
  天际线原图自带一层前景楼顶和大片白色楼面（v1 脏乱的主要来源）→ 重新上色成黑剪影，只留小窗灯（窗灯明灭）；地平线压到 y 700；
  远景同一张图翻过来、染成暗红，做纵深。楼顶前景左右翻过来，水塔挨着面板左边，摩尔加纳坐在水塔顶、面朝 Joker（尾巴摆、偶尔一抖）。
  左上角是 TAKE YOUR HEART 剪贴字标题（P5 菜单标题的位置，黑带斜 4°，纸片隔几秒跳一下）。预告信每 7 秒飘过一张。左侧（信息面板）和底部（按钮）压暗衬字。
- **眼睛**：不要蓝焰面具。露出来的那只眼睛（虹膜中心画布 (608,421)；另一只被刘海和阴影盖住，不加光）泛**金光**：
  大柔光 + 虹膜染金 + 白热亮芯 + 横向光条（cs_eye_streak）+ 偶尔一闪的四角星（P5R 原版 star4），慢慢呼吸，眨眼时熄掉。
  金色的理由：P5 觉醒时的眼睛；暖色和红黑白协调；红色会被紧挨着的红手套吞掉。
- **入场 / 选中**：白闪 → 斜条沿切口一上一下画出来、面板底亮出 → 立绘从右边带红 / 黑残影滑入（残影也按切口裁）→ 标题从左滑入 →
  原版眼神特写 + 召唤舞台 → 横幅碎开那一下眼睛金光猛地一亮、光条横贯整张脸 → 常驻。不再召唤亚森。
- **没验证的**：原版信息面板 / 角色按钮的实际位置（仓库里没有截图，按左侧面板、底部按钮估的）、游戏里的 19px 竖直偏移（场景根 offset −521）。要进游戏看。

## 4. 立绘：分层与动画

立绘已定稿：`art/p5/charselect/portrait_base / hand / nohand / blink.png`（1024×1536 透明底，2026-11-16 提交）。底图已经画到胯部，**不需要 A1b**。
场景素材同目录：city_skyline、rooftop_foreground、banner_take_your_heart、title_joker、morgana + morgana_tail、calling_card、joker_button。
落地时注意：blink 只闭了露出的那只眼（另一只在刘海下），只取眼睛一块贴片；nohand / blink 全图有轻微漂移，只用各自需要的区域；morgana.png 本身带着尾巴，要先按 morgana_tail 的形状把身体图里的尾巴抠掉，尾巴才能单独摆。
**用户 11-16 更新**：不要捏面具 / 扯面具那一套（原 A5 和扯面具演出作废）；改成眼睛蓝光 + 手和脸前方一层淡淡的蓝焰面具。

### 4.1 显示范围（用户 11-16 截图定的框）
- 截图（`art/p5/ref/charselect_framing.png`，318×405 的小截图，只用来定范围）就是选人界面里立绘要露出来的范围：上边到头顶头发上方一点，左边到抬起的大衣领尖左侧，**右边界就照截图（大衣右肩被画面右边切掉）**。
- 截图对应底图画布的 x 0~1024、y 0~约 1300（宽度用满）。下边再往下多露一些：屏幕底边落在画布 y≈1400（胸口纽扣以下），剩下的伸出屏幕。
- 摆法：立绘右边界 = 屏幕右边界；头顶在屏幕上方约 6% 处；底部伸出屏幕下边（不在半空截断）。截图里的宽高比约 0.79，在 1080p 下立绘约占屏幕宽 40%。

### 4.2 分层（全部同一画布、同一位置、同一大小，绿幕抠图在我这边做）

| 文件 | 内容 | 用途 |
|---|---|---|
| `portrait_base.png` | 定稿底图（绿幕） | 静态兜底、残影、光晕 |
| `portrait_hand.png` | 只保留抬起的那只红手套（含前臂袖子） | 手单独浮动 |
| `portrait_nohand.png` | 去掉抬起的手，补全脸颊、衣领、大衣 | 手下面的底层 |
| `portrait_blink.png` | 和 base 完全一样，只闭眼 | 眨眼贴片 |

### 4.3 Spine 骨骼（同 `tools/ui/build_portrait.py` 的流程）
root → chest（呼吸）→ head（微摆）→ hair_l / hair_r（发梢）、collar（竖起的大衣领子被风吹得轻抖）、hand（跟着头，自己再轻轻浮动）。
常驻：呼吸、发梢飘、领子抖、眨眼、身后红色轮廓光呼吸。

### 4.4 眼睛蓝光 + 淡蓝焰面具（游戏内实时，不生图）
- **眼睛蓝光**：露出来的那只眼睛（截图里画面右边那只）虹膜处一团青蓝色加色光点 + 横向拉长的细光条；常驻微弱呼吸，面具燃起时一起变亮。被刘海 / 手指遮住的那只眼睛只透出一点光。
- **蓝焰面具**：直接复用局内召唤时的 `Flame.PersonaMask`（在 p5 主线分支 `codex/p5-sts2-v0.113` 的 `p5mod/src/Vfx/Flame.cs`，沿面具轮廓往上舔的蓝色火丝、眼洞是空的、3/4 侧脸透视）。
  - 位置：**在手和脸的前面**（层级在 hand 层之上），面具中心对准两眼之间，跟着 head 骨骼一起微摆，yaw / roll 按截图里脸的朝向调。
  - 强度：比局内淡得多——整体透明度约 0.35，去掉外圈大光晕，只留火丝和亮芯，不能盖住眼睛和表情。
  - 节奏：渐现 1.2s（从中间往两边点燃）→ 保持 2.5s（火丝一直舔）→ 渐隐 1.2s（往中间收掉）→ 空 2~3s（随机）→ 循环。眼睛蓝光跟着它一起亮暗。

### 4.5 入场 + 选中演出（约 1.6s）
1. **0.00s** 画面先闪一帧黑白反色（P5 切屏），立绘从右侧带两道红 / 黑错位残影滑入（0.35s，OutExpo）；锯齿色块从中心"嘭"地弹出。
2. **0.35s** 上方切入 P5 式横幅：斜的黑底白框，里面是 Joker 的眼睛特写（裁自立绘）。
3. **0.75s** 横幅碎成红玻璃片；同一帧眼睛蓝光亮起，蓝焰面具从中间往两边点燃，这一次亮到局内强度的约 0.8，"Persona!" + 蓝焰音效；亚森剪影（`art/p5/fx/arsene/arsene_still.png`）在身后从蓝焰里一闪浮现。
4. **1.30s** 亚森淡出，面具退到常驻的淡强度，进入 4.4 的渐隐渐现循环。
5. **1.40s** 左侧介绍板入场（同 P3：等演出结束再进）。

设置里沿用 P3 的"选人动画"开关：关掉时跳过 1~4，直接进常驻状态。
