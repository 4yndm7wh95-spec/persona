## 用户拉黑的特效手法（2026-11-14）
- 红色网格网点（网点光晕、身体化成网点等）：low，不要再用。
- 环绕光圈 / 光环 / 刀光绕身转圈：不能当主体，最多做次要点缀。
- 一直有效的：不要火焰、塑料感、阴暗黑烟、贴图感、细线圈、有棱有角的形状；人物不能消失。
- **（2026-11-18 新增）红焰着色器（触媒、萎靡第二版的 `RedFlame`，觉醒火形状换红配色）**：用户「太像贴图」，拉黑；着色器已删。任何形状的火焰都别再做。
- **（2026-11-18 重申）光环当主体不行**：磨蚀第二版只有绕身风刃 → 否。光环可以留着当点缀，但必须有别的主体特效。
- **（2026-11-18 新增）刀扇第一版被否**：这套 mod 里小刀 = 子弹 / 枪击，特效里不要再画刀、刀扇；用光刃拼出棱角分明的图案「压根不算特效」。
- **（2026-11-18 新增）腐蚀波第五版被否**：不要贴在地上、一滩一滩的毒；要挂毒那一下有冲击力、打击感。用户说有生图需求可以提，让 Codex 生。
- **（2026-11-18 新增）Codex 生图的用法**：
  - 生出来的图本身有硬边、内容显示不全（画到格子边被切掉）→ **先停下来告诉用户要重生**，不要拿代码硬补着往下做。
  - 贴图里**不要画颗粒分明的小点**（墨点、飞沫、碎屑）：贴图里的颗粒不会实时运动，一看就是贴图；颗粒一律用代码做实时粒子，贴图只画连续的整块形体。
  - 墨之刃不要太往水墨风靠（用户：水墨风感觉不对）。
  - 序列帧要求每格四周留足透明（≥ 96/512 像素），近大远小的放大交给代码。
  - 不要光滑、半透明、高反光的立体液体材质（用户：太 Q 弹、像果冻）；要手绘的锐利流纹（参照 slash/ 刀光、corrosive/ 浪身）。形状要干净有力（像刀光的弧），不要扭来扭去的畸形团块；要有透视的空间力量感。
- **（2026-11-18 新增）不要再复用打击牌的手绘刀光（art/p5/fx/v4/slash/ 的 slash_thin / slash_heavy 等）**：钢铁风暴、终结技、连续反弹已经用了，后面的牌别再拿它当素材；要这种风格就让 Codex 照着画新的一批（codex_p5_painted_fx_set.md）。
