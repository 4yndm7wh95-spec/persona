## 卡牌和动作的思路（~~铁甲战士~~ → 已改为静默猎手，见文末「改替换静默猎手」）

铁甲战士的牌偏体术、卖血、力量。P5 里正好对得上：**P5 的物理技能消耗 HP、由 Persona 打出**，名字都有重合（Cleave 就是 P5 的物理技能）。所以分三层：
1. **Joker 本人的动作**：普通攻击类（打击 = 小刀斩；~~重击 = 踢~~ 用户 2026-10-25：飞踢太怪，不用踢，重击类交给亚森或之后补一个小刀突刺）、防御（前臂横挡 / 闪身）、部分牌用枪（P5 的 GUN）。
2. **亚森出手**：伤害大的、多段的、AOE 的牌（顺劈斩、旋风斩、重锤、残杀……）= Joker 摆召唤姿势（手到脸侧、蓝焰），亚森出现挥爪 / 斩击，和 P3Makoto 的 Orpheus 一样。
3. **卖血 / 力量类**：卖血牌 = P5 物理技能耗 HP 的演出；力量 / 增益 = P5 的增益技能（Charge、Tarukaja、反叛的意志之类）。
需要的全身姿势图（第一批）：待机、小刀斩、开枪、防御、召唤（手到脸侧）、受击、倒地、胜利。每个姿势先从姿势库挑参考帧。

## 召唤演出设计（用户 2026-10-25 同意）

对标 P3Makoto 的「召唤器 → 开枪 → 玻璃碎裂」，Joker 用三拍：
1. **抓脸、面具浮现**（蓄力）：平时不戴面具，召唤时面具闪现在脸上，四周一圈**面具形状的蓝焰**（原作就有）；
2. **撕下面具、蓝焰爆发**（对应扣扳机）：顿帧 + 震屏 + 闪白，原版召唤音效 + 雨宫莲喊 "Persona!" 的原版语音；
3. **红黑撕裂、亚森登场**（对应玻璃碎裂）：背景斜着撕成红黑锯齿碎片（网点、墨块），斜插一条脸部特写切入（撕面具的大画面），碎片散开后亚森在蓝焰中展翼出手。
用户要求：面具出现和撕掉的**确认感、存在感要强**（局内人物小）→ 面具单独做成素材（art/p5/fx/mask_*），游戏里放大闪现 + 沿面具轮廓描蓝焰；再加大画面的特写切入（art/p5/cutin/）。
素材：docs/codex/codex_p5_poses2.md（summon_grab / summon_rip 全身、面具单图、两张特写切入）。

其他 P5 招牌留给大招 / 斩杀：开枪（连发火光、红色弹道、命中红黑网点冲击星、每枪震屏）、弱点 "1 MORE!"、总攻击收尾的红黑剪影定格 + THE SHOW'S OVER。

## 改替换静默猎手（用户 2026-10-25）

用户：猎人更契合 —— 猎人本来就用匕首，普通攻击就是 Joker 的小刀；猎人的「小刀」（Shiv）类牌可以用 Joker 的手枪。
新的对应（取代上面「铁甲战士 → Joker」那一节）：
- **打击 / 匕首类攻击** = Joker 小刀斩（已定的 slash 姿势）。
- **小刀（Shiv）及生成 / 打出小刀的牌** = **开枪**（gun 姿势，一张 Shiv 一发子弹；多张连射）。
- **防御** = 前臂横挡 / 闪身（guard）。
- **毒** = P5 的状态异常 / 咒怨（亚森的 Eiha 系是咒怨属性）：中毒层数 = 咒怨的持续伤害；大的毒牌由亚森出手。
- **弃牌 / 抽牌 / 偷窃感** = 怪盗的手法（手里的卡牌一翻、像偷到东西）—— Joker 本来就是怪盗，比铁甲战士更贴。
- **敏捷（Dexterity）** = P5 的 Sukukaja（命中 / 回避增益）演出。
- 伤害大、AOE 的牌 = 亚森出手（召唤演出不变：抓脸 → 撕面具 → 红黑撕裂 → 亚森）。
姿势清单不变（idle、slash、gun、guard、summon、cast、hurt、down、victory + 撕面具两张），gun 的使用频率会变高，之后可能要补连射 / 收枪的过渡。

## 毒（静默猎手）怎么体现 —— 咒怨（提案）

亚森是咒怨属性（Eiha / Eigaon / Maeiha），所以静默猎手的「毒」= **亚森的咒怨侵蚀**：
- 上毒：敌人身上浮起红黑色的咒怨火焰 / 黑雾（P5 咒怨技能的红黑 + 暗紫配色），带 P5 状态异常那种斜切的小标记；
- 每回合结算：黑红火焰在敌人身上爆一下 + 一个 P5 风格的伤害数字，层数越多火越大；
- 大毒牌（致命毒药、催化剂、毒雾这类）= 召唤亚森放咒怨技能（单体 Eiha、全体 Maeiha、加倍 = Eigaon 级的大爆发）；
- 状态图标换成 P5 状态异常风格的红黑小图标。

## 局内动画清单（静默猎手的动画接口，2026-10-25）

idle_loop、low_health_loop、relaxed_loop、attack、cast（技能 / 能力牌共用）、hurt、die、**shiv**（静默猎手独有，打出小刀牌时触发）。
另外**休息处是单独的一套骨骼**（坐在篝火旁，同 P3Makoto 的 restsite），不走这套动画。

## 待机动态（用户 2026-10-25：比结城理更强的动态）

除了眨眼和闲置扯手套，待机本身要一直在动（Claude 在接入时做 Spine 网格动画，Codex 不用出额外素材）：
- **身体**：P5 战斗待机那种有节奏的起伏 —— 膝盖微屈带动全身轻轻上下弹（约 1.6 秒一个循环），上身跟着呼吸前后微晃、重心在两脚间小幅左右移；脚锁死不动。
- **大衣下摆**：Joker 最有特点的部分，做成**几段骨骼链**的波浪摆动（像有风从右边吹来，从腰到下摆越往下幅度越大、相位依次延后），幅度明显大于结城理的外套；换姿势时下摆按弹簧甩出去再回弹。
  **用户 2026-10-25 特别强调：衣角多加节点 / 骨骼，让摆动细腻自然。** 具体：前后两片下摆各一条链、每条从腰到下摆**至少 6~8 节**（越往下越密），左右开叉处的衣角尖再各加 2~3 节小骨骼单独飘；网格在下摆区域加密（格距比身体小一半），每节权重平滑过渡，不能出现折角；相邻节相位差约 0.08~0.12 秒，形成连续的波；换姿势的弹簧甩动也按节传下去（腰先动、衣角最后到）。
- **手**：两只手各自绕手腕 / 手肘小幅摆动，节奏和身体起伏错开，不同步；右手手指偶尔微微收拢再张开（用两三张手的小贴片切换）。
- **头发**：发梢分几束各自摆动，相位错开；脸不变形。
- **高领**：领尖跟着呼吸轻轻抖。
做法同 P3Makoto rig v7（规则网格 + 区域权重；黑大衣和黑裤子颜色相同，大衣下摆 / 手的区域手工圈），但幅度和骨骼数都加大。先出预览 GIF 给用户看，再进游戏。
