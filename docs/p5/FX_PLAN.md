# 第二版（2026-10-29 上午，已被第三版取代，仅作参考）

> 用户：前两版牌特效（撕开空间的盾、亚森黑羽护盾、预告信）"不好看""太难懂"；不用贴合 P5R，自由发挥，要华丽炫酷；
> 回头看看 P3 mod 的特效为什么让人满意。下面是复盘和新的做法。旧规划附在最后，仅作参考。

## 一、为什么 P3 那套好看、P5 这几版不行

对照 `mod/src/Vfx/P3Fx.cs`、`docs/STYLE_P3R.md` 和 P3 早期被夸的那几版（召唤器、玻璃碎裂、交叉斩、冲击波、蓝蝶）：

| | P3（满意） | P5 这几版（不满意） |
|---|---|---|
| 材质 | 几乎全是**光**：加法混合的柔光、白芯 + 彩色光晕的锥形光线、着色器径向闪光 / 细光环 | 不透明的**纯色多边形**（红块、黑块、黑羽），像矢量剪贴画、像 UI 色块 |
| 细节密度 | 每次爆发几十颗 GPU 柔光粒子、玻璃碎片带棱光闪烁 | 三五片手摆的三角形 |
| 空间感 | **屏幕折射波**（把后面的画面扭一下）、冲击光环往外扩，打击有"力" | 没有，图形贴在画面上 |
| 运动 | 预备（收缩蓄光）→ 爆发（1～3 帧到峰值）→ 余韵（0.4～0.8s 慢慢散），OutExpo，错峰 20～60ms，过冲 | 有一部分，但元素本身太"实"，运动再好也显得硬 |
| 可读性 | 一眼看懂在干什么：斩 = 两道光刃、召唤 = 碎玻璃 + 蓝蝶 | 象征太绕：撕开空间、黑羽护盾要想一下才明白是"防御" |
| 题材 | 意象（水、玻璃、蝶）只当点缀 | 意象当主体（整面羽毛盾、整张卡），主体反而不是光 |

结论：**好看的根本是"光 + 粒子 + 空间扭曲 + 干脆的节奏"，题材只是点缀。**

## 二、新的视觉语言

- **主体是光**：红白发光能量。白色热芯 + 绯红光晕（加法混合），暗部用深红而不是纯黑。黑色只当对比色出现在很小的地方。
- **P5 的味道靠形状和节奏**，不靠贴图堆题材：锐利的斜切（闪电式折线、斜向速度线）、漫画式的爆发停顿、偶尔一闪的白色网点或星光。
  预告信、面具、亚森只在少数大招里当"签名"点缀。
- **调色板**：热白 `#fff4f0`、亮红 `#ff2e3b`、绯红 `#e5191c`、深红 `#5a0610`；点缀金 `#ffcf5a`（暴击 / 大招）。
- **运动法则**照搬 P3：预备 → 爆发 → 余韵；OutExpo；错峰；出现带过冲；消失不急停；普通牌 ≤ 0.9s，大招 1.5～2.2s。
- **一眼看懂**：特效表达牌的动作，不表达牌名的字面意思。

## 三、工具箱（第一步，先做）

把 P3 的积木移植到 `p5mod/src/Vfx`（保持不依赖游戏、能在预览里跑），换成红色调：
1. `Flash` 径向闪光、`Shockwave` 细光环、`Gather` 收缩蓄力环（着色器）
2. `Ripple` 屏幕折射波（空间扭曲）
3. `Sparks` GPU 柔光粒子（几十颗）
4. 锥形光线：白芯 + 红色光晕，两头尖（斩击、弹道、速度线）
5. 碎片：带棱光闪烁的锐利碎片
6. 星光 / 网点等点缀

## 四、要做的特效（每个先出预览、过了再做下一个）

1. **打击**：现在的刀光和斩痕换成光 —— 刀光是白芯红晕的锥形光弧；命中：径向闪光 + 折射波 + 两道交错光刃 + 红色火花粒子 + 一顿（震屏）。
2. **开枪**：枪口一团白热闪光 + 红色光晕；弹道是一道极细的白光；命中：小光环 + 折射小波 + 火花。
3. **防御**（获得格挡）：身前收拢一圈红光（预备）→ 一道弧形的发光能量屏障瞬间张开（白色亮边 + 半透明红光面 + 折射）→ 屏障上闪过一道光、几颗星光 → 收成光点散开。一看就是"挡"。
4. **中和**（虚弱）：敌人身上一个红色光环收紧（像被"锁定"），压下一圈暗红光波；预告信只在收尾一闪。
5. **生存者 / 抽牌弃牌类**：手边几张发光的牌影扇形展开又收拢。
6. **能力牌**：脚下一圈红光扩散 + 身后一道上升的红色光柱 + 粒子上浮。
7. **大招 / 召唤亚森**：眼神特写切入（左切入、右切出、不碎）+ 蓝焰面具 + 亚森，这一档才大量用 P5 题材。

节奏：一次只做一两个，在预览里自己逐帧看过、改到满意再给用户看。
