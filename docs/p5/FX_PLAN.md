分工：
- **新的 Codex 窗口**：特效需要的素材（从 P5R 原版里找 / 导出，找不到的才生图）→ docs/codex/codex_p5_fx_assets.md。

总原则：**能用原版就用原版**（特效贴图、音效、语音、UI 字样都从 P5R 里拿），只有原版拿不到的才生图或程序画。
P5R 的视觉语言：红 / 黑 / 白三色、斜切的锯齿形块、网点（halftone）、强烈的明暗对比、动作停顿感（命中时短暂定格）、技能名用黑底白字斜框在画面上方弹出。

亚森：**用原版**（P5R 模型 PS0201 渲成 2D 序列帧，带原版动作）。他只在召唤时出现约 1 秒、被特效包着，原版模型的粗糙不明显；也最贴合原作。

## 第一批：4 张牌（最容易做、张力最强）

| 牌（静默猎手）| 对应 P5 | 为什么先做 |
|---|---|---|
| 打击 Strike | 小刀斩（Joker 自己）| 打得最多，代表手感；特效简单（斩痕 + 命中） |
| 匕首喷雾 Dagger Spray（全体两段）| 连射（Joker 的枪）| 枪口火光 + 全体命中，节奏感强 |
| 致命毒药 Deadly Poison | 召唤亚森 → 咒怨 Eiha | 全套召唤演出（面具蓝焰、撕面具、亚森登场），张力最大，也是之后所有亚森牌的模板 |
| 灵动步法 Footwork（敏捷）| 亚森 Sukukaja（命中回避提升）| 增益类模板；短、好做 |

### 1. 打击 —— 小刀横劈（约 0.45 秒）
1. Joker 切到 slash（攻击动画）。命中瞬间：
2. 敌人身上一道**横向的白色斩痕**（原版 BES_HIT_ZAN 的斩击贴图；没有就程序画：细长的白色月牙，外圈一层红），斩痕从左往右 0.08 秒划过；
3. 命中点爆出**红黑色碎片**（锯齿三角形，往右上飞散）+ 一圈白色冲击环；
4. 命中定格 0.05 秒（hitstop），镜头轻微震动；伤害数字用 P5 风格（黑白描边、斜着弹出）；
5. 音效：原版斩击命中音。

### 2. 匕首喷雾 —— 全体连射两轮（约 1.0 秒）
1. Joker 切到 gun（shiv 动画）：每发一枪切一次 gun_recoil；
2. 枪口**火光**（原版 BES_GUN 的贴图，白黄中心 + 红色外焰，3 帧闪完）；
3. 子弹轨迹：一条很细的白线瞬间连到敌人（0.03 秒）；
4. 每个敌人身上命中火花 + 小的红黑碎片；两轮各打所有敌人一次，敌人依次中弹（间隔 0.06 秒）；
5. 音效：原版枪声（Joker 的手枪）+ 命中音。

### 3. 致命毒药 —— 召唤亚森放咒怨（约 2.0 秒，亚森牌的模板）
1. **召唤**（0~0.7 秒）：Joker summon_mid → summon_grab：面具在脸上闪现，**面具轮廓外一圈蓝色火焰**（原版召唤的蓝焰），同时从画面左侧斜插进脸部特写切入图 cutin_grab（白底红黑斜框，P5 切入的样式）；语音「ペルソナ！」；
2. **撕面具**（0.7~1.0 秒）：summon_rip：蓝焰从脸上爆开（向上的蓝色火柱，包住 Joker 全身 0.3 秒），切入图换成 cutin_rip；**亚森**在 Joker 身后升起（原版模型渲的序列帧，蓝焰里现身，红黑翅膀展开）；
3. **咒怨 Eiha**（1.0~1.8 秒）：亚森挥手 → 敌人脚下冒出**红黑色的咒怨火焰**（原版 Eiha 贴图），往上卷、包住敌人，夹着暗紫色闪光；技能名「エイハ / EIHA」黑底白字斜框从画面上方弹出；
4. **收尾**（1.8~2.0 秒）：亚森化成蓝焰消散，Joker summon_end → idle；敌人身上留下中毒标记（P5 风格红黑小图标）。
5. 音效：召唤音 + 撕面具声 + Eiha 原版技能音。

### 4. 灵动步法 —— 亚森 Sukukaja（约 1.2 秒）
1. 简化召唤：只放面具蓝焰闪一下 + 亚森半透明在身后浮现 0.5 秒（不切切入图，节奏快）；
2. Joker 脚下升起**原版 Sukukaja 的增益光柱**（原版贴图；颜色按原版）+ 向上的箭头；
3. 技能名「スクカジャ / SUKUKAJA」斜框弹出；
4. 音效：原版增益音。

## 召唤的面具 = 蓝焰面具（用户 2026-10-27，做特效时再做）
人物立绘里不画面具（summon_hold / summon_rip 都是手扶 / 扯在裸脸上）。召唤时的面具由游戏内特效渲染：**P5R 原版那种蓝色火焰勾出的面具轮廓**——白色怪盗眼罩的形状（上挑的眼角、两侧上翘的尖角）只用一圈青蓝色火焰描出来，中间半透明，火舌往上窜、边缘有亮白的芯；扶面具时在脸上燃起，撕面具时随手被扯开、火焰爆开散去。先做完所有局内人物动作，再做这个特效。
