# 打击 / 枪击 / 防御 / 选敌标记 —— 设计说明（待确认，未动代码）

## 一、从结城理 mod 学到的东西（只读了代码：mod/src/Vfx）

那边的普通特效好看，不是因为元素多，而是因为每个特效都按同一套做法打磨过：

1. **每个特效都有完整的「入 → 满 → 停 → 出」四段时间轴**，而且时间很短、很精确。
   斩击（Motifs.ArcSlash）：入 0.07s（OutExpo 划出）→ 满 0.05s（整条闪白、往外鼓一下）→ 停 0.06s → 出 0.2s
   （尾巴追着头收拢，同时变细、头端继续往前滑一点，最后头端炸成一簇光点）。
   我前几版只有「出现 → 消失」两段，没有「满」和「停」，所以看起来软、没有定格感。
2. **三层叠出来的光感**：外层大范围半透明光晕 + 中层色带 + 极细的白芯，再加一个带着运动方向的「头」（四角星）。
   我前几版是一层平涂的多边形加黑描边，所以像贴纸、像卡通。
3. **主次分明**：一个主角元素（斩痕），配角延后半拍出现（0.2s 后玻璃碎屑），再加一下闪光 + 冲击波 + 空间扭曲。
   我前几版是同一时刻堆五六种分量差不多的东西，挤在一起反而什么都看不清。
4. **和游戏同步的手感**：物理命中有 50ms 顿帧（时间流速压到 0.08）+ 轻震屏；多段攻击只有第一下顿帧（0.35s 内不重复）。
   这个比任何画面元素都更能带来打击感，我们现在完全没有。
5. **跟着骨骼走**：刀光读剑尖骨骼的真实轨迹画（Catmull-Rom 补点），永远贴着武器，不和动作错位。
6. **主题来自角色自己的技能**：格挡用的是 P3 的技能 Tetrakarn（六边形蜂巢从中心往外波浪点亮、停一会儿、从外往里熄灭），
   不是画一个盾牌物件。选敌标记是细线：两层反向旋转的圆弧 + 三个向内的指示三角 + 四角括号，OutExpo 一边旋转一边收拢入场。
7. **克制**：线都很细，颜色只有一个主色 + 白。

## 二、换成 P5 —— 做法不变，换「材质」

做法照搬上面七条，变的是材质和母题：

- **颜色**：红（#e5191c）+ 白，暗部用黑红。不用青色。光晕只做薄薄一层红色辉光，主体靠白芯和红色的硬亮边。
- **形状**：P5 偏锐利、斜切：刀光更窄、两头更尖；四角星换成又细又长的十字闪；圆形元素换成斜切的菱形 / 三角。
- **节奏**：P5 比 P3 更快、更「咔」：入场更短（0.05s），停顿更明显（定格感），出场干脆。
- **不画物件、不画卡通**：没有盾牌、没有爆炸星、没有黑描边色块。

## 三、逐个设计

### 1. 打击（Strike）

| 时刻 | 画面 |
|---|---|
| 挥刀（0.13s，动作出刀帧） | 读刀尖真实轨迹扫出一道窄长的刀光月牙：外层薄红辉光 + 中层亮红带 + 极细白芯，头端一颗细长十字闪。入 0.05s → 满 0.04s（整条闪白、微鼓）→ 出 0.15s（尾追头、变细） |
| 命中 0ms | **顿帧 50ms + 轻震**。敌人身上一道斜向斩痕，同样三层结构，比挥刀的更长更亮；同时命中点一个小的白色闪光 + 一圈很细的红色冲击环 + 轻微空间扭曲 |
| 命中 +60ms | 第二道短斩痕交叉（小一号），形成 X |
| 命中 +150ms | 余韵：斩痕头端炸成一簇红白光点，沿刀路飞出几条细速度线 |
| 结束 | 约 0.4s 内全部收干净 |

### 2. 枪击（Shiv / 开枪）

| 时刻 | 画面 |
|---|---|
| 开火（0.18s） | 枪口一个横向拉长的白色十字闪（往前长、往后短）+ 薄红辉光，0.06s 闪完；一圈很细的红环往前推出去；后坐的短速度线 |
| 弹道 | 一道极细的白热线（外面薄红辉光），头飞快到达、尾巴随后收掉，0.08s |
| 命中 | **顿帧 30ms**。白色小闪 + 细红冲击环 + 几道放射状细光刺（像子弹打进去的星形裂光），火星沿弹道方向溅出 |
| 刀扇弹射 | 保留你认可过的折线弹道，只把每个弹点的命中换成上面这套 |

### 3. 防御（格挡）—— 两个方案，选一个

**方案 A：菱形光格（推荐）**。思路来自结城理 mod 的六边形护盾，换成 P5 的斜切几何：
前臂竖起那一刻，身前一片竖长的区域里，细线勾出的红白菱形 / 三角格子从前臂位置往外波浪式点亮
（每格出现时闪白、OutBack 弹出），停 0.4s，再从外往里一格格熄灭；点亮时一圈空间扭曲往外推。
是「光」不是「物件」，没有轮廓外形，不会像盾牌。

**方案 B：锁链**。来自亚森 / 觉醒的锁链母题：前臂竖起时，几道红色光链从两侧「唰」地绷直交叉在身前，
闪一下，停一会儿，再崩断成链节光点散掉。更有 P5 的故事感，但有一点「物件」的意思。

### 4. 选敌标记

照结城理 mod 锁定框的结构，换 P5 的形状：
- 两层细线圆弧反向旋转（外层红、内层白），线宽 2～3px；
- 三个向内的细长三角指示；
- 四角括号换成斜切的折角（像 P5 菜单的斜切边）；
- 入场：从 1.7 倍一边旋转一边 OutExpo 收拢（0.3s），之后指示三角轻轻呼吸；
- 不用原版箭头贴图。
