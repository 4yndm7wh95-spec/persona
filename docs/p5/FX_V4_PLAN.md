# P5 Joker 卡牌特效 第四版规划（2026-11-02）

> 用户：对之前的特效不满意；希望大多数牌都有**贴切 Joker、华丽、惊艳**的特效；
> 特效要**在游戏里实时渲染**，不要用代码画廉价的几何体贴图。素材可以交给本机 Codex 生成 / 提取。

## 一、为什么前三版看着廉价

翻了 `p5mod/src/Vfx/`（Glow.cs、CardFx.cs、HitFx.cs、SkillFx.cs）：几乎所有画面都是
`Polygon2D`（六边形、三角形、星形）+ `Line2D`（锥形光线）+ `GradientTexture2D`（圆形柔光）拼出来的，
粒子用的也是程序生成的圆点。不管加法混合、节奏怎么调，**每个元素都是边缘干净的数学图形**，
所以看起来像矢量剪贴画 / UI 动效，不像游戏特效。

原版杀戮尖塔 2 的特效是另一套做法（`res://scenes/vfx/` 下 200 多个场景，见 research/extract_file_list.txt）：
- **手绘贴图**：刀光、火焰、烟、闪电、星光都是画出来的序列帧（flipbook），不是程序图形；
- **材质着色器**：`shaders/vfx/_util/` 里有 flipbook、erosion（按噪声溶解）、polar_coordinates（极坐标环）、hue_shift、bloat；
  一张噪声贴图 + 溶解阈值动画，就能让一团火、一道刀光"烧着散掉"，而不是整体淡出；
- **GPU 粒子**发射的是这些贴图（烟团、火星、碎屑），不是圆点；
- **屏幕级处理**：`vfx_outward_screen_distortion`（扭曲）、`vfx_screen_chromatic_aberration`（色差）、`radial_blur`、`desaturate_transition`。
- 这些场景都在游戏的 PCK 里，**mod 可以直接 `ResourceLoader.Load("res://scenes/vfx/...")` 实例化**，
  并换材质 / 改颜色（原版自己就有 `NBigSlashVfx` 之类按颜色 modulate 粒子的代码）。

结论：第四版**不再在代码里画形状**。画面全部来自贴图 + 着色器 + 粒子，代码只负责编排时间轴和摆位置。

## 二、素材的三个来源（按优先级）

| 来源 | 内容 | 用法 |
|---|---|---|
| A. 杀戮尖塔 2 原版特效 | slash / big_slash / heavy_blunt / missile / starry_impact / fire_impact / lightning / scream / ribbon / smoke 等场景和它们的贴图、着色器 | 运行时直接实例化，套一个**渐变映射重上色**材质（亮度 → 白 / 亮红 / 绯红 / 黑），变成 P5 的红黑白。质量和游戏本身一致，零美术成本 |
| B. P5R 原版贴图 | research/p5r/fx（咒怨 be0094 怨灵 / 卷轴 / 环、斩击、枪击、暴击、蓝焰、Sukukaja 等；本机还有 9326 张） + art/p5/fx/arsene 亚森序列帧 | 作为粒子贴图 / 溶解遮罩放进我们自己搭的粒子场景里，提供"原作味道" |
| C. Codex 生图 | 原版没有、又必须有的手绘序列帧：P5 风格红色刀光、枪口火焰、蓝焰面具、黑羽、预告函、红黑碎玻璃、网点 / 星芒等 | 规格照原版 flipbook（例如 4×4 / 8×8 网格、真透明底），接进同一套着色器 |

另外：**人物本体也是素材**。残影、分身、闪避用 Joker 当前帧的纹理 + 着色器（描边发光、色散、溶解），不另画几何体。

## 三、视觉语言（保留上一版里被认可的部分）

- 红 / 黑 / 白为主，白色热芯 + 绯红光晕；金色只给暴击 / 大招；亚森相关用青蓝火焰。
- P5 的味道：锐利斜切、漫画式顿帧、命中瞬间的反色 / 色差闪、网点与星芒点缀、技能名斜框。
- 节奏：预备 → 爆发（1～3 帧到峰值）→ 余韵（贴图溶解散掉）。普通牌 ≤ 0.8 秒；签名牌 1.5～2.2 秒，可在设置里跳过演出。

## 用户决定（2026-11-02）
- **Persona 一律生图**（Codex），不再用原版模型三渲二（太别扭）。亚森、八岐大蛇先出草图给用户确认，再拆层在游戏里做 2D 骨骼 / 网格动画。
- **细节素材不用代码画**：预告函、面具、刀光、羽毛等，先从 P5R 原版找，找不到就 Codex 生图。
- 要**惊艳、有视觉冲击力、华丽、有确认感**：每次命中都要有顿帧 + 定向震屏 + 受击白闪 / 击退，重击和击杀有全屏冲击帧（Vfx/Impact.cs，已做第一版）。
- 跳过演出的开关以后再说。

## 打击确认感的分档（2026-11-02，p5mod/src/HitWeights.cs + Vfx/Impact.cs）
用户：太频繁容易花眼、看腻 → 看牌为主、看伤害为辅，少而重。

| 档 | 什么时候 | 效果 |
|---|---|---|
| 轻 | 小刀（子弹）每一发；多段攻击的前几下 | 短顿帧（0.3 秒内连着来只顿第一下）、轻震、白闪、小击退、一点色散 |
| 中 | 普通单发攻击；多段攻击的最后一下 | 顿帧、定向震屏、白闪转红、击退、色散 + 径向模糊 |
| 重 | 大招类攻击牌（刺杀、谋杀、铭记死亡、狩猎、华丽收场、猎杀者、串刺 / 终结技的最后一下） | 中档全部 + 全屏红黑白冲击帧 |
| 击杀 | 打死一个敌人（还有别的活着） | 冲击帧（短），不做白闪 / 击退，交给死亡动画 |
| 战斗结束 | 打死最后一个敌人 | 冲击帧停久一点、最重的顿帧和震屏；以后精英 / Boss 的最后一击接总攻击 |

- 只升不降：轻击打出 12 点以上升到中；任何一下 25 点以上、或 15 点以上且打掉当前血量三分之一，升到重。多段攻击的前几下最多升到中。
- 群攻：一次结算打中好几个敌人，白闪 / 击退各自做，顿帧 / 震屏 / 冲击帧整组只放一次（按最重的一下）。
- 红黑冲击帧 1 秒内最多一次（击杀 0.4 秒，战斗结束不限），超了只留顿帧和震屏。
- 数字之后在实机里再调。

## 五、做法和顺序

0. **取原版特效素材**（Codex，见 docs/codex/codex_p5_sts2_vfx_extract.md）：把 `scenes/vfx`、`materials/vfx`、`shaders/vfx`、
   `images/vfx`、`images/packed/vfx` 及依赖解出来放进 research/sts2_vfx/，让 Claude 能读场景结构、在云端 Godot 里离线预览。
1. **工具层**（Claude）：`VanillaFx.Spawn(场景, 位置, 重上色, 缩放, 旋转)`、渐变映射重上色材质、flipbook / 溶解 / 极坐标材质、
   屏幕扭曲 / 色差 / 反色闪、人物纹理残影。旧的 Polygon2D / Line2D 积木逐步删掉。
2. **样板三张**（Claude）：打击（刀组）、投掷匕首（枪组）、致命毒药（咒怨组），在云端渲成 GIF 给用户定方向。
3. **补图**（Codex 生图）：看完原版素材再开清单（只补缺的），规格照原版 flipbook。
4. 方向通过后逐组铺开，每组先出 GIF 预览，用户过目后 Codex 编译安装实机看。
5. 最后做签名牌。

预览：tools/p5/fxpreview（云端 Godot 4.5.1 渲染 GIF）。原版素材解出来以后预览里也能实例化原版特效场景。
