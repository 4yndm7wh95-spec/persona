# P5Joker 特效规则（2026-11-02 起，所有新特效照这份做）

来源：用户最喜欢的是结城理 mod 的「召唤器开枪」和「君王之剑」。做法照搬那边被验证过的结构和参数，只换材质。

## 1. 结构：一拍一个最满的瞬间
- 每个大动作只有一到两个「拍」。拍上同时压：顿帧 80–90ms、震屏、闪光、大折射波、朝一个方向喷的玻璃碎片、粒子、分层音效。
- 拍前后都干净，不要在拍之外再堆东西。
- 召唤牌两拍（召唤器 → 君王之剑的结构）：
  - 拍 1「召唤」：眼神特写撕开后停一下（SummonStage.EvokeAt），从 Joker 面具朝人格面具一道贯穿光 + 锥形玻璃 + 蓝焰 + 黑羽（Evoke.cs），特写同时碎开，人格面具从蓝焰里现身。
  - 拍 2「出手」：人格面具出手 = 结算，各张牌的命中特效自带顿帧和冲击声。

## 2. 方向和因果
- 碎片、光束、粒子都有方向（从谁射向谁）。人格面具的攻击要看得见「过去」（手伸过去 / 冲过去），再命中。

## 3. 材质（只用这一套）
- 光：白芯 + 红色光晕（加法），人格面具相关用蓝焰（PersonaMask 配色）。
- 玻璃：锥形碎片，强阻尼悬停、转到角度闪棱光。
- 羽毛：亚森的黑羽（代替结城理 mod 的蓝蝶）。
- 不用：卡通爆炸星、粗黑描边色块、墨笔、平涂几何拼凑。

## 4. 声音
- 每个动作分 预备 / 冲击 / 余韵，冲击最响，同一时刻最多两三个声音。
- 常听的牌（普通牌）用短而干净的声音；长、杂的声音（damage_critical）只给有眼神特写的大招。
- 不要：翅膀声（像直升机）、挥动声（像鞭子）、选牌提示音、连发枪声。

## 5. 流程
- 一次只做一个特效，做到用户满意再做下一个；先给带音效的预览视频。
- 需要细腻造型的东西（手）才让 Codex 生图，动态全部实时渲染。
