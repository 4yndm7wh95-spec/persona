## 草图怎么看
- **红色 = 右手右腿**（离镜头近，在画面左边）；**蓝色 = 左手左腿**（离镜头远）。黑色是躯干和肩。
- 头上的短线是**脸朝的方向**（全部 3/4 朝画面右方，敌人在右边）。
- 灰线 = 小刀，深灰粗线 = 枪，白色椭圆 = 面具。底部灰线 = 地面（y = 1470），所有站姿的鞋底都踩在这条线上。
- 草图只定**关节位置、重心和手脚在哪**；人物比例、服装、画风一律以 idle_a 为准。头部大小、身高和 idle_a 一样（站直时头顶约 y = 80）。

## 角色感觉
Joker 是**轻、快、有表演感的怪盗**：动作干脆、收放分明，重心低时像猫，站直时从容、带一点挑衅的笑。大衣下摆是他最显眼的轮廓，动作大的姿势让下摆跟着甩出去。
所有姿势：视线顺着脸看向画面右方的敌人（虹膜在眼睛中间略偏右、两边都有眼白、有高光；受伤 / 倒地除外），背是直的（受伤 / 倒地除外），脸以 art/p5/ref/face_standard.png 为准。

## 逐张设计

### 待机 / 商店 / 休息
- **idle**：沿用 idle_a（用户已认可身体），只修眼睛。待机的弹跳、衣摆、手、头发都由 Claude 做骨骼动画，不再出图。
- **relaxed**（商店）：母版 joker_master_a 的站姿（左手插兜），只按视线规则改头和眼。
- **rest_sit**（休息处，单独骨骼）：按 docs/codex/codex_p5_poses3.md 的说明（坐地、右膝立起、右手拿 LeBlanc 白色咖啡杯）。
- **idle_blink_patch**：idle 的闭眼小贴片。

### 防御（cast 防御）
- **guard_mid**：右前臂抬到胸前一半，拳头在胸口高度；重心开始往后腿（右腿）移。
- **guard**：重心压在后腿（右腿往画面左后方撤一步、膝盖弯），左腿在前；**右前臂竖着挡在脸和胸前偏右**，手背（红手套）朝敌人，拳头和头顶差不多高；左拳收在腰侧。下巴收、眼睛从手臂旁边盯着敌人，嘴角紧。像接下了一记重击还很从容。

### 小刀斩（attack）—— 用户 2026-10-25 最终定的动作：反手握刀，从右前下方往左前上方斜撩
（之前的正手版本、「横劈」「弓步斜劈」全部作废。）
方向按**人物自己的朝向**说：人物脸朝画面右方 = 正前方；人物的右边 = 离镜头近的一侧，左边 = 离镜头远的一侧。

**握法：全程反手**。右手拳头攥住刀柄，**刀身从小指那一侧伸出来**；刀刃朝外（背离前臂那一边）。
**拳头怎么握（用户 2026-10-26：slash_a 握持不对）**：上一版的手是四根手指顺着刀柄方向从上面「搭」在刀柄上、柄头从食指上方戳出来一大截，像从上面捏着刀柄，不是攥着。正确的反手握：
- 刀柄**横穿过拳心**：四根手指从刀柄一侧绕过去、把刀柄整个包在掌心里，指尖扣回到掌心（握紧的拳头）；**手指的方向和刀柄垂直**，不是顺着刀柄搭着。
- 从画面这个角度看到的是拳背：四个指节横着排成一排，**指节这一排的方向和刀柄平行**。
- **拇指**压在拳头上端、盖住柄头，柄头最多露出一点点；刀柄大部分藏在拳头里（刀柄只有拳头那么宽）。
- **刀身**从拳头小指那一端伸出来，护手紧贴着小指下缘。
- **手腕是直的**，拳头和前臂在一条线上，不往下折、不往后翘。
**刀身不要贴着前臂（用户 2026-10-26）**：刀身和前臂之间要**张开一个明显的角度（约 60°~90°）**，刀和手臂之间能看到一块空隙，从画面上看刀身是单独伸出来的一根，不和袖子的轮廓重叠。手臂抬起时（挥动中、终点、收势）刀身**大致竖直朝下**从拳头底下伸出来，而不是顺着前臂往手肘方向躺。透视上如果前臂是斜着朝镜头的，刀身要画成朝镜头外侧伸出来，避免看起来贴在袖子上。刀用原作 Joker 那把小刀（黑色刀柄、银色单刃，刀身约 20cm）。

**动作**：右手从**人物右前方 45°、腹部高度**出发，反手往**人物左前方 45°、斜向上**撩过去（从身前近侧的低处，斜着横过身体，挥到远侧的高处）。身体跟着从「打开」转到「合上」。

**左手（用户 2026-10-25：尽量自然）**：四张都是自然垂在身侧、手肘微弯、手指放松，随身体转动前后小幅摆动；不要伸手瞄准、不要张开五指、不要刻意甩到身后。
**腿脚（四张一样，脚掌不动）**：前后分腿站，**两脚距离约 1.2 个肩宽（不要太宽，不要劈叉式的大弓步）**；两膝都微弯、放松，像随时能跳开；重心随动作从后腿移到前腿。草图里前脚比后脚略高是透视。
**上身**：始终微微前倾（头在胯的前上方），**不要后仰**。

- **knife_ready（起点，蓄力）**：右手反握小刀放在人物右前方、腹部高度（画面上在躯干前面、靠近镜头这一侧、腰带高度），手肘收在身侧；刀身从小指侧朝下、略往后（画面左下）；上身往右转开（胸口更朝镜头），右肩往后拉；重心在后腿；左手自然垂在身侧、手肘微弯、手指放松；头稍低，眼睛盯着敌人。
- **slash_smear（挥动中，0.05 秒）**：**右臂伸出去、离身体远一点**（手在胸口高度、躯干前方约一个前臂远，手肘离开身体），手往远侧斜上方走——手贴着身体发不出力（用户 2026-10-25）；上身开始往左转；手臂和刀画成一道**从身前右下到远侧左上的斜向弧形残影**；刀仍是反手，刀身拖在手后面。
- **slash（终点，打出去）**：右臂反手挥到人物左前方斜上方，手在头的右前上方（画面上在头的右上方，**手肘微弯，不要整条手臂僵直地举着**）；刀身从拳头小指侧**大致竖直朝下**伸出（和前臂张开明显角度、不贴袖子），刀刃朝外；上身转过来合上（右肩冲到最前，能看到一点右肩的背面）；重心压到前腿、前膝弯、后腿蹬直；左手自然垂在身侧略往后（不要刻意甩开）；大衣下摆往后甩。头和眼睛始终盯着敌人。
- **slash_follow（收势）**：手臂顺势落到胸口高度，还是反手；上身稍微转过头一点，然后回 idle。

**节奏（用户 2026-10-27：出刀即攻击，掏刀后不要停顿）**：取刀 0.05 → 起势 0.05 → 起点 0.06（不停）→ 残影 0.04 → 斩停约 0.22 秒；旧写法「蓄力停约 0.2 秒」作废。原：蓄力停约 0.2 秒 → 挥动中 0.05 秒（残影）→ 打出去那一帧停约 0.2 秒（游戏里命中、定格、震屏，整个人往前冲约 30px）→ 收势 0.15 秒 → 回待机。预览：art/p5/ref/plan/slash_timing.gif。

**上一版成图（正手、大弓步）为什么怪**：腿分得太开像劈叉，上身却往后仰（重心和动作方向相反）；出刀的手臂整条僵直地举着，像在举手，不像砍完。这一版都改掉了。

### 开枪（shiv）—— 用户 2026-10-26 定的动作：选中小刀牌就侧身举枪，打出时开一枪
**现状（2026-10-26）**：瞄准 = gun_a2（用户通过，原版 52 号、相机转 50%）；拔枪 = gun_raise_a2（以 gun_a2 为底图编辑，一致性检查通过）；**收枪直接倒放拔枪那张**（原版收枪的关键姿势就是手翻上来经过脸前，和拔枪几乎一样，不再单独生图）；**后坐 = gun_recoil_a3，由 tools/p5/gun_recoil.py 从 gun_a2 脚本做出**（手腕上挑 + 整条手臂从肩膀抬起，身体像素不变）——生图两次失败：一次被当成暴力内容拦截，一次画成双枪。后坐只闪 0.08 秒，代码另加枪口火光和震动。
**照原版来（用户 2026-10-26 确认）**：P5R 原版的开枪就是 research/p5r/pose 的 51（拔枪 main[53]）→ 52（瞄准保持 main[54]）→ 53（开枪 main[55]）→ 54（收枪 main[56]）。四张图的姿势以原版为参考（Codex 按 docs/codex/codex_p5_gun_ref.md 挂枪、换成我们的视角渲出来再画）。和下面草图不同的地方以原版为准，特别是**后坐**：原版手腕大幅上挑、几乎到头顶，大衣下摆被带起来；**收枪**：手往上翻、经过脸前收回。
**触发**：**选中小刀牌（开始选目标）时**举枪并保持瞄准；打出这张牌时**开一枪**（一张小刀牌 = 一枪）；然后收枪回待机。选中后又取消（没打出）就直接收枪。连续打几张小刀牌就每张开一枪（同结城理举召唤器 aim_in / aim_loop / aim_out 的做法）。
**站姿**：人物**向自己的左边侧过去一点**（左边 = 离镜头远的一侧，侧完身体更接近侧面朝右）；**站直**，两膝基本伸直；**双脚收拢**，两脚距离约 0.8 个肩宽，不要分得很散。
**左手**：自然向下伸直，**手掌贴在自己的左大腿外侧**。
**右手**：单手握黑色手枪，**把枪笔直送出去对着敌人**：右臂在肩膀高度水平伸直，肩—手腕—枪口一条线，枪口朝画面右方；食指伸直贴在扳机护圈外侧（不扣扳机，立绘道具的拿法）；手腕直。头顺着手臂看出去，表情冷静。
- **gun_raise（举枪，过渡帧）**：右手从右胯前把枪抽出、举到一半（枪口朝前下方）；身体开始往左侧过去；脚正从 idle 的站距收拢到一半。
- **gun（瞄准，关键帧）**：上面的完整姿势。选目标期间一直停在这一张（游戏里加呼吸微动）。

### 召唤亚森（cast 亚森）—— 右手撕面具，撕完亚森就去攻击，不再有「指向」
**（用户 2026-10-26 重排：身体也要跟着动）** 扣面具时整个人往下压、蓄力（膝盖更弯、胯更低、上身微微前倾含胸，手肘朝画面左外侧抬到头那么高）；撕面具时从蓄力里**弹起来**：胯升高、胸口挺出去打开、头微仰，右臂把面具从脸上扯开到**大约一个前臂远**（手在头的左上方、近侧肩膀上方，手肘弯着，不要整条手臂甩直、甩到很远——用户 2026-10-26：太夸张）。左手：扣面具时在身侧、手指绷紧；撕的时候顺势往右下方张开，不要夸张。
**节奏**：抬手 0.1 秒 → 扣面具 0.45 秒（面具浮现 + 蓝焰 + 切入图）→ 撕面具 0.7 秒（停住，亚森出手）→ 收手 0.15 秒 → 待机。预览 art/p5/ref/plan/summon_timing.gif。

- **summon_grab**：**面具出现在脸上**。身体压低蓄力（膝盖弯、上身微前倾、背直），头微低；**右手手肘抬到和头一样高、朝画面左外侧张开，手掌从脸的近侧（画面左边那侧）扣住面具边缘**，手指张开压在面具上；面具大部分露在外面，白色要亮、比例略大；眼睛从面具眼洞里锐利地盯着右方；左手在身侧张开、手指绷紧。
- **summon_rip**：**一把撕下**：身体从蓄力里弹起、挺直，头微仰（脸仍朝右，完整露出），嘴角咧开笑或咬牙；**右臂把面具从脸上扯开到大约一个前臂远**：手在头的左上方、近侧肩膀上方，手肘弯着，面具捏在手里、离脸一个前臂左右（用户 2026-10-26：甩直甩远太夸张）；左手向右下方张开五指；两脚分开站稳；大衣下摆和头发被一股向上的气流掀起。这一帧停住，亚森在这时出手攻击。
- **summon_end**：收手：右手放下到腰侧、手里没有面具（游戏里面具化成蓝焰消失），大衣和头发落回，站回接近 idle。
