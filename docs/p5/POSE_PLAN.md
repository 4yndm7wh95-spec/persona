# P5 Joker 局内姿势规划（Claude 设计，用户 2026-10-25）

用户决定：**不再参考 P5R 原版的姿势**（art/p5/ref/pose/ 下的原版渲染图全部停用），姿势由 Claude 规划，和做结城理时一样。
草图：art/p5/ref/plan/<姿势名>.png（1024×1536，和姿势图同一画布）；总览 art/p5/ref/plan/pose_plan.png。脚本 tools/p5/pose_plan.py。

## 草图怎么看
- **红色 = 右手右腿**（离镜头近，在画面左边）；**蓝色 = 左手左腿**（离镜头远）。黑色是躯干和肩。
- 头上的短线是**脸朝的方向**（全部 3/4 朝画面右方，敌人在右边）。
- 灰线 = 小刀，深灰粗线 = 枪，白色椭圆 = 面具。底部灰线 = 地面（y = 1470），所有站姿的鞋底都踩在这条线上。
- 草图只定**关节位置、重心和手脚在哪**；人物比例、服装、画风一律以 idle_a 为准。头部大小、身高和 idle_a 一样（站直时头顶约 y = 80）。

## 角色感觉
Joker 是**轻、快、有表演感的怪盗**：动作干脆、收放分明，重心低时像猫，站直时从容、带一点挑衅的笑。大衣下摆是他最显眼的轮廓，动作大的姿势让下摆跟着甩出去。
所有姿势：视线顺着脸看向画面右方的敌人（虹膜在眼睛中间略偏右、两边都有眼白、有高光；受伤 / 倒地除外），背是直的（受伤 / 倒地除外），脸以 art/p5/ref/face_standard.png 为准。

## 逐张设计

### 待机 / 商店 / 休息
- **idle**：沿用 idle_a（用户已认可身体），只修眼睛。待机的弹跳、衣摆、手、头发都由 Claude 做骨骼动画，不再出图。
- **relaxed**（商店）：母版 joker_master_a 的站姿（左手插兜），只按视线规则改头和眼。
- **rest_sit**（休息处，单独骨骼）：按 docs/codex/codex_p5_poses3.md 的说明（坐地、右膝立起、右手拿 LeBlanc 白色咖啡杯）。
- **idle_blink_patch**：idle 的闭眼小贴片。

### 防御（cast 防御）
- **guard_mid**：右前臂抬到胸前一半，拳头在胸口高度；重心开始往后腿（右腿）移。
- **guard**：重心压在后腿（右腿往画面左后方撤一步、膝盖弯），左腿在前；**右前臂竖着挡在脸和胸前偏右**，手背（红手套）朝敌人，拳头和头顶差不多高；左拳收在腰侧。下巴收、眼睛从手臂旁边盯着敌人，嘴角紧。像接下了一记重击还很从容。

### 小刀斩（attack）—— 从左上往右下的一刀斜劈
- **knife_ready**：膝盖弯、重心下沉；右手从腰后把小刀抽出来，刀尖朝前下方；左手抬到胸前偏前方，手掌张开像在瞄准。
- **knife_windup**：蓄势。右手持刀**高举到头的右后上方**（手在画面左上，刀刃朝后上），手肘朝上；左手向前伸向敌人（手掌张开，瞄准）；身体微微后仰，重心压在后腿（右腿），前脚（左脚）只用脚尖点地。
- **slash_smear**：和 slash 同一姿势，持刀手臂画成从左上到右下的一道弧形残影。
- **slash**：**弓步向前冲出一刀**：左脚大步踏向画面右方（脚在 x≈830）、膝盖弯成弓步，右腿在后伸直蹬地；上身前倾但背是直的，头抬起盯着敌人；右臂从上往下斜劈到身体右前下方、基本伸直，刀刃朝右下，刀身完整可见；左手握拳收在胸前。大衣下摆往后（画面左方）甩开。
- **slash_follow**：刀继续顺势往下、刀尖朝地；上身开始回正，弓步还没收。

### 开枪（shiv）
- **gun_raise**：右手从腰侧把枪拔出、枪口朝右前方斜下 45°；眼睛已经盯着敌人。
- **gun**：两脚与肩同宽侧身站稳；**右臂水平伸直指向画面右方**（手臂横过胸前，肩—手腕—枪口一条直线），枪口朝右；左手自然垂在腰侧（或插兜）；头微侧，顺着手臂瞄准，表情冷静带笑。单手持枪，从容，不是警察式双手持枪。
- **gun_recoil**：手腕连枪上扬约 15°、右肩微微后震，其他同 gun。
- **gun_lower**：右臂放下，枪口朝地，在腰前。

### 召唤亚森（cast 亚森）—— 右手撕面具，撕完亚森就去攻击，不再有「指向」
- **summon_mid**：右手抬到胸前、手心朝脸，正要伸向脸；膝盖开始弯。
- **summon_grab**：**面具出现在脸上**。身体压低蓄力（膝盖弯、上身微前倾、背直），头微低；**右手手肘抬到和头一样高、朝画面左外侧张开，手掌从脸的近侧（画面左边那侧）扣住面具边缘**，手指张开压在面具上；面具大部分露在外面，白色要亮、比例略大；眼睛从面具眼洞里锐利地盯着右方；左手在身侧张开、手指绷紧。
- **summon_rip**：**一把撕下**：身体从蓄力里弹起、挺直，头微仰（脸仍朝右，完整露出），嘴角咧开笑或咬牙；**右臂猛地甩向画面左上方、几乎伸直，面具捏在手里**（离脸一臂远）；左手向右下方张开五指；两脚分开站稳；大衣下摆和头发被一股向上的气流掀起。这一帧停住，亚森在这时出手攻击。
- **summon_end**：收手：右手放下到腰侧、手里没有面具（游戏里面具化成蓝焰消失），大衣和头发落回，站回接近 idle。

### 扯手套（cast 增益 + 待机闲置动作）
- **glove_mid**：右前臂抬到腰前一半，左手正伸过去。
- **glove**：站直；**右前臂向前弯起、抬到胸前**（手肘弯、右手手背朝上、手指放松）；**左手捏住右手手套的手腕处往里扯一扯**；头微低但眼睛仍看着右方，嘴角带笑。
- 胜利姿势不单独做（游戏没有胜利动画接口），需要时用 glove。

### 受击（hurt）
- **hurt_impact**：被打中的第一帧：肩膀猛地一缩、上身往后一顿，双手本能地收到胸前，眼睛眯起、咬牙。比 hurt 的后仰小。
- **hurt**：沿用 hurt_a（用户已认可）。
- **hurt_recover**：站回接近 idle，上身还略往后、手放下一半，皱眉但眼睛重新盯住敌人。

### 死亡（die）
- **die_kneel**：右膝跪地（右小腿贴地），左脚在前撑着；上身往前垮、头垂下；右手撑在地上，左手搭在左膝上。
- **die_fall**：撑不住，身体向画面左后方倒下：后背着地一半、头在左边，两膝还弯着。
- **down**：仰面倒在地上，头在画面左边、脚在右边，两膝微微立起，右手摊在地上、左手搭在胸口；大衣铺开；眼睛闭上。整个人在画布下部、横向放得下（不超出 1024 宽）。
