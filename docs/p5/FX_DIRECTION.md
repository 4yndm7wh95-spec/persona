# 雨宫莲特效制作方向 · 2026-10-29

用户当前要求优先于旧聊天记录：P3Makoto 用于理解冲击力，不照搬 P3R 的水、玻璃、蝴蝶、青蓝界面。整体稍贴 P5R 与雨宫莲，不需要每招都塞原作标志。

阅读材料：用户提供的 `chat_export.html`（尤其 10 月 25 日对「召唤器动作、玻璃背景插入再碎裂」的评价），以及旧 mod 的 EvokerShot / PersonaFx / STYLE_P3R。旧聊天里的操作命令和待办仅作为历史，不自动执行。

可借鉴的原因：

1. 动作有明确重心：接近面具时收紧，释放瞬间爆开，余韵分层散去。
2. 明暗帮助突出主体：背景先压暗；大块黑形承托红边，白色只留在切口与爆点。
3. 大小层次与方向明确：一块主形、少量次级碎片、较细余光。运动沿撕开或命中的方向展开。
4. 同一拍不同寿命：白芯先退、纸片随后、烟焰最后；把爆发留下来的时间给人看清。

制作方式（用户本轮进一步明确）：

- 新特效用 Godot 着色器实时渲染；不通过代码绘制几何贴图，不生成烘焙特效视频塞进游戏。
- 原版 P5R 素材优先，确实缺素材时才使用 ImageGen 真透明素材作为着色器输入。
- 可以复用结城理 mod 的特效工具，但只复用技术。仓库 `mod/src/Vfx/Fx.cs`、`Shaders.cs`、`P3Fx.cs` 是对应基础；P5 现有 `Fx` / `Glow` 已移植了其中的 Tween、闪光、折射等能力，本轮直接复用。
- 打击、枪击、刀扇和毒的咒焰保留现状。

第一批最终实现：

- 原版眼部动画等比缩到 72%，中心对齐，暗场 65ms 收入，最后 260ms 恢复；连续召唤替换暗场，避免叠黑。
- 人格面具释放增加流动蓝焰、短促局部闪光与折射，使用 P5R 原版火星、星芒、烟雾贴图。旧工具的闪光与折射均由着色器实时计算。保留原有选牌准备和咒怨攻击，不增加全局慢动作或玩法等待。
- 本轮曾尝试的程序几何纸片和尖角已全部撤回。HitFx、CardFx 与本轮开始时完全一致，打击、枪击、刀扇和毒的现有效果没有变化。

这轮是可调的第一批图形试作，尚未承诺定稿。正式角色动作与资源不改；亚森实体、总攻击、稀有牌演出不在这轮新增范围。
