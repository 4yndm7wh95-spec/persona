要点：
1. 每一段都有一个看清楚的停留（≥0.5s），段和段之间是硬切或者擦入；没有任何东西是"一闪而过"。
2. 立绘卡是**硬切**进来的。冲击力来自前面的铺垫（白闪 → 红底留白 → Joker 落地 → 扯手套），以及"扯手套"这个动作从 3D 直接接到立绘上的对接。
3. 原版卡的左下就有敌人的黑剪影（原版数据里的 shadow_Point 那一层），和我们放怪物剪影的位置一致。
4. 乱斗是在抽象的红底舞台上打的，不是把战场染红。

## 5. 用户决定（2026-11-18）

不要乱斗（S2），也不要 Joker 落地（S4）。节奏照 P3 mod：**最后一击切立绘**，总长约 3.3s：
- 0–0.15 最后一击定格（伤害数字还在）；
- 0.15–0.45 裂纹从撞击点先炸开一圈、再越长越快地爬满全屏，同时画面往撞击点慢慢推近；碎开前 0.12s 微微发抖（这 0.4s 就是 P3 水波那段的蓄势）；
- 0.55 碎开：立绘卡在玻璃片后面硬切进来（没有空红底），白闪 + 撞击点巨大的白色四角星，整张卡从放大压回、震屏；怪物剪影同一拍砸进左下，紧接着喷黑血；
- 定格到 2.75，黑墨盖住再挖开接结算。
