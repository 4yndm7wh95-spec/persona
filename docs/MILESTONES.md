# 里程碑

## v0.13.0 —— 重大版本（基本过关）

基线：v0.12.30 的实机测试通过（用户确认"基本过关"），在此基础上加选人界面首次进入的预热，记为 v0.13.0。
之后如需回退到一个"整体可用"的状态，以这一版为准。

### 这一版包含
- **人物**：v7 整图换帧骨骼；轻施法收手 4 张补帧（按头部对齐、按原画调色、柔和溶解 + 掌心余光掩饰差异）；
  施法 → 待机不再用骨骼混合过渡（换图类骨骼会被提前切走）。
- **金卡独属演出**：暴政（P3R 多层斜切面板：跑马灯 / 影时间远景 + 塔尔塔罗斯 / 钟停 0:00 点火 / 倒影 / 玻璃碎片，错开切入 + 惯性滑动）、
  创世纪（光笔画出星系 → 坍缩 → 辉星落下，不用召唤器模板）、铸剑者（光之砧 + 锻炉 + 四连锤 + 淬火 + 新剑入手）、
  迫降、天际钻头、王之凝视、熔炉、创世之柱（天鹅绒门）、虚空形态（影时间天色 + 月亮）、月面射击等。
- **蓝色品质以上的卡**：均有独立特效（Uniq / Bold / Rares / ThemeFx），抬手类牌不再挥剑。
- **攻击类修正**：传承之锤 / 锻打成型共用抡锤（握点在敌人左上方空中，锤头砸在头顶）。
- **UI**：胜利结算（无圆框、斜切面板 + 出血立绘 + 错开剪影）、回合横幅（平涂双色圆）、多段伤害数字固定落点循环。
- **抗锯齿**：描边统一走 Fx.Stroke / StrokePts（Line2D 的抗锯齿在游戏里无效）。
- **绘制顺序**：back 层的全屏根节点不能用 TopLevel（会画到人物前面）。

### 已知小问题（v0.13.0 时）
- 选人界面首次进入仍可能有轻微掉帧 —— v0.13.0 扩大了预热范围（Spine 立绘实例化、夜空 / 扫光 / 粒子着色器、介绍板字体与文字栅格化），待实测。
