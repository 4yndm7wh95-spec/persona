# P3R 视觉风格准则

所有特效、动作、UI 动效都以 Persona 3 Reload 为参照。写代码和调参时逐条对照。

## 1. 色彩
| 名称 | 色值 | 用途 |
|---|---|---|
| Abyss 深海蓝 | `#071a4a` | 暗部、色带底色 |
| Royal 皇家蓝 | `#1f5cff` | 主色、大面积光效 |
| Cyan 青 | `#39d8ff` | 高光、线条、粒子 |
| Ice 冰白 | `#d8f4ff` | 核心高光、玻璃碎片 |
| Dark Hour 影时间绿 | `#6dff9e` | 能力牌、影时间相关 |
| Blood 警示红 | `#ff2a4a` | 仅用于极少数点缀（暴击、S.E.E.S. 臂章元素） |

原则：蓝白为主，高光一律偏冷；只用加法混合发光，不用暖色光。

## 2. 运动（"丝滑感"的来源）
- **缓动**：位移和缩放默认用 `OutExpo` / `OutQuint`：快速出手，长尾减速收住。禁止线性运动。
- **预备 → 爆发 → 余韵**：每个特效分三段。预备 0.08~0.15s（向内收缩、蓄光），爆发 1~3 帧内到达峰值，余韵用 0.4~0.8s 慢慢消散。
- **错峰**：同一特效的多个元素起始时间错开 20~60ms，避免同时出现显得生硬。
- **过冲**：出现时缩放从 1.6 收到 1.0（OutExpo），或者 OutBack 轻微回弹。
- **不急停**：消失用透明度加缩放的组合，时长不少于 0.15s。

## 3. 造型语言
- **锐利几何**：平行四边形色带、斜切线、细线圆弧、三角指示符，不用圆润卡通形状。
- **水与玻璃**：P3R 的主题意象是水面和玻璃。冲击波用屏幕折射（扭曲后方画面并带轻微色散），召唤器发动时玻璃碎片带棱光闪烁。
- **蓝蝶**：天鹅绒房间的意象，用于点缀和过渡，不要太多（一次 2~6 只）。
- **速度线**：爆发瞬间的放射状速度线，出现快、收得也快。

## 4. 节奏
- 普通牌特效总长 ≤ 0.9s，不能拖慢出牌节奏。
- 大招（S 级）可以到 1.5~2.2s，带全屏色带切入。
- 预备出牌的常驻效果要"安静"：慢速旋转、低透明度，悬停敌人时才给强反馈。
