# P3Makoto 卡牌插画 v4（待用户审查）

本轮91张候选全部收齐；另保留此前认可的 falling_star、defend_regent、glow 三张。最后13张从原生图目录回收，无重复生成。所有本轮候选均待用户审查，没有自动通过或直接接入游戏。

## 最新修正

- genesis：只留单手触碰金色星光。
- gather_light：只留双手与金色星光。
- heavenly_drill：主角更正为机械俄耳甫斯。
- pillar_of_creation：按最新指令改为无人物的天鹅绒之门特写；修脸版已被用户要求取代，仅归档。

## 技术核对

91张均为1000×760不透明RGB。生成大图按等比缩放/居中裁切，无拉伸。三张认可原图按字节保留于retained/，SHA256与原protected.json一致。原版两张竖图在对照中等比留边显示。旧v3文件、代码、运行资源和其他未提交素材不修改。
