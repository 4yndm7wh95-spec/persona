## 严格自检结果与未解决项

**本批未通过全部严格检查，不应直接标为已验收成品。**

- 背景有实际 alpha=0 透明区域，合成到白/深蓝底能看见透明轮廓；仍有低 alpha 杂点及少量轮廓毛边，未擅自抠图清理。隐藏 RGB 颜色不能作为透明度判断依据。
- 纯白要求未通过：以 alpha>127 且 RGB 各通道>=240 作为“近白”定义，近白像素 203656，其中精确 #FFFFFF 16885，非纯白近白 186771。imagegen 的纯白修正没有消除全部近白噪点；这会影响依赖精确白色匹配的着色器。请在新派生接入资产或容差策略中处理，勿声称本图已纯白。
- 构图大体为左下倒挂、顶部出血、右侧透明；叠参考仍有位移和比例差别，脸及飘带没有逐像素复刻。白色身体/胳膊略窄长，手部比参考明显且偏大；需 Claude 接入评估。
- 主青眼以外仍可见另一只眼的一小部分，本批只给主眼制作眨眼。
- 手部已目视检查，未见明显多余关节，指尖透视/重叠仍需审美验收。
- 约三条主黑色飘带及少量发丝，未把细发丝都标作独立飘带。主要发梢向右漂散幅度比文字目标小。
