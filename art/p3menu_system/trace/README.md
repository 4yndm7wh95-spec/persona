# 设置立绘：认可头发结果的完整画布交付

## 来源与贴回
使用第三次头发编辑的原始结果 `exec-4a65edc6-ed83-4855-8ce3-9feebf7985ef.png`（1632×964 RGBA）。本次交付没有重新生图，没有填平深色阴影。

生成输入来自 base_portrait.png 的裁切框 (0,560,880,1080)，尺寸 880×520。使用 Lanczos 将认可结果还原到该裁切尺寸，再贴回原画布：横向比例 0.5392156862745098，纵向比例 0.5394190871369294，偏移 (0,560)。比例的微小差异来自生成结果尺寸取整。

仅采用 edit_region.png 白色范围内的头发像素；范围外及范围内的脸、眼睛、耳机、衬衫、线条均恢复底图。保留生成结果的头发配色和深色阴影，没有另行重画。

## 文件与检查
- system_trace_open.png：1920×1080 RGBA，与 base_portrait.png 同画布。edit_region 外变化像素数 **0**；保护的非头发区域变化像素数 **0**。
- system_trace_closed.png：1920×1080 RGBA。同样的新头发，眼睛使用 system_portrait_closed.png 原有像素；与睁眼版在眼睛差异区域以外变化像素数 **0**。原始眼睛差异区域共 7280 像素。
- compare.png：5760×1080，左为 ref_082_aligned.png，中为睁眼版叠白底，右为睁眼版以 50% alpha 叠在参考上。

睁眼图有 1661045 个 alpha=0 像素，背景为真实透明。衬衫、黑色飘带和耳机线保持底图像素；没有添加手部。所有实际替换像素均来自认可结果缩放后的对应位置。闭眼图在 edit_region 之外也与闭眼底图一致。
