# 整身姿势测试帧

本批使用内置 imagegen，以 `../design/design_a.png` 为统一造型和画风参考，生成完整人物图，用于整图换帧动画测试。

- `idle_a.png`：近侧、画面右侧戴红色臂章的手插裤袋；远侧手空手自然垂下。
- `slash_a.png`：远侧、画面左侧手持直剑，身体前倾、双脚大步分开，剑向画面右侧挥出。自检后重画一次，收小头部比例以接近设定图。
- `_compare.png`：从左到右是 design_a、idle_a、slash_a，每张缩到512宽；当前只有三栏，总尺寸1536×512。

两个姿势输出均为2048×2048 RGBA PNG，保留生成的透明通道。工具原生返回1254×1254；保存时对整个完整人物作等比尺寸及位置归一化，头顶约y250、最低脚底约y1900。没有拆零件或把设定图像素复制进生成图。人物比例和画风已做并排目视检查；具体换帧观感尚未在游戏内测试。

## 召唤姿势未生成

`evoker_a.png` **不存在，也没有用其他姿势替代**。原要求“召唤器枪口抵自身太阳穴”被 imagegen 的输出安全检查拒绝，返回分类为 self-harm、violence。工具没有返回可保存的召唤图。

已向用户说明拒绝原因并提出“枪举在脸侧、枪口朝外、不接触头部”的替代方案。用户明确选择：**先只提交待机和挥砍，说明召唤图未生成**。因此本次只交付上述两张姿势和对应核对图，不再尝试原召唤姿势，也不擅自生成替代姿势。

本次没有修改代码、接入动画、启动游戏或覆盖 design_a 和既有分层素材。远端 Claude 读取本目录时，请将其视为两张整身动作测试帧，并注意召唤帧缺失。
