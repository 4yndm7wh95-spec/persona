# 第一批姿势参考

Blender 4.5.9，fixed2 无面具模型，已合成的 rotation-only 动作，Workbench FLAT/TEXTURE，1024×1536 RGBA，正交相机沿 (-0.8,-1,0)，按变形包围盒独立取景。左上文字是参考标签，生图不得复制。源脚本见 research/p5r/pose/scripts。

实际时间见 selection.json 的 used_time_seconds。slash 和 hurt 补渲前后 0.1 秒：slash 选择提前 0.1 秒的低身前冲，hurt 选择提前 0.1 秒的明显后仰；kick 补看两侧后仍选原时间，其姿势为腾空抬膝，并非完全伸直的踢腿。其余沿用指定时间。gun 原参考偏背面，生成仍遵从文字要求的右向 3/4；原版参考均没有武器，刀枪仅在生图添加。
