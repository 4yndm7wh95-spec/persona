## 渲染与裁切设置

复用亚森成品流程：Blender 4.5.9 LTS、EEVEE、16 samples、Standard 色彩变换、透明胶片背景。
原贴图颜色乘以 Diffuse → ShaderToRGB → 恒定两阶明暗；暗阶 0.48、亮阶 1.0，阈值 0.45。太阳灯强度 2.0，旋转角为 (25°, -25°, -30°)。

转杖相机为正交，相机方向 (-0.8, -1, 0)，3/4 朝画面右侧；全 51 帧共用固定相机与缩放。
相机位置 (-1876.032593, -2329.489258, 197.598846)，正交范围 471.265076。
按全部帧 alpha 并集外扩 8 个原始像素，固定裁切框为 `[291, 63, 1434, 1484]`（1536 方形原图坐标，右/下为开区间），等比缩放至高 1024。
最终尺寸上以 alpha 的 7×7 最大值滤波外扩 3px，合成黑色轮廓，与亚森完全相同；所有 alpha=0 像素的 RGB 清零。

固定锚点采用左上原点、像素单位：

- foot：`[366.553, 972.140]`，固定世界地面参考 (0,0,0) 的投影，不逐帧跟踪脚。
- body_center：`[366.553, 697.025]`，固定静止空间中心 (0,0,117.133806) 的投影。
