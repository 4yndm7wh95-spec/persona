## 检查说明

只读取文件尺寸和像素格式元数据；其余按目视记录，不做像素测量。五张均为横幅、约1.3:1，均带 alpha（读取格式 Format32bppArgb）。每次设置 `transparent_background=true`，目视未见独立白底/灰底或额外场景；未逐像素核验轮廓外 alpha 是否全部为0。

五张均只有一只手，没有画被抓物、文字、骨头或伤口。手腕都在左侧中部、手指整体朝右，未出现方向错误，因此没有触发重试。五张解剖大小和烟状手腕位置大致接近，但不是严格对齐的动画帧；烟丝过渡仍偏长，部分有前臂感，hold/squeeze 的握紧程度也保留原始输出，供用户验收，不因外观偏差重画。
