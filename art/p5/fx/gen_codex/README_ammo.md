# 弹巢 UI 素材
- 内置 image_gen：弹巢、装填弹底、空壳弹底各生成一次，未自行评审后重新生成。提示词及原始大图路径见 ammo_generation.json。
- 交付：ammo_cylinder.png 512×512 RGBA；ammo_round.png 与 ammo_spent.png 各128×128 RGBA，四角alpha均为0；*_raw.png保留原始输出。
- 图形裁切至alpha有效边界后适配画布：弹巢外径440px；两种弹底可见圆形82px，居中放于128px透明画布。无需修改图形内容或再次生图。
- 六个弹膛由暗色孔内部连通区域实际测量，中心、内切直径见ammo_layout.json。最小安全内径约86.5px，弹底可见圆形82px留有余量。
- ammo_check.png将装填/空壳交替叠入六孔，检查实际适配。
- 生成的六孔并非数学上完全等距：实测孔中心距外径半径比例约0.56～0.62，提示词要求为0.55。按“只生成一次”的规则保留生成结果并给出实际坐标，未伪写理论坐标。游戏定位请使用实际布局坐标。
- 单文件均低于20MB。未修改任何游戏文件、build_rig_p5.py或p5mod；art/cards等其他会话本地文件未处理。
