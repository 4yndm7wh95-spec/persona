# 防御碎玻璃素材

交付位置：art/p5/fx/v4/glass/。三张各生成一次、重画零次，不改 mod 代码，不编译，不启动游戏。

- glass_shards_sheet.png：2048×2048 RGBA，4×4 图集，16片不同形状的玻璃；每格512×512。冷白/灰白半透明玻璃，少量 P5 红反光，厚亮边、斜反光条和小崩口，无粗黑描边。
- glass_glints.png：1024×256 RGBA，4×1图集，每格256×256，四种白红闪光。每个独立等比整理进格子，至少16px空边。
- glass_dust.png：256×256 RGBA，十几颗细碎亮屑。
- check_glass.png：16片图集叠在深灰底上的预览。这个检查图有底色，三张交付素材无底色。
- *_raw.png：未处理的原始生成结果；*_generation.json：完整提示词、原始尺寸、处理方法与检查记录。glass_checks.json 另列每格范围及玻璃内容包围盒，供切图。

## 透明度和图集整理

原始碎片输出带有低透明度背景噪声，且玻璃主体偏实，因此未直接交付原图。每格依据原alpha提取主要碎片轮廓，补轮廓内部低透明区域，清除外部底噪；按每格448×448内容加32px安全留边整理回512格。没有用代码重新画多边形替代生成的玻璃。

玻璃内部 alpha 映射为64～153（约0.25～0.6），亮边和反光映射为235（约0.92）。保留原始RGB细节；这是一张可叠加的美术贴图，本身不做真实场景折射，折射和运动由游戏代码负责。

- 16格均有内容，均未跨格；实际最小内容边距 52px。
- 交付碎片非透明像素中，约 85.6% 位于64～153，其余是较亮高光。
- 三张交付图尺寸、RGBA、四角alpha0均检查通过；所有alpha0像素RGB清零。
- 玻璃屑以alpha>32、至少2px的连通块计数为 17 颗，适合小粒子叠加。
- 轮廓清理可能舍弃极细的孤立崩口或非常弱的反光，原图保留供调整。最终玻璃观感、红色强度和粒子亮度由用户验收。
