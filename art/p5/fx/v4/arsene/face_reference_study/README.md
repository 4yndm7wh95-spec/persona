# 亚森原版面部核对

来源：MODEL/CHARACTER/PERSONA/0201/PS0201.GMD，使用既有修复GLB：C:/Users/kkk/sts2_tools/p5r_rip/fx_work/arsene/PS0201_fixed.glb。旧的model/arsene目录曾混有ps_mokoi纹理，因此本次按现有成品sources.json所指的PS0201重新核对，没有仅凭目录名认模型。

原模型含独立hat和mask网格，直接读取贴图ps_arsene_t02.png和ps_arsene_eye_aura.png。用Blender4.5.9 Workbench纹理预览，原模型未改，隐藏翅膀避免挡脸，正交相机渲正面/3/4/侧面。这是设计核对图，不是实机光照复刻或新生图。

确认的明显特征：
1. 黑色角面结构，额头/鼻梁一线向下收成尖下巴；两侧尖角边缘有红橙纹路。
2. 眼周不是只有白色缝线：原贴图有红橙色锐角眼周图案，同时存在独立eye_aura贴图；最终眼部亮度/色彩还受原版材质效果影响，不能仅凭全身图高光判断结构。
3. 下半脸有非常明显的锯齿笑口、上下排列的红橙色尖齿，这是此前生成图缺失的关键识别特征。
4. 不能画成只有长鸟嘴/黑色头盔和两条白眼缝的无嘴面罩。白色领巾在脸下面，不能代替面部笑口。

原模型近景与官方小图的信息需要共同使用；本轮只做观察核对，不继续生成或改定稿。
