# 亚森 v7 修脸版分层

母图：`../arsene_draft_v7_facefix.png`（已确认修脸版）；未使用未修脸的 v7。所有层都是 2048×2304 RGBA，同一原点和画布。旧 layers/ 不覆盖。

## 分层及补全

- wing_back.png：画面左侧下垂翅膀，独立生成，补隐在身后的肩根及内侧羽毛。
- wing_front.png：画面右侧翅膀，独立生成，补肩根和被身体遮挡的内侧羽毛。
- body.png：独立生成无翼、无臂身体，补领巾、胸口、马甲、腰部及肩部接合面。帽子、修正后的脸和上领口另从已确认母图保留贴回，避免脸再走样。
- arm_back.png：腰侧手臂，独立生成完整肩帽、袖子、弯肘、袖口与黑手套；按母图拟合位置。
- arm_reach.png：胸前手臂，独立生成完整隐藏肩关节。对位时发现全层自由拟合会改变原胸前手势，因此最终以母图可见袖子和手指为主体，仅以生成素材补隐藏接合区。完整生成结果保留在 arm_reach_raw.png 便于再利用。
- eyes_glow.png：直接提取修脸母图的红橙眼周亮纹，排除下面的牙齿。不额外生成白眼光晕。

每个独立生图层生成一次、自动重画零次。原始结果为 *_raw.png；提示词、参考、对位数据在 *_generation.json。做过坐标、蒙版与关节贴回调整，没有追加生图。

## 坐标与层次

见 layers.json：左上为原点，+x 向右、+y 向下。z_index 从后向前：左翼、右翼、身体、腰侧手臂、胸前手臂、眼周亮纹。腰侧手臂虽命名 back，其手掌实际覆盖马甲，故放在 body 前。

包含两翼肩根、双臂肩关节、身体浮动中心、胸前 claw_tip、较低靴尖 toe、hat_top。坐标为本次人工对位初值，动画绑定时仍可调整。

## 检查及限制

- 六张尺寸均为 2048×2304、RGBA，四角 alpha 全为 0，四条画布边缘 alpha 最大值均为 0。
- alpha≤2 的低透明残点清零，透明像素 RGB 清零。
- check_layers.png：母图与 assembled.png 并排，底部是六层。
- check_moved.png：两组相反方向的翅膀 ±12°、手臂 ±10° 静态叠图。未见明显的关节贯穿空洞；羽毛之间的自然透明间隙不属于漏补。没有额外生图补洞。
- 这不是像素级无损分解。独立生成导致羽毛、衣褶、腿形、轮廓有变化；人工对位后总体姿势接近，但不能宣称叠图与母图完全一致。以 RGBA 差值 >8 统计，前景并集约 75.5% 像素有差异（包括颜色与细节差异），详见 layers.json。
- 胸前手臂隐藏补片和肩部接缝、翼根旋转后的外观仍需用户和 Claude 美术验收；本次未做游戏内验收、未改动画代码。
