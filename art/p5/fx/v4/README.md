## 检查与交付方式

- 每组均有check_<分组>.png深灰底，以及check_<分组>_checker.png棋盘格底，方便用户和Claude检查透明边缘。
- 24张后续特效贴图尺寸、RGBA、四角alpha=0、全透明像素RGB清零检查均通过，记录见CHECKS.json和逐图generation.json。
- 交付尺寸归一化；原始imagegen图另存raw，记录原始尺寸，不宣称全部原生2048。发光边缘保留半透明alpha，没有白底/绿幕抠图。
- 总体积约59.8MB，单文件最大约2.31MB，低于120MB/20MB上限。
- 完整提示词、原版路径、原图尺寸、交付尺寸、自检结果均在各组README与generation.json。

## 需要用户/Claude确认的限制

1. 亚森和八岐大蛇都是草图，不是最终局内可动画的分层成品；不拆身体、翅膀、手臂或蛇头，等确认后另做。用户允许先继续其他组，不把草图默认当成定稿。
2. 原版预告函是两种正面设计，自带旧纸/暗边。已有可用原版后没有额外生成竖版正背面；没有确认或交付配套无字背面。
3. 粒子贴图虽为4×4构图，但生成的物体和外晕在一些512格内贴边：24px安全边距不足的格，羽毛13格、碎片10格、火花12格。**没有达到提示词要求的每格48px边距，不把图集宣称成严格裁切即用**。*_layout.json记录每格alpha20边界；交Claude决定重新排版或返工，本轮没有自动重画。
4. 八岐大蛇草图有半透明暗色外晕，原样交付和记录；轮廓外视觉是否干净由用户验收。没有擅自抠掉和主体重叠的像素。
5. 所有贴图尚未接入或实机验收；未改mod代码，未编译、安装或启动游戏，未修改游戏原文件。
