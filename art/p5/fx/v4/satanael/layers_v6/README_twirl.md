# 撒旦耶尔 v6 转枪素材

用于《杀戮尖塔 2》P5Joker Mod 中撒旦耶尔的转枪动画。三张图使用与已确认 v6 相同的 3400×3600 RGBA 画布和左上角原点。新增素材与现有 v6 分层同目录使用。

| 文件 | 内容 | 原生来源 |
| --- | --- | --- |
| arm_fore_open.png | 沿用前臂和腕口，原位补画半朝镜头的空手。食指向右微斜下，拇指及其余三指放松。肘轴仍为 (1624, 2177) | 1430×1100 RGBA |
| finger_tip.png | 从空手图原位提取第二指节至指尖，起边羽化 4 像素 | 1:1 提取空手层 |
| gun.png | 原位提取完整左轮的可见部分，补全手挡住的枪柄、扳机和护圈后半。保留整段长枪管、准星和枪口 | 遮挡补片 1254×1254 RGBA，可见部分沿用定稿 |

使用内置 ImageGen。首次道具请求在输入检查被拒绝，随后明确说明真实的 Mod 用途后返回了补画。原生素材裁切、缩小对位，之后做两轮局部配准和接缝修整。来源尺寸、提示词和 SHA-256 在 layers.json。

转枪期间用空手层替换握枪前臂，枪在空手层上方，指尖覆盖在旋转的枪上。spin_finger 为 (2220, 2201)，位于食指第二指节。gun_guard 为 (2214, 2200)，取在扳机后侧的透明开口内。以原图坐标放置时，从 gun_guard 到 spin_finger 的偏移为 (+6, +1) 像素。

## 检查

- check_twirl.png 展示空手与指尖原位叠图、独立枪原位叠图，以及 0°、90°、180°、270° 四个转角和护圈局部。
- 四个角度的护圈轴都与食指轴重合，轴处枪层 alpha 为 0，指尖层可见。护圈的封闭开口含 3,908 个 alpha 为 0 的像素，轴点到最近实像素约 18.6 像素。
- 空手层从肘端到 x=1956 与握枪图逐像素一致。独立枪从 x=2345 向右与握枪图逐像素一致，含 156,244 个有内容的像素。枪口最右实像素距右边缘 46 像素（alpha ≥ 128）。
- 三层的画布边缘 alpha 为 0，全透明像素的 RGB 清零。放大时可见枪柄嵌板与护圈后段的轻微补片色差。

分支为 claude/epic-archimedes-m9an69。
