# 撒旦耶尔原模型外观参考

## 来源与选择

主模型为 BASE.CPK/MODEL/CHARACTER/PERSONA/0170/PS0170.GMD。复用本机 GFDExport 导出、fix_gfd_glb.py 修复后的 PS0170_fixed.glb，以及按骨骼名挂载的动作 GLB。模型与中间文件只留本机 p5r_rip/fx_work/satanael/，没有提交。此次未用 ImageGen，未启动游戏、编译或改 Mod 代码。

另只读导出检查了 PSZ0170、PS0199：PS0170 与 PS0199 都是22个网格、11个材质，主要网格名相同，三张 ps_satanael 基础DDS的SHA-256完全一致。PS0199额外有 ev_satanael_t01_shadow.dds；PSZ0170为21个网格、9个材质，少一个枪子网格，三张基础DDS仍相同。这支持它们属于同一套撒旦耶尔资源，但不能据此证明所有几何和运行时材质参数相同。选与 BPS0170 战斗动作同编号的 PS0170 作为主参考，不混入事件阴影或异色材质。详见 model_comparison.json。

## 光环与动作

光环不是只能另找的特效贴图：PS0170包含 m_ring_gfdMesh_0/1/2 三个网格。本轮全身图包含它们，另渲 halo_lit/cel.png，便于看清尖刺环形。正面水平机位下光环接近一条细线，属于观看角度，并非裁掉。

待机采用 BPS0170_000_main_0000 第0帧。已读原有16段含骨骼轨道动作的联系表，举枪选 BPS0170_000_main_0005 第27帧，30fps参考下约0.9秒；能确认举枪瞄准，尚未用游戏内事件映射证明技能名就是大罪穿甲弹。原版视频镜头仅作方向线索，低前方图是相近仰视参考，不声称完全还原原游戏相机。镜像图只翻转图像，不能用于判定人物左右手。

## 渲染与检查

Blender 4.5.9，原模型统一0.001场景单位缩放，正交相机。lit使用原贴图、普通中性柔光，不描边；cel使用原贴图乘两阶硬阴影并加1.6px黑描边。2048×2048；完整枪侧面为2560×1440。没有烘焙蓝色舞台光。保留导出材质本色，但原游戏的专用反射、发光、阴影与环境照明没有复现，不能将这里的灰暗面甲直接当作游戏最终银白高光颜色。

初轮发现GLTF导入材质把贴图Alpha误当表面透明度，产生破洞；重新渲染时取消表面Alpha连接、设实体表面不透明，轮廓外仍为真透明。DDS转PNG保留原始通道，不修改贴图。中途脚本空World初始化错误已修复后重跑，最终图片不是失败帧。

全身转身图和瞄准图按所有网格顶点自动框选，额外15%留白，包含身体、双翼、双角和光环；头部图只显示头与眼睛网格，完整框入双角。枪与握手为局部特写，周边身体可出画；握手特写允许枪管出画，完整枪见 gun_side。每张四角Alpha、内容包围盒、边缘接触记录在 checks.json。联系表为深灰底预览，原始渲染为RGBA。

## 与第6～9版生成草图的区别

- 头：原模型角从两侧大幅弯出，头盔顶部为收束的尖锐结构，不是第8版的人类恶魔头。
- 脸：封闭面甲与独立眼睛网格，没有第8版的嘴、牙和笑容。原游戏银白观感还受专用材质与强光影响。
- 翅膀：原模型存在多层巨大镰刀形翼片，确实有大面积骷髅纹样、星带等原贴图图案；这与第9版人为去除花纹的要求不同，应由用户决定最终取舍。
- 枪：原模型是异常细长的大枪，金属装饰、握把、护圈与第6/8/9版生成图都不完全相同。请以侧面及握手近景判断，不把生成左轮的细节反套成原版证据。
- 配色：本模型贴图同时有黑、暗蓝灰、金色、红色，大面积金色骷髅不是本轮添加；第9版整体去金属于美术改造。
- 下半身：原模型有腿甲与金色纹样、细长腿段；第8版蓝短裤是生成图误读，第9版全黑腿甲也属于改造，不能代替原模型。
