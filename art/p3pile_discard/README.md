## 交付与定位

- 画布均为 1024×1536 RGBA；候选及 base 原样保存，不裁剪、不缩放。
- `meta.json`：左上角为原点的像素坐标；bbox 的 right/bottom 为不包含的边界。`bbox` 包括全部非零 alpha；`visible_bbox` 使用 alpha>127，避免低透明度杂点误导定位。所有手工特征点是近似中心。
- 旧交接 README 保存在 `README_v2.md`。旧 preview 如存在，保存在 `preview_v2.png`。旧候选及原始参考图不改不删；牌组目录不动。

## 自检及已知问题

- 背景有大量真正 alpha=0 的透明像素，换底合成后没有工具直接预览里显示的彩色柔光。透明像素隐藏的 RGB 不用于判断背景合格。
- **严格透明检查仍有未通过项：存在 alpha=1..3/255 的零星杂点，未擅自阈值抠图。** 全图该透明度范围像素数为 25216，其中也可能包含自然轮廓抗锯齿；这个统计不能等同于背景杂点总数。故保留原始 alpha，不声称所有背景像素都恰为 0。
- alpha 范围 [0, 254]；严格 bbox=[0, 21, 1024, 1536]；主体 bbox（alpha>127）=[24, 27, 1024, 1536]。
- 人物、两只手和五指已做视觉检查，未见明显关节扭曲；手指受透视和弯曲影响会部分重叠。画风、蓝白配色与指定两张参考对照；主观相似度仍需用户验收。
- 未启动游戏，尚未做游戏内动画及轮廓光验证。
