## 自检及已知问题

- 背景有大量真正 alpha=0 的透明像素，换底合成后没有工具直接预览里显示的彩色柔光。透明像素隐藏的 RGB 不用于判断背景合格。
- **严格透明检查仍有未通过项：存在 alpha=1..3/255 的零星杂点，未擅自阈值抠图。** 全图该透明度范围像素数为 9207，其中也可能包含自然轮廓抗锯齿；这个统计不能等同于背景杂点总数。故保留原始 alpha，不声称所有背景像素都恰为 0。
- alpha 范围 [0, 254]；严格 bbox=[181, 103, 930, 1505]；主体 bbox（alpha>127）=[366, 322, 717, 1309]。
- 人物、两只手和五指已做视觉检查，未见明显关节扭曲；手指受透视和弯曲影响会部分重叠。画风、蓝白配色与指定两张参考对照；主观相似度仍需用户验收。
- 未启动游戏，尚未做游戏内动画及轮廓光验证。
