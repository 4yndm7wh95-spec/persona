# Orpheus 分层零件（手工克隆初版）

## 交付状态
11 张 PNG 均为 386×858、RGBA 真透明底。没有修改源图或代码；左右指画面左右。静态像素叠回与去光晕基准完全一致（比较预乘 RGB 和 alpha，最大差 0，差异像素 0）。

**动态自检未完全通过：这批是初版，不能当成已经满足所有动画验收条件的最终素材。** 多轮修整后，±15°同时层级摆动仍在竖琴左框、肩/肘以及髋/膝附近出现锯齿、补片碎边和局部透明缺口。保留问题预览，供后续精修；未掩盖或宣称已解决。

## 方法与补画
只使用 PIL/numpy：手工多边形分区保留源图可见像素，遮挡区域采用邻近材质逐圈颜色克隆延拓；未调用 imagegen。浅色半透明外光晕移除，紧贴轮廓保留一圈低透明度抗锯齿。每个零件保留完整画布坐标。

- 竖琴：续接被躯干遮挡的左侧框架及下框，琴弦按蓝色继续。此处仅构造了局部隐藏轮廓，尚未完整复原被人物遮挡的整架琴。
- 躯干：补头部、肩部与手臂后面的青色表面；保留胸部扬声器、腰甲和肩甲。
- 大腿、上臂：在髋、肩、膝、肘附近克隆延伸；关节尝试加入半径23像素的重叠补片。
- 小腿、前臂、头：补连接处。较高层补片复制原接触表面以保持静态叠回，不代表真实隐藏结构。

## 限制（明确未满足的要求）
补画限定在静态实心覆盖区域，以维持原轮廓，因此**没有保证遮挡边界向内25%或40像素的完整补画，也没有保证所有关节两边都达到15～25像素连续重叠**。克隆延拓会模糊；独立零件里仍有薄片、碎边和不完整的隐藏表面。±15°大幅动画尚不能直接使用；需要继续绘制连续的背面材质与圆滑接头，或者重新取得可分层的原始渲染。所有源文件保持不变。

## 三张预览结论
- preview_stack.png：原图、去光晕后叠回、与原图预乘RGB/alpha差异×4；人物本体差异为黑色，亮色主要是被移除的光晕。
- preview_parts.png：棋盘格仅在预览中；红十字为pivot。零件PNG本身没有棋盘格或背景。此图可见竖琴和接头的残余碎边。
- preview_swing.png：父子层级一起转动−15°和+15°，预览加宽避免裁切。仍有上述透明缺口和接缝，不满足无洞验收。
