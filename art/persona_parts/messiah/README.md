# Messiah 分层零件与骨骼动画参考

## 状态
本目录包含 14 个 600×970 真透明 RGBA 零件、rig.json、三张验收预览及辅助 QA。原图、代码、游戏资源均未修改。
这是可用于动画接入研究的拆件稿；±15° 的严格无空洞验收未完全通过，不能当作全部补画完成的成品。已知限制见下文。

## 取图、去光晕和补画方法
全程仅使用 PIL / numpy；未调用 imagegen，因本任务要求可见源像素保持不变，使用手工多边形拆件和原像素克隆更合适。没有安全拒绝或绕过。
先以高 alpha 本体建立种子，保留一像素抗锯齿邻域及有色细链/刃尖，移除外围烘焙的白色低透明度晕圈。对剩余半透明边缘，用相邻不透明本体颜色去白污染。reference_clean.png 是这一步的参考图；不替换源文件。
可见像素按源图位置划到对应零件；补画只放到后续绘制零件遮挡的区域，尽量不改变静态叠回。
胸口在抬起手臂和围巾后方的约 40px 区域，用可见蓝色胸甲纹理克隆；长刃后背安装部位用上方可见金属刃面克隆。
双肩、颈、双髋采用约 22px 半径的圆形重叠帽，纹理来自同一零件的可见原像素；torso 对应部位也补重叠。翼刃腰部遮挡处补了同色纹理。
穿过四口棺材的锁链，从原图 581~595 行的可见链节循环克隆，按原链走向补连续段；原有底部卷链保持原位。
左右腿的髋部被前裙遮挡区域已补克隆关节帽；右腿受深蓝裙甲的绘制顺序限制，不能完整补出遮挡大腿（下文说明）。

## 三张预览结论
### preview_stack.png
从左到右：原图（含烘焙晕）、拆件叠回、|叠回−原图|×4、|叠回−去晕参考|×4。差异以 alpha 合成到黑底后的可见 RGB 计算，避免透明像素隐藏 RGB 造成假差异。
可见不透明本体的源像素变化数：0。最终叠回与去晕参考仍有 2483 个 RGBA 像素差异（主要为 alpha 225~254 的遮挡边缘与关节补画导致的透明度变化），平均每通道绝对差 0.002814/255。最后一栏近黑，但并非逐像素完全一致。
### preview_parts.png
14 零件各自放在棋盘格上，红十字标出 pivot，所有资源画布仍为 600×970；预览缩略图仅为展示缩小，不影响零件位置。可检查右腿上方的关节帽和可见腿之间的遮挡缺口。
### preview_swing.png
torso 固定，其余每个子零件分别相对 parent 转 −15° / +15°。使用完整父子变换，棺材继承锁链和手臂运动；不是把各零件独立绕世界坐标乱转。预览外围额外加 220px，避免尖刃与棺材摆动被截图边界裁掉；rig 和零件坐标未改变。
26 次父子关节局部重叠检测均大于 0，双肩、颈、髋和链条挂点没有完全脱离。但这一检测不等价于无空洞：右大腿与裙甲交界、部分胸口/刃根克隆区域仍可能出现窄缝、碎边或材质接缝。因此严格“所有可动零件 ±15° 无空洞”不通过。

## 已知问题与未完全满足的要求
1. 给定 z 要求 wing_right=3、leg_right=5，但源图右大腿被深蓝裙甲压在前方遮挡；如果在 05 中补出完整白色右大腿，它会盖住 03 蓝裙，静态叠回立即改变。此处选择保持静态原构图，保留受遮挡的缺口；不能声称右腿已完整补齐。要做到大范围露出隐面，需要改变前后遮挡层划分或追加前景裙甲盖片，目前没有擅自改 rig 结构。
2. “补画延伸 25% 或 40px、取大者”只在胸口/刃根/链段等可由后绘制层遮盖的区域执行；受 z 顺序限制的右大腿不能达到这一要求。关节圆帽采用 22px 重叠，按关节规则处理。
3. 源图本身只有单一视角和烘焙光照，隐藏表面的真实轮廓不可推导；手工克隆能供小幅摆动研究，不能保证展开双臂、露出大幅胸腹/大腿时光照和结构完全自然。
4. 去晕采用保守 alpha / 有色本体筛选，极细或低 alpha 的边缘可能损失少量覆盖；原图上缘长刃已经贴边，保留原位，未另补原画布外的刃尖。
5. 棺材挂点按可见链穿过的位置设在棺材左上部，并非几何顶部正中；这样父子旋转会沿原图链挂点运动。
6. 未修改任何游戏代码；这里不包含动画实现、游戏测试或安装。
